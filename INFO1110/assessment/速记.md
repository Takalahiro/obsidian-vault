## Q1 — 正则 + 文件 + 字典统计重复函数名

```python
import re

filename = input("Enter a python file name: ")
with open(filename) as f:
    content = f.read()

pattern = r"def\s+([a-zA-Z_]\w*)\s*\("
matches = re.findall(pattern, content)

counts = {}
for name in matches:
    counts[name] = counts.get(name, 0) + 1

printed = set()
for name in matches:
    if counts[name] > 1 and name not in printed:
        printed.add(name)
        print(f"{name} {counts[name]}")
```

| 易错 | ✅ 正确 |
|------|--------|
| `regex` | `r"def\s+([a-zA-Z_]\w*)\s*\("` |
| 忘记 `import re` | 必须 |
| 大小写敏感 | `foo` ≠ `Foo`，正则本身就区分 |
| 按首次出现顺序 | 用 `set` 去重，遍历 `matches` 不是 `counts` |

## Q2 — Radio 类（`__str__` + `__len__`）

```python
class Radio:
    def __init__(self, programmes: dict):
        self.name = programmes["station"]
        self.times = [programmes[k] for k in sorted([1, 2, 3, 4])]

    def __str__(self):
        starts = []
        for start, _ in self.times:
            if start < 12:
                starts.append(f"{start}am")
            elif start == 12:
                starts.append("12pm")
            else:
                starts.append(f"{start - 12}pm")
        return "Starting times: " + " ".join(starts)

    def __len__(self):
        total = 0
        for start, end in self.times:
            total += end - start
        return total
```

| 易错 | ✅ 正确 |
|------|--------|
| `__str__` 里 `print` | 必须 `return` 字符串 |
| `__len__` 返回值 | 必须 `return` 整数 |
| am/pm 边界 | 12 → `12pm`，13 → `1pm` |
| 遍历 times | `for start, _ in self.times:` 忽略 end |

## Q3 — 装饰器

```python
def whether_foundation_section(func):
    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        if result == "Pass":
            return False    # Pass → 不需要做 Foundation
        else:
            return True     # Not Pass Yet → 需要做
    return wrapper

# 使用示例
@whether_foundation_section
def best_ever_grade(rows):
    for r in rows:
        student = r[0]
        grades = r[1:]
        if "Pass" in grades:
            print(f'{student} "Pass"')
        else:
            print(f'{student} "Not Pass Yet"')
```

| 关键结构 | 代码 |
|----------|------|
| 装饰器 = 函数收函数，返回函数 | `def deco(func):` → `def wrapper(...):` → `return wrapper` |
| 包装参数 | `*args, **kwargs` |
| 调用原函数 | `result = func(*args, **kwargs)` |
| 使用 | `@decorator` 放函数定义上一行 |

## Q4 — RLE 解码

```python
# (a) 非递归
def rle_decode(s):
    result = ""
    for i in range(0, len(s), 2):
        result += s[i] * int(s[i + 1])
    return result

# (b) 递归（一个参数、无全局变量）
def recursive_rle_decode(s):
    if s == "":
        return ""
    return s[0] * int(s[1]) + recursive_rle_decode(s[2:])
```

| 易错 | ✅ 正确 |
|------|--------|
| 数字是字符 | `int(s[i+1])` 转整数 |
| 步长 | `range(0, len(s), 2)` |
| 递归终止 | `if s == "": return ""` |
| 递归调用自身 | `recursive_rle_decode(s[2:])` |

## Q5 — 类继承（Instrument / Piano / DrumKit）

```python
class Instrument:
    def __init__(self, note_count: int):
        self.note_count = note_count
    def play(self):
        print(f"Playing across {self.note_count} notes.")

class Piano(Instrument):
    def __init__(self):
        super().__init__(0)
    def play(self):
        print("Piano plays a grand melody.")

class DrumKit(Instrument):
    def __init__(self, drums: int):
        super().__init__(0)
        self.drums = drums
    def play(self):
        if self.drums == 5:
            print("Five-piece groove incoming!")
        else:
            print(f"Thumping on {self.drums} drums.")
```

| 易错 | ✅ 正确 |
|------|--------|
| 子类不调 `super().__init__()` | 必须调（给 0 即可） |
| DrumKit 参数 | 只收 `drums`，不收 `note_count` |
| 字符串拼写 | `"Five-piece..."` 大写 F；末尾有 `.` |

## Q6 — `**kwargs` + 字典过滤

```python
def passed(grades: dict, **kwargs):
    result = []
    for key, name in kwargs.items():
        if name in grades:
            test, assignment = grades[name]
            if test == "Pass" and assignment == "Pass":
                result.append(name)
    return result
```

| 易错 | ✅ 正确 |
|------|--------|
| `**kwargs` 是字典 | `kwargs.items()` 遍历 |
| 元组解包 | `test, assignment = grades[name]` |
| 两个都是 `"Pass"` | `and` 不是 `or` |
| 返回值 | `list`，按 kwargs 传入顺序 |
