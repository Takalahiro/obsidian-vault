# 第一章：动作游戏（ACT / Action Game）

## 一、定义 / Definition

**动作游戏（Action Game，简称 ACT）** 是以玩家的**操作反应、手眼协调、动作执行**为核心玩法的游戏类型。强调**实时性**，玩家通过攻击、跳跃、闪避、格挡等操作直接控制角色行动，胜负主要取决于**操作技巧**而非数值或策略。

> **核心三要素**：操作（Control）、反应（Reaction）、节奏（Rhythm）

---

## 二、发展简史 / Brief History

| 时期         | 年代          | 标志性作品                                    | 意义            |
| ---------- | ----------- | ---------------------------------------- | ------------- |
| **黎明期**    | 1970s-1980s | 太空侵略者 / Space Invaders、大金刚 / Donkey Kong | 街机时代奠基        |
| **横版黄金期**  | 1985-1995   | 超级马里奥 / Super Mario、魂斗罗 / Contra         | 平台跳跃定型        |
| **2D格斗爆发** | 1991-1998   | 街霸2 / Street Fighter II、KOF              | 格斗游戏黄金期       |
| **3D革命**   | 1996-2001   | 马里奥64 / Mario 64、铁拳 / Tekken             | 进入立体动作时代      |
| **现代化**    | 2001-2010   | 鬼泣 / DMC、战神 / God of War                 | 爽快连招体系成熟      |
| **类型融合期**  | 2011-至今     | 黑暗之魂 / Dark Souls、只狼 / Sekiro            | ACT + RPG 等融合 |

## 三、ACT 主要子类型详解 / Subgenres

### 1. 平台跳跃 / Platformer (PLG)

**核心玩法**：通过**跳跃、攀爬、移动**在地形间穿越，避开陷阱与敌人。

**子分支**：
- **2D 横版平台 / 2D Platformer**：超级马里奥兄弟 / Super Mario Bros.、蔚蓝 / Celeste
- **3D 平台 / 3D Platformer**：马里奥64 / Mario 64、奥德赛 / Odyssey
- **精确平台 / Precision Platformer**：超级食肉男孩 / Super Meat Boy、蔚蓝 / Celeste
- **益智平台 / Puzzle Platformer**：地狱边境 / Limbo、INSIDE
- **银河恶魔城 / Metroidvania**（衍生）：空洞骑士 / Hollow Knight

**代表作**：

| 作品 | 特点 |
| --- | --- |
| 超级马里奥兄弟 / Super Mario Bros.（1985） | 平台跳跃鼻祖 |
| 奥日与黑暗森林 / Ori and the Blind Forest | 美术 + 操作的巅峰 |
| 蔚蓝 / Celeste  | 精确操作 + 情感叙事 |


---

### 2. 清版动作 / Beat 'em Up (BTA)

**核心玩法**：玩家在**横向卷轴**或固定场景中，**击败成群敌人**通关。

**特点**：
- 多人合作（2-4人）
- 简单按键组合出连招
- 节奏明快、爽快感强

**代表作**：

| 作品 | 特点 |
|------|------|
| 双截龙 / Double Dragon（1987） | 清版动作开山作 |
| 怒之铁拳 / Streets of Rage | 街机黄金期代表 |
| 名将 / Captain Commando、恐龙快打 / Cadillacs and Dinosaurs | Capcom 街机经典 |
| 战斧 / Golden Axe | 加入魔法元素 |
| 勇者斗恶龙：英雄集结 / DQ Heroes | 现代化无双类衍生 |

---

### 3. 硬核动作 / Character Action / Stylish Action

**核心玩法**：以**华丽连招、风格评分（Style Rank）、Boss战**为核心，强调"打得帅"。

**核心机制**：
- **连招系统（Combo System）**
- **风格评级（如 DMC 的 D→C→B→A→S→SS→SSS）**
- **取消（Cancel）、目押、空中连段**

**代表作**：

| 作品 | 特点 |
|------|------|
| 鬼泣系列 / Devil May Cry | 硬核动作鼻祖，但丁的连招系统 |
| 猎天使魔女 / Bayonetta | 魔女时间 + 高速连招 |
| 战神（旧3部曲）/ God of War | 北欧神话史诗 + 利维坦之斧 |
| 忍者龙剑传 / Ninja Gaiden | 极高难度的硬核动作 |
| 鬼武者 / Onimusha | 日式刀剑动作 |
| 猎魔人/猎人系列 | 现代精密动作 |

> 💡 **硬核动作 vs 普通动作**：核心区别在于"**操作上限极高**"，普通玩家能通关，但高手能玩出完全不同的层次。

---

### 4. 格斗游戏 / Fighting Game (FTG)

**核心玩法**：1v1（或2v2、3v3）对战，通过**搓招、连段、防御反击**击败对手。

**子分支**：
- **2D 格斗 / 2D Fighting**：街霸 / Street Fighter、拳皇 / KOF、罪恶装备 / Guilty Gear
- **3D 格斗 / 3D Fighting**：铁拳 / Tekken、生死格斗 / DOA、灵魂能力 / Soulcalibur
- **乱斗类 / Platform Fighter**：任天堂明星大乱斗 / Super Smash Bros.
- **空战格斗 / Arena Fighter**：龙珠斗士Z / DBFZ、火影忍者：究极风暴
- **武器格斗**：灵魂能力 / Soulcalibur

**核心术语**：

| 中文 | English | 含义 |
|------|---------|------|
| 搓招 | Motion Input | 摇杆方向 + 按键的指令招式 |
| 必杀技 | Special Move | 特殊招式 |
| 超必杀 | Super Move / Ultra | 高威力终结技 |
| 连段 | Combo | 连续命中招式 |
| 取消 | Cancel | 中断动作接其他招 |
| 确反 | Punish | 防御后的反击 |
| 立回 | Neutral Game | 双方互相试探的中距离博弈 |
| 帧数 | Frame Data | 招式启动/收招帧 |

**代表作**：

| 作品 | 特点 |
|------|------|
| 街头霸王2 / Street Fighter II（1991） | 格斗游戏祖师爷 |
| 拳皇97 / KOF '97 | 中国街机厅记忆 |
| 铁拳7 / Tekken 7 | 3D格斗代表 |
| 罪恶装备 Strive / Guilty Gear -Strive- | 现代竞技格斗 |
| 任天堂明星大乱斗特别版 / Smash Ultimate | 派对格斗 |

**特点**：

- 体力条管理（Stamina）
- 死亡掉落与回收
- 篝火/休息点系统
- 翻滚 + 格挡 + 弹反

## 四、ACT 核心设计要素 / Core Design Elements

### 1. 输入响应（Input Responsiveness）
- **输入延迟**：必须 < 100ms，越低越好
- **缓冲（Buffer）系统**：允许提前输入下一个指令
- **取消窗口（Cancel Window）**：动作中可中断的时机

### 2. 战斗反馈（Combat Feedback）
- **打击感（Hit Feel）**：靠音效 + 震屏 + 顿帧 + 特效叠加
- **顿帧（Hit Stop / Hit Pause）**：命中瞬间的微小停顿
- **击退（Knockback）/ 浮空（Launch）**

### 3. 难度曲线（Difficulty Curve）
- 学习成本与精通空间的平衡
- 通过 Boss 战阶段性检验玩家成长

### 4. 摄像机（Camera）
- 3D ACT 的最大设计难题
- 锁定系统（Lock-on）
- 自动追踪 vs 手动控制

| 择 | Mixup | 让对手二选一/三选一的攻击 |
| 起手 | Approach / Opener | 进攻起势 |
| 压制 | Pressure | 持续施压不让对手行动 |
| 投技 | Throw / Grab | 投掷类招式（无视防御） |
| 受身 | Tech / Recovery | 倒地后的快速恢复 |
| 削血 | Chip Damage | 防御时受到的少量伤害 |
| 化解 | Deflect（只狼） | 精准弹刀 |

## 六、ACT 的"打击感"是怎么做出来的 / How Hit Feel Is Crafted

打击感是 ACT 的**灵魂**，由多个细节叠加而成：

### 1. 视觉层（Visual Layer）
- **顿帧（Hit Stop）**：命中瞬间冻结 2-6 帧
- **震屏（Screen Shake）**：根据攻击力度调整幅度
- **特效（VFX）**：火花、血液、能量爆裂
- **拖影（Motion Blur）**：武器挥动残影
- **慢动作（Slow Motion）**：关键击杀慢镜

### 2. 听觉层（Audio Layer）
- **多层音效叠加**：金属声 + 肉感 + 低频轰鸣
- **音效随距离/力度变化**
- **打击音 + 受击音 + 环境回响**

### 3. 手感层（Haptic Layer）
- **手柄震动（Rumble / Haptic Feedback）**
- **PS5 自适应扳机（Adaptive Triggers）**

### 4. 动画层（Animation Layer）
- **预备动作（Anticipation）**：挥刀前的蓄力姿势
- **跟随动作（Follow-through）**：挥完后的惯性
- **受击反馈（Hit Reaction）**：敌人被打飞、踉跄、僵直

> 💡 **业界标杆**：卡普空（Capcom）的《鬼泣》《怪物猎人》、白金工作室（PlatinumGames）的《猎天使魔女》，被公认为打击感天花板。

## 七、ACT 的难度设计哲学 / Difficulty Design Philosophy

### 1. 三种主流设计思路

| 流派 | 代表 | 哲学 |
|------|------|------|
| **爽快流** | 鬼泣、猎天使魔女、战神 | 让玩家"打得帅"，难度可调 |
| **硬核流** | 忍龙、黑魂、只狼 | 通过死亡逼迫成长 |
| **公平流** | 蔚蓝、空洞骑士 | 难但讲理，失败必有原因 |

### 2. 难度设计的"心流（Flow）"理论

```
难度过低 → 无聊（Boredom）
难度过高 → 焦虑（Anxiety）
难度适中 → 心流（Flow）← 最佳游戏体验
```

优秀的 ACT 通过 **Boss 战、关卡节奏、敌人配置** 把玩家持续保持在"心流通道"内。

### 3. 死亡惩罚的尺度

| 类型 | 惩罚程度 | 例子 |
|------|---------|------|
| 极轻 | 原地复活 | 战神（普通难度） |
| 较轻 | 回到检查点 | 鬼泣、猎天使魔女 |
| 较重 | 掉落经验/金钱 | 黑暗之魂、艾尔登法环 |
| 极重 | 永久死亡（Roguelike） | Hades、死亡细胞 |

## 八、ACT 的经典战斗系统拆解 / Combat System Deep Dive

### 1.《鬼泣5》/ Devil May Cry 5 — 风格评分系统

```
D (Dope!)
↓
C (Crazy!)
↓
B (Blast!)
↓
A (Alright!)
↓
S (Sweet!)
↓
SS (SShowtime!)
↓
SSS (SSStylish!) ← 最高级
```

**评分提升方式**：
- 多样化攻击（不重复同招）
- 持续命中不被打
- 高难度技巧（空中连段、武器切换）

**评分下降方式**：
- 受击
- 长时间不攻击
- 重复使用同一招

### 2.《只狼》/ Sekiro — 架势系统（Posture System）

不同于传统血条战斗，只狼引入：
- **架势条（Posture）**：靠攻击和弹反积累
- **架势崩溃**：可触发"忍杀（处决）"
- **核心循环**：弹反 → 架势满 → 一击毙敌

> 这一系统**革新了 ACT 战斗逻辑**，从"减血"变成"破势"。

### 3.《怪物猎人》/ Monster Hunter — 武器特化系统

14 种武器，每种都是独立的战斗系统：
- 大剑：蓄力一击
- 太刀：见切弹反
- 操虫棍：飞行连段
- 盾斧：变形连击

这种设计让一款游戏拥有"14 套战斗系统"的深度。

#  第二章：STG / 弹幕射击 / Shoot 'em Up

## 一、定义

**STG（Shooting Game / Shoot 'em Up，简称 SHMUP）** 在中文语境下**特指传统的"飞行射击"游戏**，玩家操控飞机/角色，在 2D 屏幕中躲避大量弹幕并反击。

> ⚠️ 注意：日本语境下 STG = 所有射击游戏；中文/欧美语境下 STG ≈ 飞行射击/弹幕射击

## 二、核心特征

- **2D 平面**（俯视或横版）
- **大量子弹**（弹幕）
- **小判定点（Hitbox）**
- **无装备成长**，纯操作技巧
- **关卡制 + Boss 战**

## 三、子类型

### 1. 纵版射击 / Vertical Shooter
画面**从上往下卷轴**，玩家飞机在下方。
- 代表作：**雷电 / Raiden**、**1942**、**怒首领蜂 / DoDonPachi**

### 2. 横版射击 / Horizontal Shooter
画面**从右往左卷轴**，玩家在左侧。
- 代表作：**沙罗曼蛇 / Salamander**、**R-Type**、**宇宙巡航机 / Gradius**

### 3. 弹幕射击 / Bullet Hell / Danmaku
**屏幕被密密麻麻的子弹覆盖**，靠极小判定点穿梭。
- 代表作：**东方Project / Touhou**、**怒首领蜂大复活**、**虫姬**

### 4. 全方向射击 / Twin-Stick Shooter
**双摇杆**：一个控制移动，一个控制射击方向。
- 代表作：**几何战争 / Geometry Wars**、**Enter the Gungeon**、**Helldivers**

### 5. 固定屏幕射击 / Fixed Shooter
画面不卷轴，敌人从屏幕顶端出现。
- 代表作：**太空侵略者 / Space Invaders**、**小蜜蜂 / Galaxian**

## 四、代表作年表

| 年份 | 作品 | 意义 |
|------|------|------|
| 1978 | 太空侵略者 / Space Invaders | 射击游戏鼻祖 |
| 1981 | 大蜜蜂 / Galaga | 街机经典 |
| 1985 | 宇宙巡航机 / Gradius | 横版STG标杆 |
| 1990 | 雷电 / Raiden | 纵版STG里程碑 |
| 1995 | 东方封魔录 / Touhou | 弹幕游戏新流派 |
| 1997 | 怒首领蜂 / DoDonPachi | 弹幕射击定型 |
| 2008 | 几何战争2 | 现代双摇杆复兴 |
| 2017 | Cuphead | 横版STG + Boss Rush 复兴 |

## 五、核心术语

| 中文 | English | 含义 |
|------|---------|------|
| 判定点 | Hitbox | 角色实际受击区域（通常很小） |
| 弹幕 | Bullet Pattern / Danmaku | 复杂的子弹群 |
| 擦弹 | Graze | 子弹擦过判定点（加分/能量） |
| 清屏 | Bomb / Screen Clear | 消除全屏子弹的大招 |
| 残机 | Lives | 剩余命数 |
| 续关 | Continue | 投币继续 |
| 1cc | 1 Credit Clear | 一币通关 |
| 全要素 | All Clear | 全收集通关 |

#  第三章：FPS / 第一人称射击 / First-Person Shooter

## 一、定义

**FPS（First-Person Shooter）** 是以**第一人称视角（玩家眼中视角）**进行射击战斗的游戏类型。是当今**全球市场份额最大**的射击类游戏。

## 二、核心特征

- **第一人称视角**（看到的就是角色看到的）
- **3D 立体战场**
- **枪械操作**：瞄准、压枪、换弹
- **强调反应速度 + 战术意识**

## 三、子类型详解

### 1. 军事写实 FPS / Military Shooter
模拟现代/历史战争，强调真实武器与战术。
- **代表作**：
  - **使命召唤 / Call of Duty**（年货系列）
  - **战地 / Battlefield**（载具大战场）
  - **彩虹六号：围攻 / Rainbow Six Siege**（破坏 + 战术）
  - **武装突袭 / Arma 3**（硬核拟真）
  - **逃离塔科夫 / Escape from Tarkov**（撤离类硬核）

### 2. 竞技 FPS / Competitive / Tactical Shooter
强调电竞对抗，5v5 战术对枪。
- **代表作**：
  - **CS:GO / CS2 / Counter-Strike**（FPS电竞之神）
  - **Valorant / 无畏契约**（CS + 技能）
  - **Apex 英雄**（大逃杀 + 英雄）

### 3. 英雄射击 / Hero Shooter
角色拥有**独特技能**，团队配合为核心。
- **代表作**：
  - **守望先锋 / Overwatch 1 & 2**（英雄射击鼻祖之一）
  - **Valorant**（兼具竞技与英雄属性）
  - **Apex 英雄 / Apex Legends**
  - **漫威争锋 / Marvel Rivals**（2024 新作）

### 4. 大逃杀 / Battle Royale (BR)
百人乱斗，安全区缩圈，最后一人/队胜利。
- **代表作**：
  - **绝地求生 / PUBG**（开创现代BR）
  - **堡垒之夜 / Fortnite**（建造 + 射击）
  - **Apex 英雄**
  - **使命召唤：战区 / COD: Warzone**

### 5. 复古爽快 FPS / Boomer Shooter / Retro FPS
回归 90 年代风格，**高速移动 + 大量敌人 + 重金属配乐**。
- **代表作**：
  - **DOOM（2016）/ DOOM Eternal**（现代化复古）
  - **Wolfenstein 系列 / 德军总部**
  - **Ultrakill**（高速爽快FPS新作）
  - **Dusk**、**Amid Evil**（独立复古FPS）

### 6. 剧情向 FPS / Narrative FPS
单人剧情驱动，电影化叙事。
- **代表作**：
  - **半衰期系列 / Half-Life**（叙事FPS鼻祖）
  - **生化奇兵 / BioShock**（艺术性FPS）
  - **泰坦陨落2 / Titanfall 2**（被低估神作）
  - **METRO / 地铁系列**（末世氛围）

### 7. 恐怖 FPS / Horror Shooter
射击 + 恐怖氛围。
- **代表作**：
  - **F.E.A.R.**（AI开创性）
  - **生化危机7/8（FPS视角）**
  - **Phasmophobia**（合作恐怖）

### 8. PVE 合作 FPS / Co-op Shooter
多人合作打AI敌人。
- **代表作**：
  - **求生之路 / Left 4 Dead 1 & 2**
  - **喋血复仇 / Back 4 Blood**
  - **绝地潜兵2 / Helldivers 2**（虽是TPS但精神同源）
  - **战锤40K：暗潮 / Darktide**

### 9. 硬核拟真 FPS / Milsim
极致拟真，无血量条/无UI。
- **代表作**：
  - **武装突袭3 / Arma 3**
  - **Squad**
  - **Hell Let Loose**
  - **逃离塔科夫 / Escape from Tarkov**

### 10. 提取撤离 / Extraction Shooter（新兴）
进入地图、收集物资、撤离保命，死亡掉落。
- **代表作**：
  - **逃离塔科夫 / Escape from Tarkov**（开创者）
  - **使命召唤：DMZ**
  - **Hunt: Showdown / 猎杀对决**
  - **The Cycle: Frontier**（已停服）

## 四、FPS 核心机制

### 1. 枪感（Gunplay）
- **后坐力（Recoil）**
- **弹道散布（Spread）**
- **TTK（Time To Kill）**：击杀所需时间
- **爆头倍率（Headshot Multiplier）**

### 2. 移动机制
- **冲刺（Sprint）**
- **滑铲（Slide）**
- **跳射（Bunny Hop）**
- **二段跳 / 钩爪**（如泰坦陨落）

### 3. 瞄准
- **腰射（Hip Fire）**
- **开镜（ADS - Aim Down Sights）**
- **狙击镜瞄准**

## 五、FPS 经典术语

| 中文 | English | 含义 |
|------|---------|------|
| 压枪 | Recoil Control | 控制后坐力 |
| 急停 | Counter-Strafe | 急停射击保证精度 |
| 预瞄 | Pre-aim | 提前瞄准敌人可能出现的位置 |
| 卡点 | Hold Angle | 卡死位置等敌人 |
| 闪身 | Peek / Shoulder Peek | 探头看视野 |
| 投掷物 | Utility | 烟雾弹/闪光弹/手雷 |
| 击杀回合 | Ace | 一回合干掉所有敌人 |
| 爆头 | Headshot | 命中头部 |
| 救人 | Clutch | 残局以少胜多 |
| 经济 | Economy | CS类游戏的金钱管理 |

#  第四章：TPS / 第三人称射击 / Third-Person Shooter

## 一、定义

**TPS（Third-Person Shooter）** 玩家在角色**身后视角**（越肩视角）进行射击战斗。

## 二、与 FPS 的核心区别

| 维度 | FPS | TPS |
|------|-----|-----|
| 视角 | 第一人称 | 第三人称越肩 |
| 沉浸感 | 强 | 较弱 |
| 角色塑造 | 难（看不到自己） | 强（看到角色动作） |
| 掩体战斗 | 弱 | 强（有掩体系统） |
| 跑酷动作 | 受限 | 丰富 |
| 视野范围 | 有限 | 更广 |

## 三、子类型

### 1. 掩体射击 / Cover Shooter
**进入掩体 → 探头射击 → 转移**为核心循环。
- **代表作**：
  - **战争机器系列 / Gears of War**（掩体射击鼻祖）
  - **神秘海域 / Uncharted**（叙事 + 掩体）
  - **古墓丽影（重启）/ Tomb Raider**

### 2. 动作射击 / Action Shooter（接上）
强调动作演出与爽快感。
- **代表作**：
  - **生化危机4 / Resident Evil 4**（越肩视角开创者）
  - **马克思·佩恩 / Max Payne**（子弹时间）
  - **战争机器 / Gears of War**
  - **战神（新）/ God of War**（含射击元素）

### 3. 大逃杀 TPS / Battle Royale TPS
TPS 视角的吃鸡。
- **代表作**：
  - **绝地求生 / PUBG**（可切第一/第三人称）
  - **堡垒之夜 / Fortnite**（主TPS）
  - **永劫无间 / Naraku: Bladepoint**（TPS + 冷兵器）

### 4. 开放世界 TPS / Open-World Shooter
大地图自由探索 + 射击。
- **代表作**：
  - **GTA V / 侠盗猎车手5**
  - **荒野大镖客2 / Red Dead Redemption 2**
  - **看门狗系列 / Watch Dogs**
  - **全境封锁 / The Division**

### 5. 刷宝射击 / Looter Shooter
射击 + RPG 装备掉落系统。
- **代表作**：
  - **无主之地系列 / Borderlands**（刷宝鼻祖）
  - **命运2 / Destiny 2**
  - **全境封锁2 / The Division 2**
  - **Outriders**

### 6. PVE 合作 TPS / Co-op TPS
多人合作向 AI 敌人开火。
- **代表作**：
  - **绝地潜兵2 / Helldivers 2**（2024 现象级）
  - **战争机器系列**（多人合作经典）
  - **战锤40K：星际战士2 / Space Marine 2**
  - **GTFO**（硬核合作）

### 7. 二次元 TPS / Anime TPS
二次元画风 + 射击玩法。
- **代表作**：
  - **绝区零 / Zenless Zone Zero**（含射击元素）

# 第三章：角色扮演游戏（RPG / Role-Playing Game）

## 章节导言

角色扮演游戏（RPG）起源于 1970 年代的桌面跑团游戏《龙与地下城（Dungeons & Dragons）》，是电子游戏中**历史最悠久、文化最深厚、子类最庞杂**的品类之一。

**RPG 的三大核心要素**：

1. **角色养成**：等级、属性、技能、装备的成长系统
2. **剧情叙事**：玩家扮演角色推进故事，做出选择
3. **世界探索**：地图、城镇、迷宫、副本

**RPG 的常见衍生要素**：回合制/即时制战斗、任务系统、对话分支、阵营声望、多结局、存档读档（SL 大法）。

由于 RPG 子类繁多，本章将**一个子类一节**逐一展开，每节包括：定义、起源、机制、代表作、流派演化、推荐入门作品。

子类目录（按出现顺序）：

- 第一节：JRPG（日式角色扮演）
- 第二节：CRPG（欧美电脑角色扮演）
- 第三节：ARPG（动作角色扮演）
- 第四节：MMORPG（大型多人在线）
- 第五节：SRPG / TRPG（策略/战棋角色扮演）
- 第六节：Roguelike RPG
- 第七节：Sandbox RPG（沙盒角色扮演）
- 第八节：Dungeon Crawler（地牢探索类）
- 第九节：Monster Taming RPG（宝可梦类）
- 第十节：Visual Novel RPG（视觉小说类）
- 第十一节：Soulslike（魂类）
- 第十二节：Looter RPG（刷宝类）

## 第一节：JRPG（日式角色扮演游戏）

### 一、定义

**JRPG（Japanese Role-Playing Game）**：以日本厂商为主导，强调**线性剧情**、**回合制或半即时战斗**、**二次元/动漫美术**、**角色驱动叙事**的角色扮演游戏。

需要注意的是，JRPG 是**风格概念**而非地理概念。即使是欧美厂商，只要符合上述风格特征，也会被归为 JRPG（如《Sea of Stars》《Chained Echoes》）。

### 二、起源与发展

**1980 年代——奠基期**

- 1986 年《勇者斗恶龙（Dragon Quest）》— 堀井雄二打造，奠定 JRPG 的基本框架：勇者打魔王、回合制战斗、世界地图、城镇与迷宫。
- 1987 年《最终幻想（Final Fantasy）》— 坂口博信开发，引入 ATB（即时回合制）、职业系统、华丽演出。
- 1987 年《女神转生》— 阿特拉斯，恶魔合体系统的鼻祖。

**1990 年代——黄金期（SFC/PS1 时代）**

- 1995 年《时空之轮（Chrono Trigger）》— 史克威尔梦之队（堀井雄二+鸟山明+坂口博信）联合打造，被誉为史上最佳 JRPG 之一。
- 1997 年《最终幻想 VII》— 3D 化里程碑，让 JRPG 走向全球。
- 1998 年《异度装甲（Xenogears）》— 高桥哲哉，深邃哲学叙事。
- 1996 年《精灵宝可梦 红/绿》— 任天堂/Game Freak，开启宝可梦帝国。

**2000 年代——转型期**

- PS2 时代百花齐放：《最终幻想 X》《王国之心》《女神异闻录 3/4》《数码恶魔传说》。
- 但同时遭遇欧美 RPG 崛起的冲击，部分作品开始向 ARPG 转型。

**2010 年代——复兴期**

- 《女神异闻录 5》（2016）以惊艳美术和都市生活模拟惊艳全球。
- 《异度神剑》系列（任天堂）开拓开放世界 JRPG。
- 独立 JRPG 兴起：《歧路旅人》《勇气默示录》。

**2020 年代——全球化**

- 《最终幻想 VII 重制版》《最终幻想 XVI》全面动作化。
- 《女神异闻录 5 皇家版》Steam 发售，全平台覆盖。
- 中小厂复古 JRPG 大量涌现。

### 三、典型机制

**1. 战斗系统**

- **纯回合制（Turn-Based）**：勇者斗恶龙、女神异闻录
- **ATB（Active Time Battle）**：最终幻想 IV~IX
- **CTB（Conditional Turn-Based）**：最终幻想 X
- **Press Turn（弱点系统）**：女神转生、女神异闻录
- **半即时**：异度神剑、最终幻想 VII 重制版

**2. 养成系统**

- **职业转职**：最终幻想 V、勇气默示录
- **技能盘**：最终幻想 X 的 Sphere Grid、最终幻想 XII 的 License Board
- **羁绊系统**：女神异闻录的 Confidant、火焰纹章的支援对话

**3. 叙事结构**

- **线性王道**：勇者打魔王，三幕剧。
- **群像剧**：每个角色有独立背景与成长弧线。
- **多周目**：N+ 周目解锁真结局（如尼尔系列）。

### 四、代表作品矩阵

| 系列 | 厂商 | 特色 |
|------|------|------|
| 勇者斗恶龙 | 史克威尔艾尼克斯 | 王道、传统、国民级 |
| 最终幻想 | 史克威尔艾尼克斯 | 视听巅峰、每代换世界观 |
| 女神异闻录 | 阿特拉斯 | 都市校园 + 异世界，社交模拟 |
| 真·女神转生 | 阿特拉斯 | 硬核、恶魔合体、世界观黑暗 |
| 异度神剑 | 任天堂/Monolith | 开放世界、宏大叙事 |
| 火焰纹章 | 任天堂 | 战棋 JRPG（详见第五节） |
| 轨迹系列 | Falcom | 文本量巨大，世界线连贯 |
| 传说系列 | 万代南梦宫 | 即时动作战斗 + 王道剧情 |
| 尼尔 | 横尾太郎/白金 | 多周目叙事、哲学主题 |
| 王国之心 | 史克威尔/迪士尼 | 迪士尼 IP 联动 |

### 五、JRPG 的争议与现状

**优点**：
- 剧情深度、人物塑造能力极强
- 配乐艺术性高（植松伸夫、下村阳子、光田康典等大师辈出）
- 美术风格独特，二次元辨识度高

**争议**：
- 部分作品节奏拖沓、过场动画过长
- 线性流程在开放世界时代显得守旧
- 与欧美 RPG 的"自由度"理念存在根本分歧

### 六、推荐入门顺序

- **新手友好**：女神异闻录 5 皇家版、最终幻想 VII 重制版、八方旅人 2
- **王道体验**：勇者斗恶龙 11 S、传说之炎之纹章
- **进阶挑战**：真·女神转生 V、异度神剑 3
- **叙事神作**：尼尔：机械纪元、时空之轮、最终幻想 X

## 第二节：CRPG（欧美电脑角色扮演游戏）

### 一、定义

**CRPG（Computer Role-Playing Game）**：起源于欧美 PC 平台，以**桌面跑团（D&D）规则**为底层逻辑，强调**高自由度**、**复杂对话系统**、**玩家选择与后果**、**深度数值规则**的角色扮演游戏。

CRPG 中的 "C" 最初指 "Computer"（与主机 RPG 区分），如今更多被理解为一种**风格标签**——即"桌游式"的欧美 RPG。

与 JRPG 的根本差异：

| 维度 | CRPG | JRPG |
|------|------|------|
| 主角 | 玩家自创/自定义 | 预设角色 |
| 剧情 | 分支多结局 | 线性王道 |
| 战斗 | 规则驱动（命中率/豁免） | 演出驱动 |
| 自由度 | 高（可杀任何 NPC） | 低（按剧情推进） |
| 美术 | 写实/暗黑奇幻 | 二次元/动漫 |
| 价值观 | 道德灰色、阵营对立 | 善恶分明、友情羁绊 |

### 二、起源与发展

**1980 年代——奠基期**

- 1981 年《巫术（Wizardry）》— 第一人称 3D 迷宫，深刻影响日本 RPG。
- 1981 年《创世纪（Ultima）》— Richard Garriott 开发，开放世界鼻祖。
- 1988 年《Pool of Radiance》— 首个官方 D&D 授权电子游戏。

**1990 年代——黄金期**

- 1997 年《辐射（Fallout）》— Interplay/黑岛工作室，后启示录世界观、SPECIAL 系统。
- 1998 年《博德之门（Baldur's Gate）》— BioWare 开发，AD&D 2 版规则，"无限引擎"开启 CRPG 黄金时代。
- 1999 年《异域镇魂曲（Planescape: Torment）》— 文本量百万字，被誉为电子游戏文学巅峰。

**2000 年代——转型与衰落**

- 2000 年《博德之门 2》— 系列巅峰。
- 2002 年《无冬之夜》— 3D 化、模组工具。
- 但 2000 年代中期，CRPG 整体走向低谷，欧美 RPG 主流转向动作化（《质量效应》《龙腾世纪》）。

**2010 年代——文艺复兴**

依靠 **Kickstarter 众筹** 重生：

- 2014 年《神界：原罪（Divinity: Original Sin）》— Larian 工作室，回合制 + 元素互动。
- 2015 年《永恒之柱（Pillars of Eternity）》— Obsidian，致敬博德之门。
- 2017 年《神界：原罪 2》— CRPG 复兴的标志性作品。
- 2017 年《永恒之柱 2：死亡之火》。

**2020 年代——主流化**

- 2023 年《博德之门 3》— Larian 开发，登顶 TGA 年度游戏，将 CRPG 推向全球主流玩家。
- 《极乐迪斯科（Disco Elysium）》以"零战斗、纯文本"重新定义 CRPG。

### 三、典型机制

**1. 战斗系统**

- **回合制（Turn-Based）**：辐射 1/2、神界原罪、博德之门 3
- **即时带暂停（RTwP, Real-Time with Pause）**：博德之门 1/2、永恒之柱、龙腾世纪起源
- **基于规则的命中判定**：D20 系统、SPECIAL、自研规则

**2. 角色构建（Character Build）**

- **种族 + 职业 + 子职业**：人类战士、精灵法师、矮人牧师……
- **属性点分配**：力量/敏捷/智力/感知……
- **天赋树/Feat**：每升一级解锁新能力
- **多重职业（Multiclass）**：主战士兼修法师

**3. 对话与选择**

- **多分支对话树**：每个回答都可能改变后续走向
- **技能检定**：说服、威吓、欺骗触发不同结果
- **阵营/声望**：影响 NPC 态度、商人价格、结局
- **杀任何人原则**：可杀光全村，游戏不会强制读档（除非主线 NPC）

**4. 叙事结构**

- **多结局**：根据玩家选择产生数个~数十个不同结局
- **同伴系统**：每个同伴有独立支线、忠诚度、可能背叛或离队
- **道德灰色**：没有绝对的善恶，每个选择都有代价

### 四、代表作品矩阵

| 系列 | 厂商 | 特色 |
|------|------|------|
| 博德之门 | BioWare → Larian | D&D 规则、CRPG 旗舰 |
| 辐射（1/2/New Vegas） | 黑岛 → Obsidian | 后启示录、SPECIAL 系统 |
| 异域镇魂曲 | 黑岛 | 文学巅峰、哲学叙事 |
| 创世纪 | Origin | 开放世界鼻祖 |
| 神界：原罪 | Larian | 元素互动、回合制 |
| 永恒之柱 | Obsidian | 致敬博德之门 |
| 暴君（Tyranny） | Obsidian | 反派视角、邪恶帝国 |
| 开拓者（Pathfinder） | Owlcat | 高自由度、规则极硬核 |
| 极乐迪斯科 | ZA/UM | 零战斗、纯文本侦探 RPG |
| 巫师系列 | CDPR | 波兰厂商、CRPG 与 ARPG 融合 |

### 五、CRPG 的特色与挑战

**优点**：
- 自由度极高，玩家真正"扮演"角色
- 文本量庞大，叙事深度无可比拟
- 重玩价值高，多周目体验完全不同
- 模组生态发达（Nexus Mods、Steam 创意工坊）

**挑战**：
- 入门门槛高，规则复杂
- 文本量对非英语玩家不友好（汉化质量参差）
- 战斗节奏可能偏慢
- 美术风格偏写实/暗黑，对二次元玩家吸引力有限

### 六、CRPG 的两大流派

**1. 桌游派（D&D 规则系）**
- 博德之门系列、无冬之夜、开拓者
- 严格遵循 D&D / Pathfinder 规则书
- 骰子、豁免、AC、THAC0 等术语密集

**2. 自研规则派**
- 辐射（SPECIAL）、永恒之柱、神界：原罪
- 不依赖 D&D，自创战斗与成长体系
- 更易入门，但深度不减

### 七、推荐入门顺序

- **零基础友好**：博德之门 3（2023 年最现代化的 CRPG）
- **回合制入门**：神界：原罪 2
- **文学体验**：极乐迪斯科、异域镇魂曲（增强版）
- **后启示录**：辐射：新维加斯
- **硬核挑战**：开拓者：正义之怒、永恒之柱 2

## 第三节：ARPG（动作角色扮演游戏）

### 一、定义

**ARPG（Action Role-Playing Game）**：将**即时动作战斗**与 **RPG 养成系统**融合的角色扮演游戏。玩家通过手眼协调直接操控角色进行攻击、闪避、连招，同时享受装备、等级、技能树等 RPG 要素。

ARPG 的核心区别于回合制 RPG 的特征：

- **战斗即时化**：没有"轮到我了"，攻击与闪避全靠操作
- **操作权重高**：玩家技术影响通关难度
- **打击感重要**：动画、音效、震屏等反馈成为核心体验

ARPG 是一个**极宽泛的范畴**，向下可细分为多个子流派（详见后续章节，如 Soulslike、Looter RPG、Roguelike RPG 等）。本节聚焦广义 ARPG 的整体脉络。

### 二、起源与发展

**1980 年代——萌芽期**

- 1984 年《Dragon Slayer》— 日本 Falcom，被认为是 ARPG 鼻祖。
- 1986 年《塞尔达传说》— 任天堂宫本茂，将动作冒险与 RPG 要素结合（虽然塞尔达是否算 RPG 至今有争议）。
- 1987 年《伊苏（Ys）》— Falcom，"撞击式"战斗，开启日式 ARPG 流派。

**1990 年代——分化期**

- 1996 年《暗黑破坏神（Diablo）》— 暴雪，开创"点击式 ARPG"与"刷宝循环"，影响深远。
- 1997 年《圣剑传说：传奇》— 史克威尔，类塞尔达 ARPG。
- 1998 年《塞尔达传说：时之笛》— 3D 动作冒险标杆。

**2000 年代——主机化**

- 2000 年《暗黑破坏神 II》— 暗黑系列巅峰，刷宝模板被业界沿用至今。
- 2001 年《鬼武者》《忍者龙剑传》等动作 RPG 涌现。
- 2009 年《恶魔之魂（Demon's Souls）》— FromSoftware，魂系列起点，开启 Soulslike 流派。

**2010 年代——百花齐放**

- 2011 年《黑暗之魂》《上古卷轴 V：天际》— 两种截然不同的 ARPG 风格并立。
- 2012 年《暗黑破坏神 III》、2013 年《流放之路（Path of Exile）》— 刷宝 ARPG 双雄。
- 2015 年《血源诅咒》、2017 年《尼尔：机械纪元》— 动作 RPG 艺术性巅峰。
- 2017 年《塞尔达传说：旷野之息》— 重新定义开放世界 ARPG。

**2020 年代——全球化与中国崛起**

- 2022 年《艾尔登法环》— FromSoftware 集大成之作，TGA 年度游戏。
- 2020 年《原神》— 米哈游，开放世界 ARPG + 抽卡，全球现象级。
- 2024 年《黑神话：悟空》— 国产 3A ARPG 里程碑。
- 2024 年《艾尔登法环：黄金树幽影》、2024 年《暗黑破坏神 IV》资料片。

### 三、典型机制

**1. 战斗系统**

- **点击式（Click-to-Move）**：暗黑破坏神、流放之路、火炬之光
- **第三人称动作**：黑暗之魂、鬼泣、战神
- **第一人称动作**：上古卷轴、辐射 4、赛博朋克 2077
- **类塞尔达**：旷野之息、神界轮回
- **格斗式连招**：鬼泣、猎天使魔女（动作 > RPG）

**2. 养成系统**

- **等级 + 属性点**：力敏体智，自由分配
- **技能树/天赋**：流放之路的"天赋大盘"是极致代表
- **装备词条**：基础属性 + 随机词条（核心驱动力之一）
- **符文/宝石/镶嵌**：进一步定制装备

**3. 装备与战利品（Loot）**

- **品质分层**：白→蓝→紫→金→暗金（橙）→ 神话
- **随机词条**：同一件装备每次掉落属性都不同
- **套装效果**：集齐多件触发额外加成
- **赛季制**：流放之路、暗黑 IV 的核心运营模式

### 四、ARPG 的主要分支

ARPG 是一个超大的伞形分类，下属多个子流派（部分将在后续章节单独展开）：

| 子分支 | 代表作 | 核心特征 |
|------|------|------|
| 类暗黑（Diablo-like） | 暗黑破坏神、流放之路、火炬之光 | 俯视角、点击式、刷宝 |
| Soulslike（魂类） | 黑暗之魂、艾尔登法环、只狼 | 高难度、精确操作、世界观碎片化 |
| 开放世界 ARPG | 巫师 3、上古卷轴 V、旷野之息 | 大地图、自由探索、支线丰富 |
| 类塞尔达（Zelda-like） | 旷野之息、空洞骑士、Tunic | 动作冒险 + 解谜 |
| 二次元 ARPG | 原神、崩坏：星穹铁道、鸣潮 | 角色驱动、抽卡、长线运营 |
| 国产 ARPG | 黑神话：悟空、永劫无间 | 中式美学、3A 制作 |
| 类银河战士恶魔城 ARPG | 空洞骑士、奥日 | 2D 探索 + 解锁能力 |

### 五、欧美 ARPG vs 日式 ARPG

**欧美派（Western ARPG）**：
- 强调自由度、开放世界、玩家选择
- 代表：上古卷轴、巫师、暗黑破坏神、流放之路
- 战斗偏写实、硬派、沉重

**日式派（Japanese ARPG）**：
- 强调演出、角色塑造、连招华丽度
- 代表：尼尔、最终幻想 XVI、伊苏、传说系列
- 战斗偏华丽、爽快、空中连击

**新兴派（中式 ARPG）**：
- 二次元开放世界（米哈游模式）+ 3A 单机（黑神话模式）
- 代表：原神、绝区零、黑神话：悟空、鸣潮

### 六、ARPG 的核心魅力

**1. 即时反馈**：每一次攻击、闪避、暴击都直接由玩家操作触发，沉浸感极强。

**2. 成长可视化**：角色从赤手空拳到一身神装，外观可见的强大。

**3. 重玩价值**：多周目、多职业、多 Build，永远有新玩法。

**4. 长线运营**：刷宝、赛季、新职业，可玩数百小时。

### 七、推荐入门顺序

- **新手友好**：暗黑破坏神 IV、原神、塞尔达传说：旷野之息
- **王道体验**：巫师 3：狂猎、上古卷轴 V：天际
- **动作进阶**：尼尔：机械纪元、最终幻想 XVI
- **硬核挑战**：艾尔登法环、黑神话：悟空、流放之路
- **国风首选**：黑神话：悟空、永劫无间

### 八、ARPG 与其他类别的边界争议

ARPG 是一个**边界模糊**的标签，常见争议：

- **塞尔达系列**算 ARPG 还是动作冒险？（任天堂自己定位为"动作冒险"，但学界多归为 ARPG）
- **怪物猎人**算 ARPG 还是狩猎动作？（核心是动作 + 装备，多归为狩猎类 ARPG）
- **战神（2018 后）** 算 ARPG 还是动作冒险？（加入了技能树和装备词条后被归为 ARPG）
- **艾尔登法环**算 ARPG 还是 Soulslike？（Soulslike 是 ARPG 的子集）

**结论**：只要满足"即时动作战斗 + 角色养成"两要素，即可归入 ARPG 大类，再按具体特征细分子流派。

## 第四节：MMORPG（大型多人在线角色扮演游戏）

### 一、定义

**MMORPG（Massively Multiplayer Online Role-Playing Game）**：通过互联网连接，**成千上万名玩家在同一持久世界**中同时游戏的角色扮演游戏。世界 24 小时持续运行，即使玩家下线，世界依然在演变。

MMORPG 的四大核心特征：

1. **大规模（Massive）**：单服承载数千乃至数万玩家
2. **多人（Multiplayer）**：社交、组队、公会是核心驱动力
3. **在线（Online）**：必须联网，无单机模式
4. **持久世界（Persistent World）**：世界状态长期保留，玩家下线后世界继续运行

### 二、起源与发展

**1980 年代——文字 MUD 时代**

- 1978 年《MUD1》— 英国 Essex 大学，世界第一个多人在线文字冒险游戏，MMORPG 的精神鼻祖。
- 1980 年代 MUD（Multi-User Dungeon）在大学网络盛行。

**1990 年代——图形化萌芽**

- 1991 年《Neverwinter Nights》(AOL 版) — 第一款图形化 MMORPG。
- 1996 年《子午线 59（Meridian 59）》— 首款 3D MMORPG。
- 1997 年《网络创世纪（Ultima Online）》— Richard Garriott 开发，确立现代 MMORPG 框架（公会、PK、经济系统）。
- 1999 年《无尽的任务（EverQuest）》— 3D MMORPG 标杆，"EQ 模式"成为后世模板。

**2000 年代——黄金时代**

- 2001 年《暗黑之光》《传奇》— 韩国 MMORPG 在亚洲爆发。
- 2002 年《石器时代》《魔力宝贝》— 日式 MMORPG 风潮。
- 2003 年《最终幻想 XI》— 史克威尔首部 MMO，跨平台联机。
- **2004 年《魔兽世界（World of Warcraft）》— 暴雪发布，全球玩家峰值 1200 万，定义了现代 MMORPG。**
- 2005 年《魔域》《完美世界》— 国产 MMO 兴起。
- 2008 年《永恒之塔》《地下城与勇士（DNF）》。

**2010 年代——分化与衰退**

- 2010 年《最终幻想 XIV》初版失败，2013 年《重生之境》强势复活。
- 2011 年《星球大战：旧共和国》— BioWare 的 MMO 尝试。
- 2012 年《激战 2》— 取消传统任务模式，引入"动态事件"。
- 2014 年《剑灵》《黑色沙漠》— 韩式动作 MMO 兴起。
- 2015 年后 MMORPG 整体衰退，玩家被 MOBA、吃鸡、手游分流。

**2020 年代——分化与新尝试**

- 2021 年《新世界（New World）》— 亚马逊出品，褒贬不一。
- 2024 年《魔兽世界：地心之战》、《最终幻想 XIV：黄金的遗产》— 经典 MMO 仍在延续。
- 2024 年《throne and liberty》— NCsoft 新作。
- **现状**：传统订阅制 MMO 萎缩，但《FF14》《魔兽世界》仍是行业支柱；中国 MMO 主流转向手游（如《剑网 3》《逆水寒手游》）。

### 三、典型机制

**1. 角色系统**
- **种族 + 职业**：人类战士、精灵法师、兽人萨满……
- **职业三元论**：坦克（T）/ 治疗（奶）/ 输出（DPS）— 团队副本核心
- **天赋分支**：同一职业可走不同路线（如战士的防御/狂暴）

**2. 内容循环（Endgame Loop）**
- **日常任务**：每日重置的固定任务
- **副本（Dungeon）**：5 人小队挑战
- **团本（Raid）**：10~40 人协作挑战 BOSS
- **PVP**：战场、竞技场、世界 PK
- **声望/阵营**：累积声望解锁奖励

**3. 经济系统**
- **拍卖行/交易所**：玩家间自由交易
- **专业技能**：采矿、锻造、炼金、烹饪……
- **货币体系**：金币、绑定货币、点数代币
- **拾取规则**：BOP（绑定）/ BOE（可交易）

**4. 社交系统**
- **公会（Guild/Clan）**：长期组织，公会战、公会副本
- **组队**：临时小队推图
- **跨服匹配**：现代 MMO 的标配
- **结婚、师徒**：东方 MMO 特色

### 四、MMORPG 的两大流派

**1. 西方 MMORPG（W-MMO）**

- **代表**：魔兽世界、最终幻想 XIV、激战 2、星战旧共和国
- **特点**：
  - 任务驱动，剧情与世界观厚重
  - 副本/团本是核心 Endgame
  - 月卡或买断制为主
  - 公平竞技，反对付费碾压

**2. 东方 MMORPG（K-MMO / C-MMO）**

- **代表**：天堂、传奇、剑网 3、逆水寒、黑色沙漠
- **特点**：
  - 升级 + 装备强化是核心
  - 强 PK、攻城战、爆装备
  - 免费游玩 + 商城付费（F2P + Cash Shop）
  - 数值膨胀快，"VIP"特权常见

### 五、代表作品矩阵

| 游戏 | 厂商 | 上线年 | 特色 |
|------|------|------|------|
| 网络创世纪 | Origin | 1997 | MMO 鼻祖 |
| 无尽的任务 | Sony Online | 1999 | 3D MMO 模板 |
| 魔兽世界 | Blizzard | 2004 | 全球最成功 MMO |
| 最终幻想 XIV | Square Enix | 2010/2013 | 剧情驱动巅峰 |
| 激战 2 | ArenaNet | 2012 | 动态事件、买断制 |
| 黑色沙漠 | Pearl Abyss | 2014 | 动作战斗 + 美术巅峰 |
| 剑网 3 | 西山居 | 2009 | 国产武侠 MMO 旗舰 |
| 逆水寒 | 网易 | 2018/手游2023 | 国产高品质 MMO |
| 最终幻想 XI | Square Enix | 2002 | 跨平台 MMO 先驱 |
| 新世界 | Amazon | 2021 | 亚马逊首部 MMO |

### 六、商业模式演变

| 模式 | 代表 | 特点 |
|------|------|------|
| 月卡（订阅制） | 魔兽世界、FF14 | 每月固定费用，公平 |
| 买断制 | 激战 2 | 一次付费永久游玩 |
| F2P + 商城 | 大多数韩式/国产 MMO | 免费下载，时装/便利道具付费 |
| F2P + Pay to Win | 部分东方 MMO | 数值付费，备受争议 |
| 免费试玩 + 升级订阅 | FF14 试玩版 | 免费体验前期内容 |

### 七、MMORPG 的兴衰原因

**鼎盛原因（2004-2010）**：
- 互联网普及 + 宽带降价
- 社交需求强烈，游戏即第二人生
- 没有强力替代品

**衰退原因（2015 后）**：
- 手游崛起，碎片化时间侵占
- MOBA、吃鸡、自走棋等更轻量化的多人体验
- MMO 投入产出比低，新作开发风险大
- 老 MMO 数值积累过深，新人门槛过高
- 单机/合作游戏体验更强

**当下定位**：
- 传统 MMO 进入"长寿守成"阶段，靠老玩家与版本更新维持
- 新方向：MMO + 沙盒（New World）、MMO + 动作（黑色沙漠）、MMO + 手游化（逆水寒手游）

### 八、MMORPG 的核心魅力

**1. 第二人生**：在虚拟世界拥有身份、朋友、成就。

**2. 长线成长**：可玩数年甚至十数年，角色伴随玩家成长。

**3. 社交粘性**：公会、战友、师徒——人才是 MMO 最重要的内容。

**4. 集体史诗**：40 人团本通关、跨服战场、世界首杀，独属 MMO 的体验。

### 九、推荐入门顺序

- **新手友好（剧情向）**：最终幻想 XIV（免费试玩到 60 级）
- **经典体验**：魔兽世界（怀旧服或正式服）
- **买断无月卡**：激战 2
- **国产武侠**：剑网 3、逆水寒手游
- **动作派**：黑色沙漠、剑灵
- **沙盒派**：新世界、上古卷轴 OL

### 十、MMORPG 与其他多人 RPG 的区别

| 类型 | 同时在线 | 持久世界 | 代表 |
|------|------|------|------|
| MMORPG | 数千~数万 | ✅ | 魔兽世界、FF14 |
| Co-op RPG | 2-4 人 | ❌ | 神界：原罪、博德之门 3 |
| 网游 RPG（小型） | 数十人/服 | 部分 | 暗黑破坏神 IV、命运 2 |
| 沙盒生存 | 数十~百人/服 | ✅ | 方舟、Rust |

**关键区分点**：MMORPG 必须同时具备"大规模"+"持久世界"+"RPG 养成"三要素。

## 第五节：SRPG / TRPG（策略/战棋角色扮演游戏）

### 一、定义

**SRPG（Strategy Role-Playing Game）/ TRPG（Tactical Role-Playing Game）**：将**回合制策略战棋**与 **RPG 角色养成**融合的游戏类型。玩家在网格化战场上指挥多名角色，通过地形、站位、技能搭配取得胜利。

> **术语辨析**：
> - 在日本，"SRPG"（シミュレーションRPG）是主流叫法，泛指战棋 RPG
> - 在欧美，"TRPG"（Tactical RPG）更常用，"TRPG"在中文语境也常指"桌面 RPG（Tabletop RPG）"，需根据上下文判断
> - 本节"TRPG"特指**战术角色扮演游戏**，桌面 RPG 将在后续单独章节讨论

### 二、核心特征

1. **网格化战场**：方格（Square）或六边形（Hex）地图
2. **回合制行动**：双方/多方轮流行动，每个角色有行动力
3. **数值与策略并重**：等级、装备重要，但站位、地形、属性克制同样关键
4. **小队作战**：通常 4~12 名可控角色组成队伍
5. **永久死亡（Permadeath）**：部分作品中角色死亡不可复活（火纹经典传统）

### 三、起源与发展

**1980 年代——起源**

- 1988 年《梦幻模拟战（Master of Monsters）》— SystemSoft，日式 SRPG 雏形。
- 1989 年《梦幻之星 II》战斗已有战棋雏形。
- 1990 年《火焰之纹章：暗黑龙与光之剑》— 任天堂/Intelligent Systems，**确立 SRPG 的现代框架**。

**1990 年代——黄金时代**

- 1991 年《皇家骑士团》— Quest 出品，剧情厚重的硬派 SRPG。
- 1993 年《梦幻模拟战 II》— Masaya，被誉为 SRPG 巅峰之一。
- 1995 年《机器人大战》系列爆发 — Banpresto 跨界融合。
- 1995 年《超级机器人大战 F》、1996 年《皇家骑士团：命运之轮》。
- 1997 年《最终幻想战略版（FFT）》— 松野泰己作品，剧情与系统神作。
- 1999 年《伊苏 V》、《风花雪月》前身《圣战之系谱》。

**2000 年代——多元化**

- 2003 年《火焰之纹章：烈火之剑》— GBA 三部曲，欧美打开火纹市场。
- 2003 年《魔界战记（Disgaea）》— 日本一软件，等级 9999、伤害千万，"数值爆破"流派代表。
- 2004 年《战场女武神（Valkyria Chronicles）》前身、2005 年《战略三国志》。
- 2007 年《幻想战记：刚铁之华》。
- 2008 年《战场女武神》— SEGA，BLiTZ 半即时战棋系统，PS3 名作。

**2010 年代——复兴期**

- 2010 年《XCOM: Enemy Unknown》— Firaxis，西方战棋复兴里程碑。
- 2013 年《火焰之纹章：觉醒》— 拯救火纹系列，引入婚姻/子代系统。
- 2015 年《XCOM 2》— 续作进一步完善。
- 2017 年《火焰之纹章 Echoes》、2019 年《火焰之纹章：风花雪月》— SRPG 全球大火。
- 2018 年《战意》《战场女武神 4》。

**2020 年代——黄金复兴**

- 2020 年《三角战略（Triangle Strategy）》— 史克威尔 HD-2D 名作。
- 2022 年《火焰之纹章 Engage》、2022 年《歧路旅人 2》。
- 2023 年《圣兽之王（Unicorn Overlord）》— Vanillaware，即时战棋创新。
- 2024 年《奥秘 33》《Tactics Ogre Reborn》。
- 中国独立游戏：《天命奇御》《部落与弯刀》。

### 四、典型机制

**1. 战场系统**
- **方格 vs 六边形**：方格更直观（火纹），六边形机动性更强（XCOM 用方格但视野是锥形）
- **地形效果**：森林+回避、山地+防御、河流减速
- **高低差**：高地射程加成、骑兵无法上山
- **天气系统**：雨雪影响命中和移动

**2. 角色与职业**
- **职业转职树**：剑士 → 勇者 / 剑圣，FFT 的"系统"是经典代表
- **属性相克**：剑克斧、斧克枪、枪克剑（武器三角，火纹经典）
- **属性元素**：火/水/风/土/光/暗
- **兵种相克**：步兵、骑兵、飞兵、装甲，互有克制

**3. 战斗机制**
- **命中率/暴击率**：随机性核心，"99% 必中"成为玩家梗
- **行动力（AP/CT）**：有的按回合（火纹），有的按速度排序（FFT）
- **支援系统**：相邻角色加成、合击、护卫
- **永久死亡**：角色阵亡不可复活（火纹经典/古典模式）

**4. 养成系统**
- **等级 + 经验**：杀敌升级
- **武器熟练度**：剑用得多剑等级高（FE/FFT）
- **支援对话**：角色间好感度提升解锁剧情和加成
- **装备/技能学习**：FFT 的"工作系统"代表，技能可跨职业带

### 八、SRPG 的核心魅力

**1. 棋盘上的智斗**：每一步都需深思熟虑，胜利来自策略而非反应。

**2. 角色羁绊**：长期培养的角色一旦阵亡（永久死亡），痛彻心扉。

**3. 养成深度**：转职、技能、装备搭配，组队思考乐趣无穷。

**4. 剧情承载**：相比 ARPG，SRPG 节奏更慢，更适合厚重叙事。

### 九、SRPG 的挑战与现状

**面临挑战**：
- 节奏慢，不适合手游碎片化
- 学习曲线陡，新人门槛高
- 全球市场较小众

**现状**：
- 任系（火纹）、史克威尔（FFT 系列、三角战略）、日本一（魔界）三足鼎立
- XCOM 系列代表西式力量
- 独立游戏领域涌现创新（Into the Breach、Wargroove、Songs of Conquest）
- 手游市场：《明日方舟》《钢岚》等"塔防/战棋手游"算 SRPG 变种

### 十、推荐入门顺序

- **新手友好**：火焰之纹章：风花雪月、三角战略
- **剧情向**：最终幻想战略版：狮子战争、皇家骑士团：重生
- **数值狂欢**：魔界战记 6
- **西式硬核**：XCOM 2、Into the Breach
- **画面派**：战场女武神 4、圣兽之王
- **粉丝向**：超级机器人大战 30（需熟悉机战 IP）

### 十一、SRPG 与相邻类型的边界

| 类型 | 战棋元素 | RPG 养成 | 代表 |
|------|------|------|------|
| SRPG | ✅ 核心 | ✅ 核心 | 火纹、FFT |

## 第六节：Roguelike / Roguelite（肉鸽 / 类肉鸽）

### 一、定义

**Roguelike**：一种以**随机生成、永久死亡、回合制探索**为核心的地牢冒险游戏类型，得名于 1980 年的游戏《Rogue》。

**Roguelite（类肉鸽 / 轻度肉鸽）**：保留 Roguelike 部分核心特征（随机生成、死亡惩罚），但加入**跨周目继承元素**（永久解锁、成长保留），降低硬核程度的衍生类型。

> **术语辨析**：
> - 严格意义的 Roguelike 由 2008 年"柏林诠释（Berlin Interpretation）"定义
> - 现代玩家口中的"肉鸽游戏"绝大多数是 Roguelite
> - 中文"肉鸽"是 Rogue 的音译梗

### 二、柏林诠释——经典 Roguelike 的八大核心要素

2008 年国际 Roguelike 开发者大会确立的定义标准：

**高价值要素（必备）**：
1. **随机生成环境（Random Environment）**：每次游戏地图、敌人、物品随机
2. **永久死亡（Permadeath）**：角色死亡后存档删除，从头再来
3. **回合制（Turn-based）**：玩家与敌人轮流行动
4. **网格化移动（Grid-based）**：方格地图，按格移动
5. **非模态（Non-modal）**：战斗、探索、菜单等都在同一界面，无切换
6. **复杂度（Complexity）**：多种解决方案应对同一问题
7. **资源管理（Resource Management）**：食物、药水、法力有限
8. **打怪推图（Hack'n'Slash）**：以战斗为主要交互

**低价值要素（加分项）**：
9. ASCII 字符画面
10. 地下城探索
11. 数值与属性系统

满足越多 → 越"硬核 Roguelike"；只满足部分 → "Roguelite"或"Rogue-like-like"。

### 三、起源与发展

**1980 年代——洞穴年代**

- 1980 年《Rogue》— Michael Toy 等人开发，UNIX 平台 ASCII 字符地牢冒险，**类型奠基者**。
- 1985 年《Hack》→ 1987 年《NetHack》— 开源接力，深度恐怖。
- 1987 年《Moria》— 基于《魔戒》摩瑞亚矿坑。
- 1990 年《Angband》— 基于 Moria 衍生，沿用至今。

**1990 年代——硬核传承**

- 1994 年《ADOM（Ancient Domains of Mystery）》— 德国开发者 Thomas Biskup，至今仍在更新。
- 1995 年《Linley's Dungeon Crawl》→ 后演化为《Dungeon Crawl Stone Soup》。
- 这一时期的 Roguelike 几乎全是"程序员的游戏"，玩家小众。

**2000 年代——破圈尝试**

- 2002 年《矮人要塞（Dwarf Fortress）》开发开始 — Tarn Adams 兄弟，模拟深度封神。
- 2008 年柏林诠释发布，类型获得正式定义。
- 2008 年《Spelunky》— Derek Yu，**将 Roguelike 与平台跳跃融合，开启 Roguelite 时代**。

**2010 年代——大爆发**

- 2011 年《以撒的结合（The Binding of Isaac）》— Edmund McMillen，引爆 Roguelite 潮流。
- 2012 年《FTL: Faster Than Light》— 太空 Roguelite，剧情驱动。
- 2013 年《盗贼遗产（Rogue Legacy）》— 跨周目继承的代表作。
- 2014 年《以撒的重生》、《Crypt of the NecroDancer》— 节奏 + Roguelite。
- 2017 年《杀戮尖塔（Slay the Spire）》— **卡牌 + Roguelite，开创新分支**。
- 2018 年《死亡细胞（Dead Cells）》— 类银河战士恶魔城 + Roguelite。
- 2019 年《盐与避难所》、《Risk of Rain 2》。

**2020 年代——黄金时代**

- 2020 年《哈迪斯（Hades）》— Supergiant，**Roguelite + 剧情驱动**，TGA 提名年度游戏。
- 2021 年《吸血鬼幸存者（Vampire Survivors）》— 引爆"幸存者类（Survivor-like）"新分支。
- 2022 年《迷雾侦探》《Cult of the Lamb》《Backpack Hero》。
- 2023 年《邪恶冥刻（Inscryption）》、《小骨：英雄杀手》。
- 2024 年《哈迪斯 II》《Balatro（小丑牌）》— 卡牌肉鸽再创神话。
- 2025 年仍是 Roguelite 占据 Steam 独立游戏榜最大份额的年代。

### 四、核心机制详解

**1. 随机生成（Procedural Generation）**
- 地图随机：房间布局、走廊连接
- 物品随机：每局武器、道具不同
- 事件随机：商人、宝箱、精英怪
- 词条随机：装备属性组合

**2. 永久死亡（Permadeath）**
- **硬核派**：死亡=存档删除（NetHack）
- **软性派**：死亡保留部分进度（Hades 死后增加镜灵）
- **挑战派**：可选硬核模式（杀戮尖塔的"心脏"模式）

**3. 跨周目成长（Meta-progression）—— Roguelite 关键**
- 永久解锁新角色、新武器、新事件
- 提升基础属性（生命、攻击力）
- 解锁新的 BD（Build）可能性
- "失败=变强"的正反馈循环

**4. Build 构筑（流派搭建）**
- 角色固有差异
- 道具协同效应（Synergy）
- 随机奖励组合出意外强力流派
- "成型刻"是肉鸽玩家的快感顶点

### 五、Roguelike vs Roguelite 对比

### 八、Roguelike/lite 的核心魅力

**1. 高重玩性**：每局体验不同，几百小时不重复。

**2. Build 创造快感**：偶遇神级 Combo，亲手缔造"毕业 Build"的满足。

**3. 失败的意义**：每次死亡都在变强（meta progression）或变聪明（玩家技术）。

**4. 短局制**：单局 30~60 分钟，适合碎片时间。

**5. 高性价比**：通常售价低，时长长。

### 九、为何 Roguelite 在 2010s-2020s 大爆发？

**开发端**：
- 程序生成大幅降低关卡设计成本
- 适合独立工作室小团队开发
- 同样的素材可玩 100 小时

**玩家端**：
- 短局制契合现代生活节奏
- 重玩性高，性价比极高
- 直播友好（每局都是新内容）
- "再来一把"的成瘾循环

**市场端**：
- Steam/Switch 独立游戏渠道成熟
- 玩家对 3A 长篇游戏疲劳
- 直播/短视频时代的天然内容素材

### 十、推荐入门顺序

- **入门首选**：哈迪斯（剧情友好 + 动作爽快）
- **卡牌入门**：杀戮尖塔、Balatro（小丑牌）
- **平台动作**：死亡细胞、Spelunky 2
- **弹幕射击**：以撒的结合：忏悔、挺进地牢
- **休闲解压**：吸血鬼幸存者、20 分钟到黎明
- **策略派**：Into the Breach、FTL
- **硬核挑战**：Dungeon Crawl Stone Soup、ADOM、矮人要塞
- **3A 体验**：Returnal、哈迪斯 II

## 第七节：Sandbox RPG（沙盒角色扮演类）

### 一、定义

**Sandbox RPG（沙盒 RPG）**：将 RPG 的角色养成、剧情系统与沙盒的高自由度、开放世界、玩家驱动结合的复合类型。玩家不再被线性主线推着走，而是**在一个充满系统交互的活世界里，自己决定"我要成为谁、做什么"**。

> **核心信条**："世界不是为你准备的舞台，而是一个你恰好出现在其中的运转系统。"

### 二、核心特征

1. **开放世界**：无强制路线，地图大部分区域开局即可抵达
2. **角色养成**：等级、技能、属性、装备等 RPG 底层系统完整保留
3. **涌现式叙事（Emergent Narrative）**：故事来自系统交互而非编剧预设
4. **多解性**：同一个任务可以战斗、潜行、说服、贿赂、绕过……
5. **世界模拟**：NPC 有作息、阵营有关系、生态有链条
6. **玩家自定义目标**：可以当英雄、商人、小偷、法师、农夫、连环杀手
7. **后果系统**：选择影响声望、阵营、世界状态

### 三、与相邻类型的区别

| 类型 | 自由度 | RPG 系统 | 主线强度 | 代表 |
|------|------|------|------|------|
| **Sandbox RPG** | 极高 | 完整 | 弱/可忽略 | 上古卷轴、哥特王朝 |
| 开放世界 ARPG | 高 | 完整 | 强 | 巫师 3、艾尔登法环 |
| 线性 RPG | 低 | 完整 | 极强 | 最终幻想 10、巫师 2 |
| 纯沙盒 | 极高 | 弱/无 | 无 | 我的世界、泰拉瑞亚 |
| 模拟生活 | 中 | 弱 | 无 | 模拟人生、星露谷 |

**关键区分**：Sandbox RPG = **"沙盒的自由 + RPG 的深度系统"**，缺一不可。《巫师 3》虽然是开放世界 RPG，但主线叙事极强、玩家身份固定为杰洛特，所以更偏 **叙事驱动开放世界 RPG**，而非真正的 Sandbox RPG。

### 四、发展简史

**起源（1980s–1990s）**：
- **《创世纪（Ultima）》系列**（1981 起）：Richard Garriott 缔造，尤其《创世纪 7》被誉为"第一个真正的沙盒 RPG"——NPC 有完整作息、可烤面包、可偷东西
- **《Daggerfall》**（1996）：上古卷轴 2，地图面积约 16 万平方公里，至今仍是史上最大 RPG 地图之一

**奠基（2000s）**：
- **《上古卷轴 3：晨风》**（2002）：将沙盒 RPG 带入 3D 时代，世界观与自由度的双重突破
- **《哥特王朝（Gothic）》系列**（2001 起）：德系硬核沙盒 RPG，阵营选择真正改变玩法
- **《上古卷轴 4：湮没》**（2006）：Radiant AI 系统让 NPC 拥有动态行为

**黄金期（2010s）**：
- **《上古卷轴 5：天际》**（2011）：沙盒 RPG 的代名词，"再玩亿遍"的 MOD 永生作
- **《辐射 3 / 新维加斯 / 4》**：废土版天际，新维加斯的多结局阵营系统至今封神
- **《神界：原罪 2》**（2017）：回合制沙盒 RPG，环境互动与多解任务的天花板

**新时代（2020s）**：
- **《博德之门 3》**（2023）：将 CRPG 沙盒哲学推向主流，"任何东西都可以拿、扔、说话、杀"
- **《王国之泪》**（2023）：用物理系统重新定义"沙盒"在动作 RPG 里的可能
- **《天外世界》《赛博朋克 2077》**：不同程度地继承传统

### 五、核心系统设计

**1. 世界设计**
- 无缝大地图 vs 分区加载
- 兴趣点（POI）密度
- 垂直空间利用
- 环境叙事（environmental storytelling）

**2. NPC 与 AI**
- 作息系统（Schedule）
- 派系关系（Faction）
- 动态对话与反应
- Radiant 任务生成

**3. 任务系统**
- 多路径解法
- 道德灰色地带
- 蝴蝶效应式后果
- 失败也是结果（任务可以"搞砸"而非读档）

**4. 角色系统**
- 属性 + 技能双轨（如辐射的 SPECIAL + Skills）
- 无职业限制（天际：你用什么就强什么）
- Perk / 天赋树
- 声望 / 业力系统

**5. 交互系统**
- 物品可拾取/可放置
- 可偷窃/可击杀任意 NPC
- 物理与魔法环境互动
- 制作、附魔、炼金

### 六、设计哲学

**Bethesda 学派（美式沙盒）**：
- "Go anywhere, do anything"
- 广度优先，深度其次
- 玩家自由 > 叙事控制
- 代表：上古卷轴、辐射

**Larian / Obsidian 学派（CRPG 沙盒）**：
- 系统深度优先
- 任何系统都可被玩家利用/打破
- 强调"如果我能想到，游戏就该允许"
- 代表：神界原罪、博德之门 3、新维加斯

**Piranha Bytes 学派（德式硬核沙盒）**：
- 世界不为玩家服务
- 阵营选择不可逆
- 难度即沉浸
- 代表：哥特王朝、Risen、Elex

### 七、涌现式叙事的魅力

Sandbox RPG 最迷人之处在于**玩家自己创造的故事**：

- 天际玩家："我本来要去屠龙，结果被一只兔子带跑了 200 小时"
- 新维加斯玩家："我用一颗手雷解决了主线 BOSS"
- 博德之门 3 玩家："我把那个 NPC 推下悬崖，跳过了整章剧情"
- 模拟矿工（Dwarf Fortress）："Losing is fun"

这种**"游戏没设计，但允许发生"**的故事，是线性游戏永远无法提供的。

### 八、技术挑战

1. **世界规模 vs 内容密度**：地图大但空洞 = 罐头
2. **AI 行为可信度**：NPC 不能像木偶
3. **任务复杂度爆炸**：多解 = N 倍工作量
4. **Bug 数量**：自由度越高，组合越多，Bug 越离谱（B 社祖传）
5. **存档膨胀**：世界状态越多，存档越大

### 九、代表作品谱系

**史诗级**：
- 上古卷轴 3/4/5
- 辐射 3 / 新维加斯 / 4
- 哥特王朝 1/2
- 神界：原罪 1/2
- 博德之门 3
- 巫师 3（边缘案例）

**特色之作**：
- Kenshi（极致开放，无主角光环）
- Mount & Blade 系列（中世纪战争沙盒 RPG）
- Kingdom Come: Deliverance（写实历史沙盒 RPG）
- 矮人要塞（最硬核的涌现叙事）
- Caves of Qud（Roguelike + Sandbox RPG）

**新生代**：
- 王国之泪（任天堂式诠释）
- 星空（B 社争议作）
- Avowed（黑曜石新作）

### 十、常见误区

- ❌ "开放世界 = Sandbox RPG"：刺客信条是开放世界，但不是沙盒 RPG
- ❌ "地图大就是沙盒"：自由度核心在于**系统交互**，不是面积
- ❌ "沙盒 = 没剧情"：好的沙盒 RPG 剧情同样优秀，只是不强迫
- ❌ "Sandbox RPG 都是欧美的"：日系也有（如《龙之信条》部分元素）

## 第八节：Dungeon Crawler（地牢探索类）

### 一、定义

**Dungeon Crawler（地牢探索/地牢爬行）**：玩家深入由房间、走廊、楼层构成的封闭迷宫，**战斗、探索、收集战利品、不断变强**的 RPG 子类型。核心循环极度纯粹——**下楼 → 战斗 → 拾荒 → 升级 → 再下楼**。

> **核心信条**："楼层就是叙事，战利品就是奖赏，怪物就是阻力。"

### 二、核心特征

1. **迷宫式关卡**：房间、走廊、楼层、机关、隐藏门
2. **战斗为主轴**：遭遇战密度高，战术或操作驱动
3. **战利品驱动（Loot-driven）**：装备词条、稀有度、随机掉落
4. **角色成长**：等级、技能、装备三位一体
5. **资源管理**：HP/MP、药水、火把、负重
6. **越深越强**：楼层难度递增，奖励同步递增
7. **死亡惩罚**：从读档到永久死亡（Permadeath）不等

### 三、子类型谱系

Dungeon Crawler 是个庞大家族，按视角与节奏分四大派：

| 子类 | 视角 | 节奏 | 代表 |
|------|------|------|------|
| **Blobber（方格步进）** | 第一人称 | 回合/步进 | 巫术、魔法门、魔岩山传说 |
| **Action Dungeon Crawler** | 俯视/第三人称 | 实时动作 | 暗黑破坏神、火炬之光 |
| **Roguelike Dungeon Crawler** | 多样 | 回合/实时 | 盗贼传说、以撒、哈迪斯 |
| **Tactical Dungeon Crawler** | 俯视 | 回合战术 | 暗黑地牢、迷雾侦探 |

### 四、发展简史

**史前时代（1970s）**：
- **《pedit5》《dnd》**（1975 前后）：PLATO 大型机上的游戏，几乎是有据可查的最早地牢游戏
- **《Rogue》**（1980）：开创 Roguelike 概念，ASCII 字符地牢的鼻祖

**第一人称步进时代（1980s）**：
- **《巫术（Wizardry）》**（1981）：方格步进、第一人称、队伍制的奠基者，深刻影响了日式 RPG（勇者斗恶龙、女神转生都是它的孩子）
- **《魔法门（Might and Magic）》**（1986）：与巫术并称双璧
- **《地下创世纪（Ultima Underworld）》**（1992）：第一个 3D 实时第一人称地牢，影响了《系统震撼》《上古卷轴》

**ARPG 革命（1990s 末）**：
- **《暗黑破坏神（Diablo）》**（1996）：Blizzard North 用"点击战斗 + 随机掉落 + 随机地牢"重新定义类型，让 Dungeon Crawler 走向大众
- **《暗黑破坏神 2》**（2000）：词条系统、套装、符文之语——奠定现代 Loot 设计的圣经

**百花齐放（2000s）**：
- **《火炬之光》系列**：暗黑的精神继承者
- **《泰坦之旅》**：神话题材 ARPG
- **《女神异闻录 3/4》**：JRPG 把地牢爬行融入校园生活
- **《世界树迷宫》**：3DS 上的步进地牢复兴者

**新黄金期（2010s–2020s）**：
- **《暗黑地牢（Darkest Dungeon）》**（2016）：心理压力 + 哥特恐怖 + 战术回合
- **《盗贼遗产》《死亡细胞》《哈迪斯》**：Roguelite 浪潮席卷
- **《暗黑破坏神 3/4》《流放之路》《最后纪元》**：现代刷子游戏三巨头
- **《迷雾侦探》《邪恶冥刻》**：实验性方向

### 五、核心系统设计

**1. 地牢生成**
- **手工设计**：固定布局，重玩性靠玩法（如暗黑地牢）
- **程序生成（Procedural）**：每次随机（如暗黑、以撒）
- **混合式**：手工房间 + 随机拼接（最常见）

**2. 战利品系统（Loot）**
- 稀有度（白/蓝/黄/橙/绿）
- 词条（前缀、后缀、隐含）
- 套装效果
- 唯一物品（Unique）
- 掉落曲线（Drop rate curve）

> **暗黑 2 的天才设计**：词条系统让"打装备"变成无限游戏，每件装备都是一次小小的赌博。

**3. 角色构筑（Build）**
- 职业 / 流派
- 技能树
- 天赋点
- 装备搭配
- "Build Diversity"是评判刷子游戏的核心指标

**4. 难度曲线**
- 楼层递增
- 难度等级（普通/噩梦/地狱）
- 大秘境 / 深渊式无限难度
- 季节机制（Path of Exile 模式）

**5. 资源管理**
- HP / MP / 体力
- 药水 / 卷轴
- 负重 / 背包格子（Tetris 式管理）
- 火把 / 食物（硬核派）

### 六、设计哲学

**暗黑学派（Loot is King）**：
- 战利品是唯一真理
- "再来一把就睡"循环
- 数值膨胀爽快感
- 代表：暗黑、流放之路

**Blobber 学派（步进硬核）**：
- 地图测绘是乐趣
- 队伍编成是核心
- 谜题与机关并重
- 代表：巫术、魔岩山传说、世界树迷宫

**Roguelike 学派（每次都是新冒险）**：
- 永久死亡
- 每次随机一切
- 知识积累代替数值积累
- 代表：盗贼传说、矮人要塞冒险模式、Caves of Qud

**Darkest 学派（心理战）**：
- 资源永远不够
- 角色会死、会疯、会留下心理创伤
- 失败也是叙事
- 代表：暗黑地牢、迷雾侦探

### 七、Loot 设计的艺术

Dungeon Crawler 的核心驱动力是**多巴胺与赌博心理**：

- **斯金纳箱（Skinner Box）**：随机奖励刺激持续游玩
- **接近完美的诱惑**：差一个词条就完美——"再刷一把"
- **稀有度色彩心理学**：橙色暴击的瞬间比剧情高潮还爽
- **碎片化目标**：每件装备都是小目标，叠加成长期目标

> 暗黑 2 的"Diablo Drop"设计：BOSS 死亡瞬间装备四散弹出，是游戏史上最经典的多巴胺时刻之一。

### 八、Blobber 复兴

2010 年代后，老派步进地牢意外复兴：

- **《魔岩山传说（Legend of Grimrock）》**（2012）：把巫术的玩法用现代画面重做
- **《世界树迷宫》系列**：3DS 上的现象级，玩家手绘地图
- **《迷雾侦探》《地下传奇》**：独立游戏的实验

复兴原因：**怀旧 + 慢节奏需求 + 烧脑乐趣的稀缺**。

### 九、与相邻类型的区别

| 类型 | 战利品 | 地牢 | 战斗 | 代表 |
|------|------|------|------|------|
| **Dungeon Crawler** | 核心 | 核心 | 主导 | 暗黑 |
| ARPG（开放世界） | 重要 | 之一 | 主导 | 巫师 3 |
| Roguelike | 单局内 | 核心 | 主导 | 以撒 |
| MMORPG | 重要 | 副本 | 多元 | 魔兽世界 |
| JRPG | 中等 | 之一 | 主导 | 最终幻想 |

**关键区分**：Dungeon Crawler 的地牢与战斗是**目的本身**，而非通往剧情的手段。

**第一人称步进派**：

### 十一、常见误区

- ❌ "Dungeon Crawler = Roguelike"：有重叠但不等同，暗黑 2 不是 Roguelike
- ❌ "必须有地牢"：核心是**封闭关卡 + 战利品 + 战斗循环**，"地牢"是符号化的
- ❌ "都是无脑刷"：暗黑地牢、巫术绝不无脑
- ❌ "已经过时"：暗黑 4、流放 2 仍是 2024 年最赚钱的类型之一

## 第九节：Monster Taming RPG（宝可梦类 / 怪物养成 RPG）

### 一、定义

**Monster Taming RPG（怪物收服/养成 RPG）**：玩家不是直接战斗的主体，而是**收集、培养、指挥一群怪物作战**的 RPG 子类型。核心循环是 **遭遇 → 捕捉 → 培养 → 对战 → 进化/收集更多**。

> **核心信条**："你不是英雄，你的伙伴才是。"

### 二、核心特征

1. **收集（Collect）**："收齐图鉴"是玩家的元目标
2. **捕捉机制**：通过特定方式（精灵球、契约、驯服）将敌方怪物收为己有
3. **培养系统**：等级、技能、属性、进化、个体值
4. **指挥战斗**：玩家不亲自下场，而是发号施令
5. **队伍编成**：通常 3–6 只出战，强调搭配与克制
6. **属性克制**：石头剪刀布式相克链是战斗灵魂
7. **图鉴文化**：收集欲是核心驱动力之一
8. **对战社群**：PvP 与交换是长尾生命力

### 三、发展简史

**史前时代（1980s–1990s 初）**：
- **《女神转生》系列**（1987 起）：恶魔合体/交涉系统，被认为是怪物收集的精神鼻祖
- **《天使之诗》《Megami Tensei》**：早期 JRPG 中已有怪物收服元素
- **《勇者斗恶龙 5》**（1992）：第一个把"招募怪物当伙伴"做成主玩法的主线 RPG

**革命之年（1996）**：
- **《精灵宝可梦 红/绿》**（1996）：田尻智构想了 6 年的"昆虫收集 + 通信对战"在 Game Boy 上引爆全球
  - **通信电缆**成为社交核心：交换才能进化、版本独占、两版本对战
  - 创造了"图鉴"这个 RPG 史上最有粘性的元目标
  - 奠定**6 只出战、属性克制、回合制指令**的标准范式

**百花齐放（1990s 末–2000s）**：
- **《数码宝贝世界》**（1999）：PS 上的怪兽养成名作，强调"养"而非"抓"
- **《怪物农场》系列**（1997 起）：CD 读取生成怪物的奇思妙想
- **《Jade Cocoon》《Azure Dreams》**：早期实验性作品
- **《勇者斗恶龙 怪兽篇》**（1998 起）：DQ 衍生的纯怪物收集线，配种系统深度极高

**宝可梦黄金时代（2000s–2010s）**：
- **《宝可梦 金/银》**（1999）：日夜系统、亲密度、生蛋
- **《宝可梦 红宝石/蓝宝石》**（2002）：特性、双打
- **《宝可梦 钻石/珍珠》**（2006）：物特分离、Wi-Fi 对战
- **《宝可梦 黑/白》**（2010）：剧情高峰
- **《宝可梦 X/Y》**（2013）：3D 化、Mega 进化

**类型扩张与挑战者（2010s–至今）**：
- **《妖怪手表》**（2013）：日本本土曾短暂掀翻宝可梦的现象级
- **《Monster Hunter Stories》**（2016）：卡普空把怪猎宇宙改成怪物养成
- **《Temtem》**（2020）：MMO 化的西式宝可梦
- **《幻兽帕鲁（Palworld）》**（2024）：宝可梦 + 生存 + 枪械的离经叛道之作，发售一周 800 万销量震惊业界
- **《宝可梦 朱/紫》**（2022）：开放世界化的尝试
- **《数码宝贝物语：网络侦探》系列**：数码宝贝的现代回归

### 四、子类型分化

| 子类 | 特征 | 代表 |
|------|------|------|
| **正统派（捕捉式）** | 野外遭遇 + 道具捕获 | 宝可梦、Temtem |
| **契约派（合体/交涉）** | 与怪物对话/交易/合体 | 女神转生、真女神转生 |
| **配种派** | 繁殖与遗传是核心 | 勇者斗恶龙怪兽篇、怪物农场 |
| **羁绊派** | 重养成轻数量 | 数码宝贝、怪物猎人物语 |
| **生存融合派** | 怪物 + 生存建造 | 幻兽帕鲁、Craftopia |
| **开放世界派** | 开放地图自由探索 | 宝可梦 朱/紫、Cassette Beasts |

### 五、核心系统设计

**1. 捕捉系统**
- 削血到红 → 投球的经典范式
- 状态异常（睡眠/麻痹）提升成功率
- 球的稀有度与种类（高级球、特殊球）
- 概率公式（HP%、状态、球系数、等级差）

**2. 属性克制**
- 宝可梦的 18 属性相克表是教科书级设计
- 设计目标：**没有最强属性，只有最适合的搭配**
- 双属性叠加创造复杂度（如龙/钢的高抗性）

**3. 数值系统（深度的秘密）**
- **种族值（Base Stats）**：物种的天赋上限
- **个体值（IV）**：先天差异，0–31
- **努力值（EV）**：后天训练，可分配
- **性格（Nature）**：影响成长方向
- **特性（Ability）**：被动技能
- 这套系统让"看似简单的儿童游戏"拥有 MOBA 级的对战深度

**4. 进化系统**
- 等级进化
- 道具进化（特定石头）
- 亲密度进化
- 交换进化（社交绑定的天才设计）
- 时间/地点进化
- 形态变化（Mega、极巨、太晶）

**5. 对战系统**
- 单打 / 双打 / 三打 / 多打
- 出招顺序（速度 / 优先度）
- 状态异常 / 天气 / 场地
- 替换博弈（"换人"是核心战术）

### 六、设计哲学

**任天堂学派（宝可梦本格）**：
- 收集欲优先
- 系统简单上手，深度藏在数值里
- "全年龄"是设计铁律
- 通信/交换是社交核心

**Atlus 学派（女神转生派）**：
- 怪物是黑暗神话的一部分
- 交涉、合体取代捕捉
- 故事与道德选择并重
- 难度与暗黑美学

**Pocketpair 学派（帕鲁派）**：
- 打破"萌"的桎梏
- 怪物作为劳动力 + 武器 + 食物
- 生存沙盒融合
- 反乌托邦的黑色幽默

**勇者斗恶龙 / 怪物农场学派（养成派）**：
- 配种、遗传、随机性
- 长期培养优于快速收集
- 玩家是"训育家"而非"训练家"

### 七、为什么这么上瘾？

Monster Taming 集合了 **多种心理学钩子**：

1. **收集欲（Collector's Drive）**：图鉴空格的强迫症
2. **养成投入（Sunk Cost）**：花 50 小时练的伙伴情感无价
3. **赌博心理**：闪光、高个体值的随机奖励
4. **拟人化情感**：怪物有名字、表情、叫声
5. **社交资本**：稀有怪物的炫耀价值
6. **掌控感**：从弱小到强大的成长曲线

> 宝可梦的天才：**把昆虫采集的童年记忆，变成数字时代的永恒成瘾循环**。

### 八、宝可梦现象学

宝可梦不只是游戏，是**人类娱乐史上最赚钱的 IP**（超过 1100 亿美元收入，超越米老鼠、星球大战）：

- **游戏 + 动画 + 卡牌 + 周边**的全媒体生态
- **二十多年文化记忆**的代际传承
- **TCG（集换卡牌）市场**：稀有卡可拍卖百万美元
- **Pokémon GO** 重新定义 LBS 手游
- **世锦赛 VGC**：电竞化的回合制游戏

## 第十节：Visual Novel RPG（视觉小说 RPG / VN-RPG）

### 一、定义

**Visual Novel RPG（视觉小说 RPG）**：以**文本叙事为核心**，融合 RPG 系统（角色养成、战斗、属性、选择分支）的混合类型。它不是纯 VN（纯文字 + 选项），也不是叙事型 JRPG，而是处于两者交集的**叙事重 + 系统轻**的特殊形态。

> **核心信条**："故事是身体，系统是骨架，立绘是灵魂。"

### 二、核心特征

1. **文本量巨大**：单作 50–200 万字是常态
2. **静态/半动态画面**：立绘 + 背景 + 文本框为主呈现
3. **分支与多结局**：选择驱动剧情走向
4. **角色路线（Route）**：通常多女主/多男主分线
5. **轻量 RPG 系统**：属性、好感度、战斗、养成至少占其一
6. **CG 收集**：关键剧情有插画奖励
7. **配音文化**：日系作品几乎全语音
8. **多周目设计**：一周目通关只是开始

### 三、与纯视觉小说的区别

| 维度 | 纯 VN | VN-RPG |
|------|------|------|
| 玩法 | 阅读 + 选项 | 阅读 + 选项 + 系统 |
| 战斗 | 通常无 | 有（回合制/战术/卡牌等） |
| 数值 | 无或极弱 | 属性、等级、装备 |
| 失败 | 几乎不会 | 可能 Game Over |
| 时长 | 20–80 小时 | 40–150 小时 |
| 代表 | CLANNAD、白色相簿2 | Fate/stay night、女神异闻录 |

> **关键判断**：是否拥有"可以失败的玩法循环"。

### 四、发展简史

**史前时代（1980s）**：
- **《天使们的午后》**（1985）：日本 PC 美少女游戏雏形
- **《同级生》**（1992，elf）：恋爱模拟雏形，引入时间表系统
- **《雫》《痕》**（1996–1997，Leaf）：开创"泣系"叙事派
- **《To Heart》**（1997）：现代 VN 范式定型

**黄金奠基（1990s 末–2000s 初）**：
- **《YU-NO》**（1996）：分歧图（A.D.M.S）系统的鼻祖，影响《命运石之门》
- **《Kanon》《AIR》**（1999/2000，Key）：泣系巅峰
- **《月姫》**（2000，TYPE-MOON）：同人作品引爆类型
- **《Fate/stay night》**（2004）：**VN-RPG 的里程碑**，三线剧情 + 圣杯战争 + 战斗演出，是公认的"系统化 VN"高峰

**机制融合期（2000s 中–2010s）**：
- **《女神异闻录 3》**（2006）：JRPG + 校园生活 + Social Link，**模糊了 VN 与 RPG 的边界**
- **《逆转裁判》系列**：法庭辩论作为玩法
- **《极限脱出》系列**（999、VLR、ZTD）：解谜 + 文字 AVG
- **《命运石之门》**（2009）：手机邮件系统作为分支机制
- **《传说之下（Undertale）》**（2015）：把 VN 式叙事注入像素 RPG，反向融合

**现代多元化（2010s 后–至今）**：
- **《十三机兵防卫圈》**（2019）：13 视角群像 + RTS 战斗
- **《AI: 梦境档案》**：解谜 + VN
- **《Roadwarden》**：文字探索 + RPG，欧美独立派
- **《Citizen Sleeper》**（2022）：骰子 + 赛博朋克 + 文字 RPG
- **《Slay the Princess》**（2023）：VN + 选择分支的极致实验
- **《1000xRESIST》**（2024）：科幻叙事新范式

### 五、子类型谱系

| 子类 | 特征 | 代表 |
|------|------|------|
| **传奇 ADV 派** | 重剧情 + 轻战斗 | Fate/stay night、命运石之门 |
| **校园生活模拟派** | 时间管理 + 社交 + 战斗 | 女神异闻录 3/4/5 |
| **战术 VN 派** | VN + SRPG | 十三机兵、樱花大战 |
| **解谜 VN 派** | 谜题作为玩法 | 逆转裁判、极限脱出 |
| **欧美叙事 RPG 派** | 文本 RPG + 骰子/属性 | Disco Elysium、Citizen Sleeper |
| **乙女 / 男性向恋爱派** | 攻略路线 + 轻 RPG | 心跳回忆、薄樱鬼 |
| **同人 / 商业实验派** | 各种混搭 | Slay the Princess、Doki Doki |

### 六、核心系统设计

**1. 分支结构**
- **线性 + 关键选项**：大体一条路，关键节点分歧
- **分歧图（Flowchart）**：可视化所有路线（YU-NO、命运石之门）
- **路线锁（Route Lock）**：达成条件才能进入特定线
- **真结局（True End）**：通关所有路线后解锁的最终真相

**2. 好感度系统**
- 选项加点
- 礼物 / 约会
- 时间表系统（同级生式）
- Social Link（女神异闻录式）：**社交即战斗强化**

**3. 战斗系统（如有）**
- Fate 式：**演出化战斗 + 简单指令**
- 女神异闻录式：完整回合 JRPG
- 十三机兵式：实时战略 RTS
- Disco Elysium 式：**对话即战斗**，技能检定

**4. 时间管理**
- 学期 / 日历推进
- 行动点数（每天做几件事）
- DDL 压力（如 P5 的截止日期）
- **时间作为最稀缺资源**

**5. 多周目设计**
- 继承属性 / 道具
- 解锁新选项
- 隐藏剧情碎片
- 真结局门槛

### 七、设计哲学

**TYPE-MOON 学派（重设定 + 长台词）**：
- 世界观深邃，设定文档比剧本还厚
- 战斗是叙事的高潮工具
- 角色魅力 = 类型生命力
- 代表：Fate 系列、月姬

**Atlus 学派（生活模拟融合）**：
- VN 元素融入 JRPG 主体
- 校园 + 异世界双线
- 社交 = 战力
- 代表：女神异闻录 3/4/5

**Key 学派（泣系叙事派）**：
- 情感冲击优先
- 系统极简
- 音乐与剧情共鸣
- 代表：CLANNAD、Little Busters!

**欧美叙事 RPG 派**：
- 文本即玩法
- 骰子 / 技能检定的紧张感
- 反类型化、反萌系
- 代表：Disco Elysium、Citizen Sleeper、Roadwarden

**香草社学派（演出至上）**：
- 美术风格强烈
- 群像叙事 + 系统创新
- 代表：十三机兵防卫圈、奇迹时代奥丁领域

### 八、为什么这是"灰色地带"？

VN-RPG 的定位之争长期存在：

- **纯 VN 派**：认为带战斗就不算 VN
- **纯 RPG 派**：认为没数值深度就不算 RPG
- **现实**：**这个交集恰恰是最具创新力的地带**

> Disco Elysium 就是最佳证明：它**几乎没有传统战斗**，但靠"对话即战斗"获得 RPG 评论界最高评价，同时被视为 VN 的进化形态。

### 九、文化背景与地域差异

**日本系**：
- 美少女游戏文化的延伸
- 18 禁原作 → 全年龄移植的产业链

**欧美系**：
- 起步晚但创新多
- 倾向"文学 RPG"方向
- Disco Elysium、Citizen Sleeper、80 Days
- Twine、Ren'Py 等开源工具促进独立创作

**韩国系**：
- 男性向手游为主

## 第十一节：Soulslike（魂类 / 类魂游戏）

### 一、定义

**Soulslike（魂类游戏）**：以 FromSoftware《恶魔之魂》（2009）和《黑暗之魂》系列（2011 起）为原型衍生出的动作 RPG 子类型。它**不是单纯的"难"，而是一整套独特的设计哲学体系**——通过严苛但公平的战斗、隐晦的叙事、死亡惩罚与探索发现，构建一种**"敬畏感"的游戏体验**。

> **核心信条**："Prepare to Die." —— 不是惩罚玩家，而是让胜利有重量。

### 二、核心特征（七大支柱）

1. **死亡惩罚机制**：死亡掉落货币/经验，原地重拾 or 二次死亡彻底失去
2. **存档点回溯**：篝火/star点机制，休息回血但敌人复活
3. **耐力系统（Stamina）**：攻击、闪避、格挡都消耗耐力，逼迫节奏管理
4. **锁定 + 翻滚 + 格挡**：动作系统的"三位一体"
5. **Boss 战为核心高潮**：每个 Boss 是一首完整的"乐章"
6. **碎片化叙事（Lore）**：剧情藏在道具描述、环境、NPC 残语中
7. **互联式地图**：捷径解锁带来的"啊原来这里通这里"的顿悟感

### 三、隐藏的核心：FromSoftware 设计哲学

**1. 敬畏感（Awe）**
- 巨大的 Boss、宏伟的废墟、寂静的氛围
- 让玩家**先感到渺小，再感到强大**

**2. 公平的残酷**
- 敌人不会作弊，所有死亡都"是你自己的错"
- 学习曲线 = 心流曲线

**3. 隐晦的尊重**
- 不告诉玩家怎么玩，相信玩家会探索
- 没有引导箭头、没有任务标记

**4. 死亡作为语言**
- 死亡不是失败，是**学习的工具**
- "你死了"是叙事节奏的一部分

**5. 距离感的叙事**
- 不让你"代入"主角，而是让你"考古"世界
- 玩家是这个衰败世界的旁观者

### 四、发展简史

**史前时代（前魂时代）**：
- **《国王密令（King's Field）》**（1994 起，FromSoftware）：第一人称暗黑奇幻 ARPG，魂系的真正源头
- **《影之塔（Shadow Tower）》**（1998）：King's Field 精神续作
- **《忍者龙剑传》《鬼武者》**：高难度动作的日系基因

**奠基之作（2009）**：
- **《恶魔之魂（Demon's Souls）》**（2009，PS3 独占）
  - 制作人：宫崎英高
  - **首创**：篝火（神龛）、灵魂掉落、入侵 PvP、留言系统
  - 世界倾向（World Tendency）系统
  - 当时被索尼日本认为"不会成功"，结果成为邪典经典

**黄金奠基（2011–2014）**：
- **《黑暗之魂（Dark Souls）》**（2011）：**类型正式定型**
  - 互联开放地图（罗德兰）
  - "Prepare to Die" 成为类型口号
  - 篝火 → 火继承的世界观
- **《黑暗之魂 II》**（2014）：第二代，宫崎英高未亲自执导，争议较大但 DLC 获高度评价
- **《血源诅咒（Bloodborne）》**（2015）：**类型分支**
  - 维多利亚哥特 + 克苏鲁
  - 取消盾牌，强化进攻 + 回血机制（Rally）
  - 速度感与精神污染美学

**完成与超越（2016–2019）**：
- **《黑暗之魂 III》**（2016）：系列集大成
- **《只狼：影逝二度》**（2019）：**进一步分化**
  - 弃绝 RPG build，强化动作纯粹性
  - 弹反系统（Deflect）取代翻滚
  - 复活机制改写死亡哲学
  - 获 TGA 年度游戏

**类型大爆发（2014–2020）**：
- **《盐与避难所（Salt and Sanctuary）》**（2016）：2D 魂类先驱
- **《仁王（Nioh）》**（2017）：日式战国 + 暗黑破坏神 Build
- **《嗜血代码（Code Vein）》**（2019）：动漫风魂类
- **《堕落之王》《灰烬重生》《Mortal Shell》** 等大量跟风

**艾尔登法环时代（2022–至今）**：
- **《艾尔登法环（Elden Ring）》**（2022）：**开放世界 + 魂类**
  - 与 George R. R. Martin 合作世界观
  - 销量突破 2800 万，TGA 2022 年度游戏
  - **让魂类从"硬核小众"变成"全民现象"**
- **《匹诺曹的谎言（Lies of P）》**（2023）：韩国 Round8 制作的高质量魂类
- **《卧龙：苍天陨落》**（2023）：Team Ninja 的三国魂
- **《Elden Ring: Shadow of the Erdtree》**（2024）：DLC 史上最高规格
- **《明末：渊虚之羽》《影之刃零》《明末》**：中国厂商加入魂类竞赛

### 五、子类型分化

| 子类 | 特征 | 代表 |
|------|------|------|
| **正统魂（Soulslike Pure）** | 篝火 + 翻滚 + 重剑 + Build | 黑暗之魂、Lies of P |
| **快节奏魂（Bloodborne 派）** | 弃盾 + 进攻型回血 | 血源、嗜血代码 |
| **弹反魂（Sekiro 派）** | 弹反 + 架势条 | 只狼、卧龙、明末 |
| **Build 魂（Nioh 派）** | Loot + 流派 + 深度 Build | 仁王 1/2、卧龙 |

### 六、核心系统设计

**1. 死亡 / 篝火循环**
- 死亡 → 失去货币 → 跑尸找回 → 二次死亡彻底丢失
- 篝火 = 存档 + 升级 + 传送 + 敌人重置
- **创造紧张感与节奏感的完美工具**

**2. 耐力（Stamina）系统**
- 所有动作消耗耐力
- 逼迫玩家"思考再行动"
- 与传统 ACT（鬼泣、忍龙）的爽快连击形成根本区别

**3. 翻滚 / 格挡 / 弹反**
- **翻滚（i-frame）**：黑魂正统
- **格挡 + 盾反**：黑魂、Lies of P
- **弹反（Deflect）**：只狼、卧龙
- 三种范式定义不同的战斗哲学

**4. Build 系统**
- 等级点数分配（力量/敏捷/智力/信仰）
- 武器派生（Infusion）
- 魔法 / 奇迹 / 法术
- "百人百魂"——build 多样性是长尾生命力

**5. Boss 设计**
- **Phase 切换**：通常 2–3 阶段
- **演出与音乐**：每个 Boss 一首专属交响乐
- **学习曲线**：5–20 次死亡后突破的成就感
- **叙事高潮**：Boss 名字、台词、形象都承载剧情

**6. 碎片化叙事**
- 道具描述
- NPC 残缺对话
- 环境符号学
- "Lore 视频"亚文化（VaatiVidya 等 YouTuber）

**7. 互联地图设计**
- 看似线性的迷宫，最后发现彼此相通
- "捷径"（Shortcut）的设计是顿悟的源泉
- 不死镇 → 病村 → 罗德兰深处的经典案例

**8. 异步多人系统**
- **留言系统**：玩家在地上留言互助
- **血迹回放**：看到其他玩家的死亡瞬间
- **召唤 / 入侵**：合作 + PvP 的灰色地带
- 是"孤独但不孤单"的天才设计

### 七、设计哲学

**FromSoftware 学派（宫崎英高）**：
- 残酷而公平
- 隐晦而尊重
- 距离感的叙事
- 美学优先于玩家友好

**Team Ninja 学派（仁王派）**：
- 高难度 + 深度 Build
- 多动作流派
- 暗荣式刷子玩法
- 关卡式而非开放式

**Round8 学派（Lies of P）**：
- 极致模仿后的本土化
- 清晰的世界观（皮诺曹 + 蒸汽朋克）
- 武器组合系统的创新

**独立魂派**：
- 用 2D 或低成本表达魂的"精神"而非"形式"
- Hollow Knight、Blasphemous、Tunic
- 证明魂类是**哲学而非画面**

### 八、为什么这么上瘾？

魂类游戏击中了一系列特殊心理机制：

1. **延迟满足（Delayed Gratification）**：50 次死亡后的胜利无可替代
2. **学习快感（Mastery）**：从手忙脚乱到从容应对的成长
3. **逆境心流（Flow under Pressure）**：紧张感持续 100+ 小时
4. **考古乐趣（Archaeology）**：拼凑碎片故事的智力满足
5. **社群归属感**：通关者之间的"幸存者俱乐部"
6. **反消费主义快感**：在"轻松爽快"的游戏世界中，**艰难本身成为价值**

> 宫崎英高的天才：**让"死亡"成为一种正反馈**。

### 九、魂类 vs 类魂的争论

- **狭义魂（Soulsborne）**：仅指 FromSoftware 的 Souls/Bloodborne/Sekiro/Elden Ring
- **广义魂（Soulslike）**：所有继承核心机制的作品
- **争议点**："只是难 = 魂类"是常见误解
  - **难 ≠ 魂**：忍龙、鬼泣 DMD 也很难，但不是魂类
  - **魂的本质**：是**篝火-死亡-学习**的完整哲学循环

- Dark Souls 1 / 2 / 3
- Bloodborne
- Sekiro: Shadows Die Twice
- Elden Ring + Shadow of the Erdtree

**高质量模仿者**：
- Lies of P

## 第十二节：Looter RPG（刷宝类 / 掠夺者 RPG）

### 一、定义

**Looter RPG（刷宝类 RPG）**：以**装备掉落（Loot）作为核心驱动力**的 RPG 子类型。玩家反复挑战内容，目的不是推进剧情，而是为了**获取更好的装备 → 变得更强 → 挑战更难内容 → 获取更好装备**的永动循环。

> **核心信条**："再来一把，下一个橙装就是它了。"——这是 Looter 的灵魂咒语。

### 二、核心特征（六大支柱）

1. **装备稀有度系统**：白 → 绿 → 蓝 → 紫 → 橙 → 红的视觉语言
2. **随机词缀（Affix）**：同一件装备百万种属性组合
3. **掉落即奖励**：开宝箱/打怪/通关都是赌博式正反馈
4. **战力螺旋（Power Creep）**：装备 → 战力 → 内容 → 装备
5. **可重复内容**：副本、地图、Rift、赛季机制
6. **Build 多样性**：装备词缀决定流派，流派决定玩法

### 三、隐藏的核心：斯金纳箱（Skinner Box）

Looter RPG 是**电子游戏中最纯粹的可变比率强化（Variable Ratio Reinforcement）**应用：

- **不知道何时掉好东西** → 持续投入
- **偶尔的暴击式爆装** → 多巴胺峰值
- **沉没成本** → "再刷一把就睡"
- **比较心理** → 装备数值 = 社交货币

> Looter 是**最接近老虎机的游戏类型**，但用"技能 + 策略"的外衣包装了赌博本质。

### 四、发展简史

**史前时代（Roguelike 与 ARPG 起源）**：
- **《Rogue》**（1980）：随机生成 + 随机掉落的鼻祖
- **《NetHack》《Moria》**（1980s）：道具系统与稀有度雏形
- **《暗黑破坏神（Diablo）》**（1996，Blizzard North）：**Looter ARPG 的真正起点**
  - David Brevik 把 Roguelike 的随机掉落 + 实时动作结合
  - 红白绿蓝金的稀有度系统首次确立

**奠基黄金期（2000s）**：
- **《暗黑破坏神 II》**（2000）：**Looter 的圣经**
  - Set 装备、独特装备（Unique）、符文之语（Runeword）
  - 大秘境的雏形、地狱难度
  - 季节性更新概念
  - 至今仍是无数 Looter 致敬的对象
- **《无尽的任务（EverQuest）》《魔兽世界》**（2004）：MMO 化的 Looter，副本掉落 + 团队分配
- **《无主之地（Borderlands）》**（2009，Gearbox）：**FPS + Looter 的革命**
  - "Bazillion Guns" 概念，号称千万种枪
  - 把 Looter 从俯视角 ARPG 拓展到第一人称射击

**类型大爆发（2010s）**：
- **《火炬之光 1/2》**（2009/2012）：暗黑 II 精神续作
- **《暗黑破坏神 III》**（2012）：拍卖行风波 → 夺魂之镰复活 → 大秘境定型现代 Looter
- **《无主之地 2》**（2012）：系列巅峰，反派"Handsome Jack"成经典
- **《流放之路（Path of Exile）》**（2013，GGG）：**深度 Build + 通货系统**
  - 拒绝金币，用通货卷轴交易
  - 天赋树 1300+ 节点
  - 联盟（League）赛季机制
- **《命运（Destiny）》**（2014，Bungie）：**Looter Shooter MMO 化**
- **《全境封锁（The Division）》**（2016）：现代军事 Looter
- **《暗黑地牢（Darkest Dungeon）》**（2016）：Looter + Roguelite

**多元化与服务化（2017–至今）**：
- **《命运 2》**（2017）：Looter Shooter 的成熟形态
- **《圣歌（Anthem）》**（2019）：BioWare 的滑铁卢，Looter 商业化反面教材
- **《无主之地 3》**（2019）：系列规模化
- **《最终幻想起源：天堂的陌生人》**（2022）：FF + Nioh 式 Looter
- **《暗黑破坏神 IV》**（2023）：开放世界 + Looter，赛季制服务化
- **《流放之路 2》**（2024 EA）：系列接班人
- **《最后纪元（Last Epoch）》**（2024）：D2 + PoE 的折中派

| 子类 | 视角 | 战斗 | 代表 |
|------|------|------|------|
| **正统 ARPG Looter** | 俯视角 | 实时动作 | Diablo、PoE、火炬之光 |
| **Looter Shooter** | 第一/第三人称 | 射击 | Borderlands、Destiny、Division |
| **Hack & Slash Looter** | 俯视角 | 强动作连击 | Grim Dawn、Wolcen |
| **MMO Looter** | 多种 | RPG | WoW、Lost Ark |
| **Roguelite Looter** | 多种 | 单局制 | Hades、Darkest Dungeon |
| **战术 Looter** | 各种 | 策略 | XCOM Chimera Squad、Marvel's Midnight Suns |
| **Soulslooter（魂刷融合）** | 第三人称 | 魂式 | Nioh、Wo Long、Stranger of Paradise |
| **生存 Looter** | 第一/第三 | 多种 | Remnant、Outriders |

### 六、核心系统设计

**1. 装备稀有度（Rarity）**
- 经典色阶：白 → 绿 → 蓝 → 紫 → 橙 → 红
- 每级稀有度增加词缀数量与质量
- **视觉冲击是核心爽点**——掉橙装时的金光特效是设计语言

**2. 词缀系统（Affixes）**
- **前缀 + 后缀**：D2 模式
- **隐式 + 显式**：PoE 模式
- **传奇专属词缀**：D3/D4 模式
- **数学的艺术**：词缀池的设计决定 Build 深度

**3. 战利品掉落（Loot Drop）**
- 怪物等级 = 掉落等级
- 魔法找寻（Magic Find / Item Find）属性
- 爆装动画与音效（金币声、橙光）是**多巴胺触发器**
- 智能掉落（Smart Loot）：根据角色职业偏向掉落

**4. Build 系统**
- 技能树 / 天赋树
- 装备搭配触发流派
- "装备决定 Build" vs "Build 决定装备"两派哲学
- **Build 多样性 = 类型生命力**

**5. 终局内容（Endgame）**
- **大秘境（Greater Rift）**：D3 首创，无限层数
- **地图（Atlas）**：PoE 的可定制终局地图
- **赛季 / 联盟（Season / League）**：周期性重置 + 新机制
- **Boss Rush**：纯战斗挑战
- **天梯（Ladder）**：竞速排行榜

**6. 难度梯度**
- 普通 → 噩梦 → 地狱（D2 模式）
- 痛苦等级 / 折磨等级（D3）
- 世界等级（D4、Outriders）
- 难度 = 掉落质量乘数

**7. 经济系统**
- **金币派**：D2/D3，简单但通胀
- **通货派**：PoE，物物交易
- **绑定派**：MMO 防止 RMT
- **拍卖行**：D3 早期失败案例

**8. 赛季机制（Seasonal Model）**
- 角色重置 + 新机制 + 限定奖励
- 让玩家"重新发现"游戏
- 是现代 Looter 的标准服务化模式

### 七、设计哲学

**Blizzard 学派（暴雪派）**：
- 易上手、难精通
- 视觉爽快、音效冲击
- 大众化与深度的平衡
- 代表：Diablo II / III / IV

**GGG 学派（流放之路派）**：
- 极致深度
- 1000+ 小时才入门
- 经济驱动玩法
- "不友好但公平"
- 代表：Path of Exile

**Gearbox 学派（无主之地派）**：
- Looter + 幽默叙事
- 武器手感优先
- 合作社交
- 代表：Borderlands 系列

**Bungie 学派（命运派）**：
- Looter + MMO + Shooter
- 赛季叙事
- 装备 = 身份
- 代表：Destiny 1 / 2

**EHG 学派（最后纪元派）**：
- D2 怀旧 + PoE 深度的折中
- 离线 + 在线双模式
- "对玩家友好的硬核"

### 八、爆装快感的科学

Looter 设计的核心是**多巴胺峰值管理**：

1. **可变比率强化**：每次掉落都是赌博
2. **预期管理**：紫装是基线，橙装是惊喜，红装是高潮
3. **视觉/听觉触发器**：金光、特殊音效
4. **比较系统**：左右对比当前装备
5. **沉没成本陷阱**："刷了 100 把还没出我就再来一把"
6. **社交炫耀**：装备截图 = Looter 玩家的社交货币

> Looter RPG **不是关于"获得"，而是关于"渴望"**。爆装的瞬间会立即被"下一件更好的"渴望取代。

### 九、与其他类型的边界

| 对比类型 | 核心区别 |

| **传统 RPG** | Looter 关心"刷"而非"故事"，剧情是壳 |

| **MMO** | MMO 关心社交与世界，Looter 关心装备循环 |
| **ARPG** | ARPG 是 Looter 的常见载体，但 Looter 也包括 Shooter |
| **MOBA** | MOBA 是单局平衡，Looter 是长线积累 |

# 第三部分：策略类游戏（Strategy Games）

策略类游戏是电子游戏中**最古老、最深邃、分支最庞杂**的类型谱系。它直接继承了人类几千年的棋类、桌游、兵棋传统，奖励的不是手速与反应，而是**判断、规划、远见**。

> **核心信条**："胜利属于思考更深的人。"

**策略类的本质**：在有限信息与有限资源的约束下，通过决策追求最优解。

**主要子类清单**（共 12 节）：

- 第一节：RTS（即时战略）

## 第一节：RTS（Real-Time Strategy / 即时战略）

### 一、定义

**RTS（Real-Time Strategy，即时战略）**：游戏时间**实时流动**，玩家需要**同时**进行资源采集、基地建设、单位生产、科技升级、战术指挥的策略游戏类型。所有玩家与 AI 的行动并行发生，**没有回合**，时间本身就是战场。

> **核心信条**："时间即资源，操作即胜负。Macro 是地基，Micro 是利刃。"

RTS 是策略游戏中**最考验综合能力**的子类——它要求玩家像同时下五盘象棋的特级大师一样，分配注意力、管理多条战线、在毫秒级压力下做出宏观决策。

### 二、核心特征（六大支柱）

1. **实时性（Real-Time）**：游戏时间不停，思考与操作必须同步
2. **资源采集（Resource Gathering）**：矿/气/木/食物/电力等多元资源体系
3. **基地建设（Base Building）**：建筑生产单位、提供科技、构成防线
4. **科技树（Tech Tree）**：从基础兵种逐步解锁高阶单位与升级
5. **单位克制（Unit Counter）**：石头剪刀布的兵种相克链
6. **APM 与多线程（APM & Multitasking）**：每分钟操作数 + 战场注意力分配

### 三、隐藏的核心：宏观与微观的双重压力

RTS 真正的挑战是**同时处理两个时间尺度**：

**宏观（Macro）**：
- 经济运营（农民数量、扩张时机、资源平衡）
- 科技路线（先升科技还是先暴兵）
- 战略决策（rush / 龟缩 / 空投 / 骚扰）
- 人口规划与生产周期管理

**微观（Micro）**：
- 单位编队、走位、风筝、集火
- 关键技能释放时机
- 阵型与地形利用
- 侦察与视野控制

> **顶级 RTS 选手 = 同时是 CEO（宏观调度）+ 特种兵教官（微操指挥）+ 情报分析师（侦察判断）**。这种"一脑多用"的极限要求，让 RTS 成为**电竞史上技术门槛最高的类型**。

### 四、发展简史

**史前时代（雏形期，1980s）**：
- **《Utopia》**（1981，Intellivision）：最早的实时策略雏形，资源 + 建造
- **《Stonkers》**（1983）、**《The Ancient Art of War》**（1984）：早期实时军事模拟
- **《Herzog Zwei》**（1989，Technosoft，MD）：**公认的 RTS 直接祖先**，已有基地、生产、单位指挥

**奠基黄金期（1990s 上半叶）**：
- **《Dune II: The Building of a Dynasty》**（1992，Westwood）：**现代 RTS 的真正起点**
  - 鼠标点选、采集、建造、科技树范式全部确立
  - 三大派系（厄崔迪/哈克南/奥多斯）的不对称设计
  - 几乎所有后续 RTS 都是它的精神后裔
- **《魔兽争霸：人类与兽人》**（1994，Blizzard）：暴雪 RTS 的起点，对战 + 剧情双线
- **《命令与征服》**（1995，Westwood）：**RTS 的大众化革命**
  - 真人过场动画（FMV）
  - GDI vs NOD 的冷战美学
  - 编队、群选等操作范式
- **《魔兽争霸 II：黑潮》**（1995）：水域作战、迷雾、暴雪式平衡

**RTS 的盛世（1990s 下半叶 — 2000s 初）**：
- **《横扫千军（Total Annihilation）》**（1997，Cavedog）：**大规模战争先驱**
  - 无限单位上限、3D 地形、物理弹道
  - 经济持续流动模型（不同于 D2 的离散资源）
- **《星际争霸（StarCraft）》**（1998，Blizzard）：**RTS 的圣经，电竞之父**
  - 人/虫/神三族**完全不对称却平衡**的设计奇迹
  - 韩国电竞产业的开端，OGN/MBC 的星际联赛
  - **影响延续 25 年以上**，至今仍是 RTS 平衡设计的教科书
- **《帝国时代 II》**（1999，Ensemble）：**历史 RTS 的巅峰**
  - 13 个文明的差异化设计
  - 时代升级（黑暗→封建→城堡→帝王）
  - 决定版（2019）至今活跃
- **《家园（Homeworld）》**（1999，Relic）：**3D 太空 RTS 的革命**
  - 真正的三维战场
  - 史诗叙事与视觉美学
- **《命令与征服：红色警戒 2》**（2000）：冷战架空，国民级 RTS
- **《魔兽争霸 III：混乱之治 / 冰封王座》**（2002/2003）：**RTS + RPG 融合的革命**
  - 英雄系统、物品、酒馆雇佣兵
  - 地图编辑器孕育了 **DOTA → 整个 MOBA 类型**
  - 4 族（人/兽/暗夜/亡灵）平衡新典范

**类型成熟与多元化（2000s 中后期）**：
- **《英雄连（Company of Heroes）》**（2006，Relic）：**掩体与战线 RTS 革命**
  - 取消传统采矿，引入"控制点"资源
  - 步兵自动寻找掩体、压制系统
- **《最高指挥官（Supreme Commander）》**（2007）：横扫千军精神续作，超大规模
- **《星际争霸 II：自由之翼》**（2010）：电竞延续 + 单人战役复兴
- **《命令与征服 3：泰伯利亚之战》**（2007）、**《红色警戒 3》**（2008）：C&C 系列谢幕

**衰落与转型（2010s）**：
- MOBA、自走棋、塔防分流了 RTS 的玩家与设计者
- **《全面战争（Total War）》系列**：转型为"回合制大地图 + 实时战斗"的混合体
- **《灰熊心（Grey Goo）》《钢铁收割》《Iron Harvest》**：怀旧派坚持
- **《家园：卡拉克沙漠》**（2016）、**《家园 3》**（2024）：经典 IP 复活

**复兴尝试（2020s）**：
- **《帝国时代 IV》**（2021，Relic）：经典 RTS 的现代化复兴
- **《星际争霸 II》冷藏**：暴雪不再开发新内容，社区接管
- **《StormGate》《Tempest Rising》《ZeroSpace》**：星际/红警精神续作的众筹潮
- **《Battle Aces》**：极简化 RTS 的实验

### 五、子类型谱系

| 子类 | 特征 | 代表 |
|------|------|------|
| **经典基建 RTS** | 采矿 + 建造 + 暴兵 | StarCraft、AoE、C&C |
| **大规模 RTS** | 数百单位 + 物理战场 | Total Annihilation、Supreme Commander |
| **战线 RTS** | 控制点 + 掩体 + 战线推进 | Company of Heroes、Iron Harvest |
| **历史 RTS** | 真实文明 + 时代演进 | Age of Empires、Rise of Nations |
| **科幻 RTS** | 太空 / 未来战争 | StarCraft、Homeworld、Sins of a Solar Empire |
| **混合 RTS** | RTS + RPG / TBS | Warcraft III、Total War |
| **极简 RTS** | 去除微操，强调宏观 | Battle Aces、Bad North |
| **MOBA-Like 起源** | RTS 地图编辑衍生 | DotA（War3 mod）、Aeon of Strife |

### 六、核心系统设计

**1. 资源系统（Resource Model）**
- **离散采集**：工人采矿模式（StarCraft、AoE）
- **持续流动**：建筑直接产出（Total Annihilation、Supreme Commander）
- **控制点**：地图占领模式（Company of Heroes、DoW）
- **多元资源**：金/木/食物/石（AoE）vs 双资源（StarCraft 矿/气）

**2. 基地建设（Base Building）**
- **集中式**：所有建筑围绕主基地（C&C）
- **分散式**：可在地图任意建造（StarCraft Terran 飞房）
- **建造者类型**：工程车（C&C） vs 工人（SC/AoE） vs 自动建造（TA）
- **建筑功能**：生产 / 防御 / 科技 / 资源加工

**3. 科技树（Tech Tree）**
- **线性**：升级路径单一
- **分叉**：多路线选择（人族机械 vs 生化）
- **时代制**：AoE 的黑暗→封建→城堡→帝王
- **科技 = 战略选择**：升级时机决定胜负

**4. 单位与克制（Unit Counter）**
- **石头剪刀布**：步兵 → 弓兵 → 骑兵 → 步兵
- **属性克制**：轻甲 / 重甲 / 建筑 / 空军
- **种族不对称**：StarCraft 三族截然不同的玩法
- **英雄单位**：War3 引入的 RPG 元素

**5. 视野与侦察（Fog of War & Scouting）**
- **战争迷雾**：未探索 / 已探索 / 实时视野三层
- **侦察单位**：StarCraft 农民 / 隐刀 / 观察者
- **信息差就是胜负**：知道对手在做什么 = 一半胜利

**6. 微操系统（Micro）**
- **编队（Control Group）**：1–9 数字键
- **走位（Kiting）**：风筝、拉扯
- **技能释放（Spellcasting）**：法术单位的关键操作
- **阵型（Formation）**：弓在后、肉在前

**7. 宏观系统（Macro）**
- **生产周期（Production Cycle）**：建筑空闲 = 资源浪费
- **人口管理（Supply）**：StarCraft 的 Supply、AoE 的 Pop Cap
- **扩张时机（Expansion Timing）**：何时开新矿是核心决策
- **资源平衡（Resource Balance）**：囤积 vs 消耗的动态平衡

**8. APM 与 EPM**
- **APM（Actions Per Minute）**：每分钟操作数，韩国职业选手 300–400+
- **EPM（Effective APM）**：有效操作数，去除无意义点击
- **多线操作（Multitasking）**：A 处暴兵 + B 处侦察 + C 处骚扰
- **热键体系（Hotkey）**：键盘是 RTS 的真正武器

**9. 地图设计（Map Design）**
- **出生点（Spawn）**：双人/三人/四人对称
- **资源分布**：主矿 / 分矿 / 富矿
- **路口与隘口（Choke Point）**：防守的天然位置
- **高地与视野**：StarCraft 高地优势的经典设计

### 七、设计哲学

**Blizzard 学派（暴雪派）**：
- 极致平衡，多年迭代
- 不对称种族设计的奇迹
- 电竞导向，深度优先
- 代表：StarCraft I / II、Warcraft III

**Westwood / EA 学派（命令与征服派）**：
- 大众化、影视化
- 真人 FMV 过场
- 阵营对抗的强叙事
- 代表：Dune II、C&C、Red Alert

**Ensemble 学派（帝国时代派）**：
- 历史模拟、文明差异
- 时代演进的纵深感
- 慢节奏、长游戏时长
- 代表：Age of Empires 系列、AoM

**Relic 学派（英雄连派）**：
- 反传统采矿，控制点革命
- 战线、掩体、压制
- 战术写实主义
- 代表：Company of Heroes、Dawn of War

**Cavedog / GPG 学派（横扫千军派）**：
- 大规模物理战场
- 经济持续流动
- 单位无上限
- 代表：Total Annihilation、Supreme Commander

### 八、RTS 的"死亡"与争议

**为什么 2010 年后 RTS 衰落？**

1. **门槛过高**：APM 200+ 才能入门让休闲玩家望而却步
2. **MOBA 分流**：DotA / LoL 把 RTS 的"控制英雄"部分独立出来，更轻松
3. **挫败感强**：输了 30 分钟的 1v1 全是自己的责任，没法甩锅队友
4. **学习曲线陡峭**：建造序列、人口节点、兵种克制的庞大记忆量
5. **画面表现局限**：俯视角 + 小单位难以适应 3A 视觉时代
6. **设计师流失**：Blizzard、Westwood、Ensemble、Cavedog 相继解散或转型

**复兴的尝试**：
- **降低 APM 门槛**：Battle Aces 取消基地建设
- **强化叙事**：Iron Harvest、Tempest Rising
- **回归经典**：AoE II 决定版、AoE IV
- **众筹文艺复兴**：StormGate（前暴雪人）、ZeroSpace

> RTS 没有死，它**碎裂成了 MOBA、自走棋、塔防、Tactics**等多个后代。每个后代继承了它的一部分基因。

### 九、与其他类型的边界

| 对比类型 | 核心区别 |
|---------|---------|
| **TBS** | 回合 vs 实时；TBS 思考时间无限，RTS 时间即资源 |
| **MOBA** | MOBA 控制单一英雄无基建，RTS 多线宏观调度 |
| **Real-Time Tactics** | RTT 无基建无生产，纯战术指挥既有部队 |
| **Tower Defense** | TD 单位路径固定，RTS 动态战场 |
| **Grand Strategy** | GS 国家级宏观，RTS 战役级微观 |
| **City Builder** | CB 无对抗或弱对抗，RTS 军事对抗为核心 |

## 第二节：TBS（Turn-Based Strategy / 回合制战略）

### 一、定义

**TBS（Turn-Based Strategy，回合制战略）**：玩家与对手（AI 或其他玩家）**轮流行动**的策略游戏类型。每一回合内，玩家拥有**几乎无限的思考时间**，可以从容规划资源、调度单位、布置战术。游戏的核心张力来自**有限行动点 / 移动力 / 资源** 与 **无限可能性** 之间的取舍。

> **核心信条**："一步走错，满盘皆输。但你有的是时间想清楚。"

TBS 是策略游戏中**最古老、最纯粹**的形态——它直接继承了围棋、象棋、兵棋的血脉，是**思考者的游戏**。

### 二、核心特征（六大支柱）

1. **回合结构（Turn Structure）**：你动 → 我动 → 你动的清晰节奏
2. **思考时间无限**（或长限制）：奖励深度计算与远见
3. **行动点系统（Action Points / Movement Points）**：每回合的资源约束
4. **网格化战场（Grid-Based）**：六边形 / 方格 / 区域抽象
5. **完全信息或战争迷雾**：信息层级决定策略深度
6. **单位永久性（Persistence）**：单位损失通常不可逆，每个士兵都珍贵

### 三、隐藏的核心：决策的"纯净度"

RTS 的胜负受 APM、手速、操作精度影响；**TBS 把这些噪音全部剥离，只留下纯粹的决策本身**。

- **没有手速借口**：输了就是想错了
- **没有操作失误**：每一次点击都是深思熟虑的
- **没有时间压力**（多数情况）：你和对手智力的正面碰撞
- **每一回合都是棋谱**：可复盘、可分析、可学习

> TBS 是**最接近棋类**的电子游戏类型。它的对手不是"反应更快的人"，而是"想得更深的人"。

### 四、TBS vs 4X vs Tactics 的边界

这是策略游戏分类中**最容易混淆的三个概念**，需要先厘清：

| 类型 | 核心 | 尺度 | 代表 |
|------|------|------|------|
| **TBS（广义）** | 回合制 + 策略 | 任意 | 涵盖以下两者 |
| **4X** | 探索/扩张/开发/征服，宏观帝国 | 文明级、千年尺度 | Civilization、Master of Orion |
| **Tactics（SRPG）** | 小队战术，角色养成 | 战斗级、士兵尺度 | XCOM、火焰纹章 |
| **狭义 TBS** | 战役级，介于二者之间 | 战役 / 战场 | Heroes of Might & Magic、Wargame |

> **本节聚焦"狭义 TBS"——战役级回合制战略**。4X 与 Tactics 各有专章。

### 五、发展简史

**史前时代（1970s—1980s）**：
- **桌面兵棋的电子化**：Avalon Hill、SPI 公司的纸面兵棋是 TBS 直系祖先
- **《Tanktics》**（1978）、**《Computer Bismarck》**（1980，SSI）：最早的 TBS
- **《Eastern Front 1941》**（1981，Atari）：六边形 + 二战东线模板
- **《Empire》**（1977/1987）：早期 4X / TBS 雏形

**奠基期（1980s 末 — 1990s 初）**：
- **《文明（Civilization）》**（1991，Sid Meier）：4X 与 TBS 的双重奠基（详见 4X 章）
- **《大海军（Grand Admiral）》《将军（Panzer General）》**（1994，SSI）：**经典战役 TBS 范式**
  - 六边形地图、单位经验、战役链
  - 影响后续无数二战 TBS
- **《魔法门之英雄无敌（Heroes of Might and Magic）》**（1995，New World Computing）：**TBS 的另一条主脉**
  - 大地图探索 + 战场战斗的双层结构
  - 英雄 + 城镇 + 资源的奇幻 TBS 模板

**黄金时代（1990s 中后期 — 2000s 初）**：
- **《英雄无敌 II》**（1996）：系列美学定型
- **《英雄无敌 III》**（1999，3DO/NWC）：**TBS 的不朽经典**
  - 8 个城镇、上百英雄、千余魔法物品
  - 至今仍有活跃 MOD 社区与重制（HoMM III HD）
  - 战场战术与战略地图的完美双层结构
  - **被誉为"史上最伟大的 TBS 之一"**
- **《大将军：罗马的荣耀》《全面战争：幕府将军》**（2000，The Creative Assembly）：**全面战争系列起点**
  - 回合制战略地图 + 实时战术战斗的混合体
  - 重新定义"战略层 + 战役层"分离设计
- **《文明 III》**（2001）：4X 王朝继续
- **《银河文明（Galactic Civilizations）》**（2003）：太空 4X 复兴

**多元化与衰落期（2000s 中 — 2010s 初）**：
- **《英雄无敌 IV / V》**（2002/2006）：系列尝试转型，褒贬不一
- **《国王的恩赐（King's Bounty）》系列**（2008+）：HoMM 精神继承
- **《永恒之柱式 TBS 衰落**：3D 时代来临，TBS 显得过时
- **TBS 一度被视为"老人游戏"**

**复兴期（2010s）**：
- **《XCOM: Enemy Unknown》**（2012，Firaxis）：**Tactics TBS 的现代复兴**（详见 Tactics 章）
- **《文明 V》**（2010）/ **《文明 VI》**（2016）：4X 现代化标杆
- **《英雄无敌 VII》**（2015）：复兴失败，系列陷入沉寂
- **《钢铁雄心 IV》**（2016，Paradox）：大战略 TBS 现代典范
- **《幽浮 2》**（2016）：XCOM 续作，深化 Tactics TBS
- **《英雄无敌 III：玩家进化版（Horn of the Abyss）》**：MOD 社区接管系列

**当代繁荣（2020s）**：
- **《人类（Humankind）》**（2021，Amplitude）：文明的挑战者
- **《老世界（Old World）》**（2021，Mohawk）：Soren Johnson（文明 IV 设计师）的回归
- **《SpellForce: Conquest of Eo》**（2022）：奇幻 TBS 复兴
- **《迁徙：奥德赛》《Songs of Conquest》**（2023）：HoMM 精神继承的独立复兴
- **《Heroes of Might and Magic: Olden Era》**（2024 公布）：系列正统复活

### 六、子类型谱系

| 子类 | 特征 | 代表 |
|------|------|------|
| **战役级 TBS** | 单一战场或战役链 | Panzer General、Wargame |
| **奇幻 TBS** | 双层地图 + 英雄 + 魔法 | Heroes of Might & Magic、King's Bounty |
| **4X TBS** | 帝国级、千年尺度 | Civilization、Master of Orion |
| **战术 TBS（SRPG）** | 小队级、角色养成 | XCOM、Fire Emblem |
| **大战略 TBS** | 国家级、外交经济 | Hearts of Iron（半实时）、Old World |
| **混合 TBS** | TBS 战略 + RTS 战斗 | Total War 系列 |
| **Roguelite TBS** | 单局制 + 永久死亡 | Into the Breach、Slay the Spire（边界） |
| **棋盘式 TBS** | 高度抽象 + 简洁规则 | Chess、围棋类电子化 |

### 七、核心系统设计

**1. 回合结构（Turn Structure）**
- **严格交替**：A 行动完，B 行动（象棋模式）
- **同时回合（We-Go）**：双方同时下令，同时结算（Combat Mission）
- **行动点制（IGOUGO）**：每方一回合内有总点数
- **优先级 / 主动权（Initiative）**：单位根据速度排序行动（XCOM、火纹）

**2. 网格系统（Grid System）**
- **六边形（Hex）**：六个方向、距离更均匀（Civilization V/VI、Wargame）
- **方格（Square）**：四向或八向（火焰纹章、英雄无敌）
- **区域（Region）**：抽象大区域（Risk、HOI4）
- **无网格**：连续地图（部分大战略游戏）

**3. 行动点 / 移动力（Action / Movement Points）**
- **每单位独立移动力**：HoMM、XCOM
- **共享行动点**：整个军队池（部分兵棋）
- **双行动制**：移动 + 攻击 / 双移动 / 双攻击（XCOM）
- **疲劳与补给**：长距离移动有惩罚（Wargame、Old World）

**4. 战斗解算（Combat Resolution）**
- **确定性**：纯数值对比（围棋、象棋）
- **概率性**：命中率 + 暴击（XCOM 的命中率信仰危机）
- **战力对比**：双方战力数值结算（HoMM 战前预测）
- **位置加成**：高地、地形、背刺（XCOM、火纹）

**5. 单位经验与升级（Unit Progression）**
- **个体经验**：每个单位独立升级（火纹、XCOM）
- **类型升级**：整个兵种升级（HoMM）
- **指挥官加成**：英雄/将军提供 Buff（HoMM、Total War）
- **永久死亡（Permadeath）**：失去单位不可逆，提升决策重量

**6. 战略层与战术层**
- **单层 TBS**：只有一个尺度（火焰纹章主要是战术层）
- **双层 TBS**：大地图 + 战斗地图（HoMM、Total War）
- **三层 TBS**：帝国 / 战役 / 战斗（部分大战略）
- **尺度切换**：是 TBS 设计深度的标志

**7. 信息系统（Information）**
- **完全信息**：象棋、围棋
- **战争迷雾（Fog of War）**：未探索区域不可见
- **半信息**：知道单位位置不知组成（部分兵棋）
- **欺骗与误导**：假情报、伪装单位（Wargame）

**8. AI 设计**
- **TBS 是 AI 最难做的类型**：思考时间充足意味着 AI 必须"真的会思考"
- **作弊式 AI**：通过资源/视野作弊弥补智能不足（Civ 高难度）
- **脚本式 AI**：固定行为模式（多数 TBS）
- **机器学习 AI**：实验性方向（AlphaGo、AlphaStar 启发）

### 八、设计哲学

**Sid Meier 学派（文明派）**：
- "再来一回合"的成瘾循环
- 多系统交叉的有趣决策
- 历史浪漫主义
- 代表：Civilization 系列

**NWC 学派（英雄无敌派）**：
- 双层地图的优雅结构
- 收集与探索的乐趣
- 数学化的战场战术
- 代表：HoMM I—V

**SSI 学派（兵棋派）**：
- 历史真实性优先
- 复杂规则、硬核数值
- 战役链的连贯叙事
- 代表：Panzer General、Steel Panthers

**Firaxis / Julian Gollop 学派（XCOM 派）**：
- 概率紧张感
- 永久死亡 + 角色羁绊
- 简洁规则下的深度战术
- 代表：XCOM 系列、Phoenix Point

**Paradox 学派（大战略派）**：
- 国家级宏观模拟
- 外交、经济、内政交织
- 历史沙盒
- 代表：HOI4、EU4、CK3（半实时，但 TBS 精神）

**Creative Assembly 学派（全战派）**：
- 战略层 TBS + 战术层 RTS 的混合体
- 历史与奇幻的双线推进
- 大规模战场的视觉震撼
- 代表：Total War 系列

**Subset Games 学派（极简派）**：
- 完全信息、确定性
- 小规模、深度计算
- 谜题感强于战争感
- 代表：Into the Breach、FTL（边界）

### 九、TBS 的"快慢之争"

TBS 内部存在一个长期的**节奏哲学冲突**：

**慢派（深度优先）**：
- 一局可以打 20+ 小时（HoMM、Civ）
- 系统繁多，决策复杂
- 适合周末长开
- "策略游戏就该慢慢想"

**快派（凝练优先）**：
- 一局 30 分钟（Into the Breach）
- 规则极简，但深度极深
- 适合通勤碎片时间
- "策略游戏不是耐心比赛"

**当代趋势**：快派崛起。Slay the Spire、Into the Breach、Wildermyth 证明了**短时长 TBS 的商业可行性**，也让 TBS 重新吸引年轻玩家。

### 十、TBS 与"思考的乐趣"

TBS 在所有游戏类型中**最接近哲学**：

- **决策即叙事**：每一步选择都是你的故事
- **失败即学习**：复盘是 TBS 玩家的核心活动
- **耐心即美德**：奖励深思熟虑，惩罚冲动
- **想象力即引擎**：玩家在脑中预演十步之后的局面

> 玩 RTS 是"成为指挥官"，玩 TBS 是"成为军师"。

**Sid Meier 的名言**：
> "A game is a series of interesting decisions."（游戏是一系列有趣的决策。）

这句话**几乎是为 TBS 量身定做的**。当其他类型用动作、画面、叙事吸引玩家时，TBS 只用"决策"本身就能让你沉迷数百小时。

### 十一、与其他类型的边界

| 对比类型 | 核心区别 |
|---------|---------|
| **RTS** | 实时 vs 回合；RTS 比手速，TBS 比思考 |
| **4X** | 4X 是 TBS 的子集，强调宏观帝国管理 |
| **Tactics（SRPG）** | Tactics 是 TBS 的子集，强调小队战术 + 角色养成 |
| **Real-Time Tactics** | RTT 实时 + 无基建，TBS 回合 + 可有基建 |
| **桌游 / 棋类** | TBS 是棋类的电子化扩展，规则更复杂 |
| **Roguelike** | TBS 关注单局策略，Roguelike 关注 Run-based 进度 |
| **大战略** | 多数大战略是"准实时"（可暂停），介于 TBS 与 RTS 之间 |

## 第三节：4X（eXplore, eXpand, eXploit, eXterminate）

### 一、定义

**4X**：以**探索（Explore）、扩张（Expand）、开发（Exploit）、征服（Exterminate）**四大行为循环为核心的策略游戏子类型。玩家从一个小部落 / 一颗星球 / 一座城市起步，**经营一个文明从诞生到霸权（或灭亡）的全过程**。

> **核心信条**："从石器到星辰，从一城到一国，让你的文明屹立于历史长河。"

4X 是策略游戏中**最宏大、最史诗、最沉迷**的类型——它让玩家扮演**上帝、君主、元首、议会**的复合体，用上百小时书写一段虚构历史。

### 二、四个 X：词源与核心

**4X** 由游戏记者 **Alan Emrich** 在 1993 年评测《**Master of Orion**》时首创：

| X | 含义 | 玩家行为 |
|---|------|---------|
| **eXplore** | 探索 | 派遣斥候 / 飞船揭开地图迷雾，发现资源、奇观、邻居 |
| **eXpand** | 扩张 | 建立新城市 / 殖民地，占领土地、资源点 |
| **eXploit** | 开发 | 经营城市，发展科技、生产、文化、宗教、经济 |
| **eXterminate** | 征服 | 击败对手，无论通过军事、文化、外交还是科技 |

> 这四个动词**不是阶段，而是循环**——整局游戏中你会反复在四者间切换。

### 三、核心特征（七大支柱）

1. **文明级尺度**：管理国家 / 帝国 / 银河文明，跨越千年
2. **回合制为主**（少数实时 / 半实时，如 Stellaris）
3. **多胜利路径**：军事、科技、文化、外交、经济、宗教、超越
4. **科技树（Tech Tree）**：贯穿整局的进步系统
5. **城市 / 殖民地管理**：基础经济单元
6. **多文明对抗**：通常 4—16 个 AI 或玩家文明
7. **程序生成地图**：每局世界都不同，重玩性极强

### 四、隐藏的核心："再来一回合"成瘾循环

4X 的真正魔力不在系统，而在**心理学**：

> **"Just one more turn."**（再来一回合就睡。）

这句话是 Sid Meier 设计 Civilization 时的核心目标，也是 4X 玩家被反复诅咒的咒语：

- **下一回合科技就好了**
- **下一回合城市就建成了**
- **下一回合就能拿下那座城**
- **下一回合那个奇观就到手了**
- **……天亮了。**

这是 4X 类型最强大也最危险的特性——它通过**多线并行的短期目标**，让玩家永远找不到自然的"停手点"。一局 4X 通常要 **8—40 小时**，多人局动辄数十小时。

### 五、发展简史

**史前时代（1970s—1980s）**：
- **桌游《文明（Civilization）》**（1980，Francis Tresham）：4X 的精神祖先，Sid Meier 后来获得授权
- **《Reach for the Stars》**（1983，SSG）：太空 4X 雏形
- **《Empire》**（1977/1987，Walter Bright）：早期帝国扩张游戏
- **《Civilization》桌游版的电子化未遂**：版权混乱

**奠基年代（1991—1996）**：
- **《Civilization》**（1991，Sid Meier，MicroProse）：**类型奠基之作**
  - 从 4000 BC 到太空时代的史诗
  - 科技树、奇观、外交、文化基础
  - 全部 4X 元素首次集成
- **《Master of Orion》**（1993，SimTex）：**太空 4X 奠基**
  - "4X" 一词正是为评测它而创造
  - 种族特性、舰船自定义、银河外交
- **《Master of Magic》**（1994，SimTex）：奇幻 4X 雏形
  - 双世界（物理/魔法）、法师对抗
  - 影响后来 Age of Wonders、Endless Legend
- **《Civilization II》**（1996，MicroProse）：**4X 黄金范式定型**
  - 等距视角、外交动画、议会
  - 至今仍被许多老玩家视为系列最佳

**多元化（1996—2003）**：
- **《Master of Orion II》**（1996）：太空 4X 巅峰
- **《Alpha Centauri》**（1999，Sid Meier / Brian Reynolds）：**4X 叙事巅峰**
  - 文明续作未获版权后的"精神续作"
  - 七大派系各有意识形态（环保、军国、科学、神权、市场、人本、生存）
  - 哲学引言、未来科技树、深度叙事
  - 被誉为"最好的 4X"之一
- **《Civilization: Call to Power》**（1999，Activision）：版权乱战中的支线
- **《Sid Meier's Civilization III》**（2001，Firaxis）：文化扩张、战略资源引入
- **《Galactic Civilizations》**（2003，Stardock）：太空 4X 复兴

**Firaxis 王朝（2005—2016）**：
- **《Civilization IV》**（2005，Soren Johnson）：**许多人心中的 4X 巅峰**
  - 宗教系统、伟人系统、内政滑块
  - Leonard Nimoy 配音的科技解锁
  - 主题曲《Baba Yetu》获格莱美奖
  - MOD 社区无比繁荣（Fall from Heaven 2 等传奇 MOD）
- **《Civilization V》**（2010）：**六边形革命**
  - 方格 → 六边形
  - "一格一单位"（1UPT）取消单位堆叠
  - 城邦系统、社会政策
  - 争议巨大但影响深远
- **《Civilization: Beyond Earth》**（2014）：Alpha Centauri 精神续作（口碑平平）
- **《Civilization VI》**（2016，Ed Beach）：**区域系统革命**
  - 城市从一格扩展为多格区域（Districts）
  - 地形规划成为核心玩法
  - 卡通画风争议
  - DLC 时代之王（《Rise and Fall》《Gathering Storm》）

**Paradox 与"伪 4X"崛起（2010s）**：
- **《Stellaris》**（2016，Paradox）：**实时 4X 革命**
  - Paradox 大战略引擎 + 4X 框架
  - 实时但可暂停，跨越 4X 与大战略边界
  - 故事事件、远古遗迹、危机
- **Endless 系列（Amplitude）**：
  - **《Endless Space》**（2012）/ **《Endless Space 2》**（2017）
  - **《Endless Legend》**（2014）：奇幻 4X 杰作，独特种族
  - **《Humankind》**（2021）：文明的直接挑战者

**多元化与挑战者时代（2020s）**：
- **《Old World》**（2021，Mohawk Games）：Soren Johnson（Civ IV 设计师）回归
  - 君主继承、家族政治、性格特质
  - 角色羁绊融入 4X
- **《Humankind》**（2021）：文化叠加系统，每个时代选择不同文化
- **《Distant Worlds 2》**（2022）：实时太空 4X
- **《Terra Invicta》**（2022）：现代地球 + 太空 4X 跨界
- **《Civilization VII》**（2025）：Firaxis 系列重启
  - 三时代结构（古代 / 探索 / 现代）
  - 每时代选择不同文明（争议巨大）
  - 评价两极分化

### 六、子类型谱系

| 子类 | 时空设定 | 代表 |
|------|---------|------|
| **历史 4X** | 真实地球历史 | Civilization 系列、Humankind、Old World |
| **太空 4X** | 银河、星际 | Master of Orion、Stellaris、Galactic Civilizations、Endless Space |
| **奇幻 4X** | 魔法世界 | Master of Magic、Age of Wonders、Endless Legend、Fallen Enchantress |
| **架空 4X** | 未来 / 平行世界 | Alpha Centauri、Beyond Earth、Pandora |
| **历史精确 4X** | 特定时代 | Old World（古代地中海）、Field of Glory: Empires |
| **轻量 4X / 4X-Lite** | 简化、短局 | The Battle of Polytopia、Hexarchy |
| **混合 4X** | 跨类型融合 | Total War（4X + RTS）、Stellaris（4X + 大战略） |

### 七、核心系统设计

**1. 探索系统（Explore）**
- **战争迷雾**：未知 → 已知地形 → 已知敌情 三层
- **斥候单位**：早期专属探索单位
- **奇观与遗迹**：探索奖励（部落村庄、远古遗物）
- **地图类型**：泛大陆、群岛、星云、随机

**2. 扩张系统（Expand）**
- **城市奠基**：选址博弈（资源、地形、防御）
- **边界扩张**：文化 / 影响力 / 直接占领
- **殖民竞速**：早期最关键的战略
- **扩张惩罚**：避免无脑扩张（腐败、不快乐、维护成本）
  - Civ IV 的"维护费"
  - Civ V 的"幸福度上限"
  - Civ VI 的"宜居度"
  - Stellaris 的"行政容量"

**3. 开发系统（Exploit）**
- **科技树**：4X 的脊柱
  - 线性树（早期文明）
  - 网状树（Civ V/VI）
  - 时代制（Humankind）
  - 随机研发（Stellaris）
- **城市建造**：建筑、奇观、单位生产队列
- **资源管理**：食物、生产、金钱、科学、文化、信仰
- **改良地块**：农场、矿山、港口、奇观加成
- **贸易路线**：城市间 / 文明间经济网络

**4. 征服系统（Exterminate）**
- **军事单位**：从战士到机甲的全谱系
- **军事胜利**：占领所有 / 关键城市
- **非军事征服**：
  - **科学胜利**：太空船、超越
  - **文化胜利**：旅游业 / 影响力压制
  - **外交胜利**：联合国 / 银河议会
  - **宗教胜利**：信仰扩散
  - **经济胜利**：财富 / 公司主导

**5. 多胜利路径设计哲学**
> 4X 设计的核心难题：**让所有路径同样有趣**。

- 早期 4X 几乎只有军事胜利
- Civ IV 开始平衡多路径
- Civ VI 有 6 种胜利方式
- **每种路径需要独特玩法循环，否则沦为装饰**

**6. 外交系统**
- **AI 文明性格**：好战、外交、商人、孤立
- **协议**：贸易、研究、防御同盟、互不侵犯
- **关系数值**：好感、警告、敌对
- **宣战借口**：从无理由（Civ III）到正义战争（Civ VI）
- **争议**：4X 的外交 AI **几乎没有令人满意的实现**

**7. 文明 / 派系特性（Asymmetry）**
- **领袖特质**：每个文明的独特能力
- **独特单位与建筑（UU/UB）**：替代标准单位 / 建筑
- **起始偏好**：地形、地理位置加成
- **平衡哲学**：差异化优先于绝对平衡
- **趋势**：从"轻微差异"（Civ III）到"玩法重塑"（Civ VI、Endless Legend）

### 八、4X 的"中后期问题"

4X 类型存在一个**几乎无法根治的设计顽疾**：

**前期：高潮**
- 探索新大陆，遇见邻居
- 每个决策都关键
- 资源稀缺，选择困难

**中期：高峰**
- 文明成型，外交博弈
- 战争与建设并行
- 决策最丰富

**后期：崩溃**
- 胜负已定但游戏未结束
- 微管理城市数量爆炸
- 回合等待时间变长
- "Just one more turn" 变成 "终于打完了"

**业内称为"4X 后期疲劳（Late-game Slog）"**。各种解法：

- **自动化**：Civ VI 的城市总督、自动建造
- **强制收尾**：Stellaris 的"危机"系统（虚空魔虫、机器叛乱、域外银河来客）
- **时代切换**：Humankind / Civ VII 的"重置"机制
- **回合上限**：到了某回合根据分数判胜负
- **缩短中后期**：Old World 的"野心"系统加速进程

**没有任何 4X 完美解决了这个问题**，它几乎是类型本身的代价。

### 九、设计哲学的两大流派

**Sid Meier 派（"有趣的决策"）**：
- 系统服务于玩家选择
- 简洁规则，深度涌现
- 平衡 AI 体验与可玩性
- "如果一个系统不带来有趣决策，砍掉它"
- 代表：Civilization 系列、Old World

**Paradox / Amplitude 派（"模拟即叙事"）**：
- 系统本身产生故事
- 复杂规则，玩家需学习
- 可读性让位于真实感 / 戏剧性
- "让世界自己讲故事"
- 代表：Stellaris、Endless Legend

> 两派没有优劣，但**目标受众不同**：前者吸引广义策略玩家，后者吸引硬核模拟爱好者。

### 十、4X 的"涌现叙事"魅力

4X 不靠剧本写故事——**故事在玩家与系统的互动中自然涌现**：

- 你的祖先是渔猎部落，定居在一座岛上
- 你与海对岸的中国签订了千年友谊
- 一场火山喷发摧毁了你的奇观之城
- 你的最后一块殖民地在外星人入侵中陷落
- 你的太空船在最后一回合发射成功

这些故事**没有写在任何脚本里**，但每个 4X 老玩家都能讲出几十个。这是 4X 与传统叙事游戏的根本区别——**它给你的不是故事，而是讲故事的能力**。

> Stellaris 老玩家间流传的"我的银河史诗"长帖、Civ 玩家的"AAR（After Action Report）"文化，都是这种涌现叙事的产物。

### 十一、4X 与其他类型的边界

| 对比类型 | 核心区别 |
|---------|---------|
| **TBS** | 4X 是 TBS 的子集，但更强调宏观帝国管理 |
| **大战略** | 大战略多为实时（可暂停），起点为成熟国家而非起源；4X 跨越文明全周期 |
| **RTS** | RTS 单局短、战术为主；4X 单局长、战略为主 |
| **City Builder** | City Builder 没有"对手文明"和征服维度 |
| **Tactics** | Tactics 是小队尺度；4X 是文明尺度 |
| **桌游 Civ** | 电子 4X 继承桌游精神，但加入实时计算与隐藏信息 |

### 十二、平台与文化分布

**PC 优势绝对**：
- 4X 几乎是 **PC 独占类型**
- 长时长 + 鼠标精度 + 大屏幕信息量
- 主机版多为妥协（Civ VI 主机版受好评但属例外）

**手游 4X**：
- **简化 4X**：Polytopia（短局精品）
- **氪金 4X**：Game of War、State of Survival、Rise of Kingdoms（伪 4X，本质 SLG）
  - "4X 皮 + 滚服 + 联盟战争"模型
  - 商业上极其成功，但与传统 4X 几乎是两个东西

**地区文化偏好**：
- **欧美**：历史 4X（Civ）、太空 4X（Stellaris）的核心市场
- **东亚**：策略手游 SLG 主导，传统 4X 受众较小
- **东欧**：4X 与大战略的强势市场（Paradox 受众基本盘）

## 第四节：Grand Strategy（大战略）

### 一、定义

**Grand Strategy（大战略，简称 GS / GSG）**：以**国家 / 政权**为操作单位，在**真实历史时空**中，通过**实时但可暂停**的方式同时管理**军事、外交、经济、内政、科技、宗教、文化**等多维度的策略游戏类型。

> **核心信条**："你不是将军，你是国家本身。从教皇的破门令到士兵的口粮，从王朝的联姻到农民的赋税——历史在你手中重写。"

大战略是策略游戏中**最复杂、最硬核、最劝退、也最迷人**的类型。它不取悦玩家，它**邀请玩家进入历史**。

### 二、词源与流派归属

**"Grand Strategy"** 一词源自军事学术语，由军事理论家 **Basil Liddell Hart** 在 20 世纪中期推广，指**国家层面统筹一切资源以达成政治目标的最高战略**——超越纯军事的"战略（Strategy）"，包含经济、外交、宣传等所有国家工具。

游戏类型借用此词，强调：

- **超越纯战争**：战争只是工具之一
- **国家视角**：玩家是"国家意志"，而非将军 / 元首个人
- **历史尺度**：通常跨越数十年至数百年

### 三、与 4X 的关键区别

大战略与 4X 常被混淆，但**设计哲学根本不同**：

| 维度 | 4X | Grand Strategy |
|------|-----|---------------|
| **起点** | 一个部落 / 一颗星球（从无到有） | 一个成熟国家（已有历史） |
| **设定** | 多为虚构 / 程序生成 | **真实历史地图与国家** |
| **时间制** | 回合制为主 | **实时可暂停** |
| **胜利条件** | 明确（科技/文化/军事胜利） | **通常无明确胜利**（沙盒） |
| **核心驱动** | 系统涌现 | **历史叙事 + 系统涌现** |
| **失败定义** | 文明灭亡 | 国家解体 / 玩家自定 |
| **玩家心态** | "建立伟大文明" | "**改写历史**" |
| **学习曲线** | 陡 | **悬崖** |
| **代表** | Civilization、Stellaris | EU、CK、HOI、Victoria |

> 一个粗略但有效的判别：**4X 问"我能建立怎样的文明？"，大战略问"如果我是路易十四 / 斯大林 / 拜占庭皇帝，会怎样？"**

### 四、核心特征（八大支柱）

1. **实时可暂停（Real-Time with Pause, RTwP）**：游戏时间持续流动，可暂停 / 调速（1—5 倍速）
2. **真实历史地图**：精确还原省份、地形、人口、文化、宗教
3. **历史起始日期**：通常多个起始点（如 EU4 的 1444、1492、1618、1700 等）
4. **沙盒玩法**：无脚本剧情，历史由玩家与 AI 共同生成
5. **多层系统耦合**：经济影响军事影响外交影响内政……牵一发动全身
6. **国家任意切换**：从西班牙到霍尔木兹，从拜占庭到尼泊尔，**任何国家可玩**
7. **MOD 友好**：从历史精确到完全幻想（魔戒、冰与火、星战）
8. **DLC 长青模型**：游戏发售只是开始，10 年迭代是常态

### 五、Paradox Interactive：大战略的代名词

讨论大战略**绕不开 Paradox Interactive**——这家瑞典公司**几乎以一己之力定义了现代大战略**。

**起源**：
- **Paradox Entertainment** 原是瑞典桌游公司
- 1995 年开发桌游《Svea Rike》（瑞典帝国主题）
- 1999 年成立电子游戏部门
- **Johan Andersson**（核心设计师）开发《Europa Universalis》

**Clausewitz 引擎**（以普鲁士军事理论家克劳塞维茨命名）：
- Paradox 的专属引擎
- 支持复杂的省份地图、AI、嵌套系统
- 多代大战略共用此引擎及其后续版本

**四大旗舰系列**：
- **Europa Universalis（EU）**：1444—1821，近代国家形成
- **Crusader Kings（CK）**：867—1453，中世纪封建王朝
- **Hearts of Iron（HoI）**：1936—1948，二战
- **Victoria**：1836—1936，工业革命与帝国主义

**这四作覆盖了人类历史 867—1948 共一千年**——玩家可以从查理曼后裔玩到希特勒投降。

### 六、发展简史

**史前时代（1980s—1990s）**：
- **桌面战棋传统**：Avalon Hill、SPI 的历史战棋（《俄罗斯战役》《Third Reich》）是精神祖先
- **《Balance of Power》**（1985，Chris Crawford）：冷战大战略雏形，**首个真正的"国家级"游戏**
  - 没有军事单位移动，只有外交决策
  - "你赢得游戏的方式是不输掉它"
- **《Hidden Agenda》**（1988）：第三世界国家治理模拟
- **《Conflict: Middle East Political Simulator》**（1990）
- **《Imperialism》**（1997，SSI）：经济 / 殖民大战略
- **《Imperialism II》**（1999）

**Paradox 黎明（2000—2007）**：
- **《Europa Universalis》**（2001，Paradox）：**类型奠基**
  - 改编自法国同名桌游（1993）
  - 1419—1820 的近代历史沙盒
  - 实时可暂停 + 省份地图开创性结合
- **《Hearts of Iron》**（2002）：二战大战略
- **《Victoria: An Empire Under the Sun》**（2003）：人口模型 + 工业化
- **《Crusader Kings》**（2004）：**封建王朝模拟**
  - 玩"角色"而非"国家"——王朝继承、家族阴谋
  - 与三大兄弟系列形成互补
- **《Europa Universalis II》**（2001）/ **《III》**（2007）
- **《Hearts of Iron II》**（2005）★：HoI 系列口碑高峰
- **《Victoria II》**（2010）★：Victoria 系列口碑高峰

**黄金时代（2012—2020）**：
- **《Crusader Kings II》**（2012）★：**Paradox 历史性突破**
  - 角色 RPG + 大战略融合
  - "我女儿被法国国王俘虏，我儿子是私生子，我老婆毒死了我兄弟"——CK2 的玩家故事数不胜数
  - 12+ 年持续更新，几十个 DLC
  - **大战略真正"破圈"的作品**
- **《Europa Universalis IV》**（2013）★：**EU 系列至今的标杆**
  - 12+ 年仍在更新
  - 殖民、贸易、科技、外交全面成熟
  - "玩烂了 EU4"成为大战略玩家的勋章
- **《Hearts of Iron IV》**（2016）：**HoI 现代化**
  - 战线系统、师团编辑器
  - 国家专注树（Focus Tree）
  - 销量大爆，吸引大量新人入坑大战略
- **《Stellaris》**（2016）：**4X × 大战略跨界**（详见第三节）
- **《Imperator: Rome》**（2019）：罗马共和国主题
  - 发售口碑灾难
  - 经过几次大改版后稳定，但开发暂停（2021）
- **《Crusader Kings III》**（2020）★：
  - CK2 的精神继承 + 现代化界面
  - 3D 角色、性格特质系统重构
  - 入门门槛大幅降低，新玩家友好

**多元化与挑战（2020s）**：
- **《Victoria 3》**（2022）：
  - 利益集团、政治改革、市场经济
  - 评价两极——硬核玩家觉得"不像 Victoria"，新玩家觉得"经济模拟惊艳"
- **《Hearts of Iron IV》持续 DLC 化**：到 2025 年仍是主力
- **《Europa Universalis V》**（2025 公布）：传闻中的次世代 EU
- **挑战者们**：
  - **《Old World》**（2021）：Civ + CK 的混血（详见第三节）
  - **《Field of Glory: Empires》**（2019）：Slitherine 的轻量大战略
  - **《Shadow Empire》**（2020）：硬核科幻大战略
  - **《Terra Invicta》**（2022）：现代地球 + 太空大战略
  - **《Ara: History Untold》**（2024）：微软入局，定位 Civ 与大战略之间

### 七、四大 Paradox 主系列详解

**1. Europa Universalis（EU）—— 国家**
- **时代**：1444—1821（近代）
- **核心**：贸易、殖民、宗教改革、领土扩张
- **操作单位**：国家（你是抽象的"国家意志"）
- **关键系统**：
  - **君主点数**（行政 / 外交 / 军事）：所有决策的通货
  - **核心 / 宣称**：领土合法性
  - **贸易节点**：全球经济网络
  - **Aggressive Expansion**：扩张过快引发联军
- **经典体验**：以小国（如奥斯曼附属国）翻盘称霸；扮演拜占庭复国；发现并殖民新大陆
- **风格**：冷静、宏观、战略

**2. Crusader Kings（CK）—— 角色**
- **时代**：867—1453（中世纪）
- **核心**：王朝政治、继承、阴谋、宗教
- **操作单位**：**角色**（你是某个具体的国王 / 公爵 / 伯爵）
- **关键系统**：
  - **特质系统**：性格、技能、缺陷
  - **继承法**：长子继承 / 分割继承 / 选举……
  - **阴谋**：暗杀、勾引、捏造、绑架
  - **生命模拟**：生育、教育、衰老、死亡
- **经典体验**：玩 800 年家族传奇；通过联姻、暗杀建立大帝国；意外的私生子继承毁掉一切
- **风格**：戏剧性、个人化、**叙事最强的大战略**
- **梗文化**：CK 玩家的"我把女儿嫁给了马"是类型标志性段子

**3. Hearts of Iron（HoI）—— 战争**
- **时代**：1936—1948（二战）
- **核心**：军事、生产、战线、科技
- **操作单位**：国家，但聚焦于军事机器
- **关键系统**：
  - **师团编辑器**：自定义部队编制
  - **战线 / 战役计划**：AI 辅助的战术执行
  - **国家专注树**：历史 / 替代历史路径
  - **生产线 + 装备库**：工业战争模拟
- **经典体验**：让中国统一全球；让墨西哥征服美国；扮演秘鲁建立印加帝国
- **风格**：紧张、战术、军事核心
- **新人友好度**：四大系列**最高**，许多人从 HoI4 入坑

**4. Victoria —— 社会**
- **时代**：1836—1936（工业革命—一战后）
- **核心**：人口、工业、政治、经济- **操作单位**：国家，但**人口（POP）是主角**
- **关键系统**：
  - **POP 系统**：每个省份的人口分文化、宗教、职业、识字率、政治诉求
  - **利益集团**（Vic3）：地主、工业家、知识分子、工会、军队……
  - **市场经济**：商品供需、价格波动、贸易关系
  - **政治改革**：选举权、奴隶制、女性权利、劳工法
  - **意识形态光谱**：保守、自由、社会主义、共产主义、法西斯
- **经典体验**：把清朝改革成君主立宪制；让赞比亚成为工业强国；亲历 1848 革命浪潮
- **风格**：**最"非战争"**的大战略——你可以全程不打仗
- **门槛**：经济与政治系统极复杂，**四大系列最劝退**

> **简记法**：
> - **EU**：你是**国家**
> - **CK**：你是**人**
> - **HoI**：你是**军队**
> - **Vic**：你是**社会**

### 八、Paradox DLC 模式：争议与革命

Paradox 开创了一种**独特的商业模式**，深刻影响了整个游戏行业：

**模式特征**：
- 本体游戏发售后**持续 5—15 年**更新
- 大型 DLC（资料片）+ 免费补丁交替推送
- DLC 通常解锁新机制（如 EU4 的"贸易公司"、CK3 的"北方诸神"）
- 免费补丁同步加入新地图、平衡调整、bug 修复
- "**订阅服务**"：Paradox 后期推出 DLC 月费订阅

**优点**：
- 老玩家**永不离开**——游戏体验持续进化
- 游戏寿命远超普通 3A（EU4 至 2025 年仍在出 DLC）
- 形成**强社群粘性**

**争议**：
- 完整体验需购买**几百美元 DLC**，新人门槛高
- 部分核心机制被锁在 DLC 后（"付费机制" vs "付费内容"之争）
- "Paradox 税"：玩家戏称的累计 DLC 成本
- 折扣促销 + DLC 包裝缓解但未根除问题

**影响**：
- Total War、Civilization、城市天际线等系列**部分借鉴**此模式
- 但 Paradox 的执行**最极端、最完整**

### 九、社群文化：大战略玩家的特殊生态

大战略玩家是**所有游戏类型中最"病"的群体之一**（褒义）。

**典型特征**：
- 单局动辄**几十至几百小时**
- 维基 / 论坛使用率**极高**
- "我玩了 2000 小时还是新手"是真实状态
- 沉迷读历史书 / 看历史 YouTube
- 学过的奇怪知识：神圣罗马帝国选帝侯制度、奥斯曼禁卫军体制、英国谷物法

**社群中心**：
- **Reddit**：r/paradoxplaza、r/eu4、r/CrusaderKings、r/hoi4 等
- **Paradox 官方论坛**：MOD 与攻略大本营
- **YouTube**：
  - **历史向**：The Red Hawk、Spiffing Brit（EU4 玩烂了）
  - **教程向**：Generalist Gaming、Florry（HoI4）
  - **叙事向**：One Proud Bavarian（CK3 故事）
- **Steam 创意工坊**：MOD 发布主阵地
- **中文社群**：贴吧（P 社吧、HOI4 吧）、NGA、3DM、B 站

**文化梗**：
- "**One more turn**"（虽然大战略不是回合制，但意思相同）
- "**Just a small war**"（结果打成 50 年大战）
- "**Bohemia stronk**"（小国称霸的执念）
- "**Byzantium reborn**"（重建拜占庭是 EU4 玩家的圣杯）
- "**Heir is bisexual**"（CK 角色随机特质带来的故事）
- "**Italy did nothing wrong**"（HoI4 意大利的迷因）

**MOD 文化**：
大战略是 **MOD 最繁荣的类型之一**：
- **历史精确派**：MEIOU and Taxes（EU4，超硬核历史）、The Great War（HoI 一战）
- **架空历史**：Kaiserreich（HoI4，德国赢了一战）★——本身已成传奇
- **奇幻 IP**：
  - **A Game of Thrones**（CK2/CK3，冰与火之歌）
  - **Elder Kings**（CK，上古卷轴）
  - **The Lord of the Rings: Realms in Exile**（CK3）
- **科幻**：Star Wars: Fallen Republic（HoI4）

> Kaiserreich 的口碑甚至超过部分 Paradox 本体——它讲述"如果德意志帝国赢了一战"的世界，已被改编为小说、漫画，形成独立 IP。

### 十、设计哲学：历史模拟 vs 玩家自由

大战略最深层的设计张力：

**历史模拟派**：
- 还原历史进程是首要目标
- AI 应推动历史"自然发展"
- 玩家是历史的参与者，而非主宰
- 代表：早期 Paradox、HoI3、Vic2

**玩家叙事派**：
- 玩家的故事高于历史还原
- 系统应支持"任何疯狂操作"
- "如果秘鲁征服世界"也应有趣
- 代表：HoI4、CK3、EU4 后期

**Paradox 自身**也在两派间摇摆。CK3 大幅倾向后者（角色叙事），Vic3 试图回归前者（社会模拟），EU4 居中平衡。

> 这是大战略的根本悖论：**严格历史还原会让游戏变成"看历史频道"，完全自由会让游戏变成"换皮 4X"**。优秀大战略走在两者之间的钢丝上。

### 十一、AI 问题：大战略永恒的痛

大战略 AI 是**所有策略游戏中最难做的**：

**AI 必须同时处理**：
- 数百个国家的决策
- 经济、军事、外交、内政、科技多线
- 长期战略与短期战术平衡
- 与盟友 / 对手的复杂博弈

**结果**：
- AI 在大多数情况下**做出"差不多过得去"的决策**
- 玩家学会规则后**很容易碾压 AI**
- 高难度通过给 AI 经济 / 军事**加成**实现，而非提升智能
- "**AI 用作弊代替智能**"是大战略不可言说的秘密

**改进尝试**：
- HoI4 的"AI 战略行为"系统
- Vic3 的市场 AI 自动调节
- CK3 的角色 AI 与目标驱动
- 机器学习 AI 仍未真正进入大战略（成本过高，难调试）

> 大战略玩家最终接受了一个事实：**AI 不是对手，历史进程才是对手；多人游戏才是真正的考验**。

### 十二、多人游戏：大战略的终极形态

**单人 vs 多人**：
- 单人：与 AI 和系统博弈，**叙事驱动**
- 多人：与人类博弈，**博弈驱动**

**多人体验**：
- **小型局**：3—8 人，朋友间，3—10 小时一局
- **MP 大型局**：32 人，组织化，**单局可达数月**
- **MP 联赛 / 锦标赛**：HoI4 与 EU4 都有正规赛事

**著名 MP 社区**：
- **TheGameSomeday**：YouTube 大型 HoI4 / EU4 多人赛事录播
- **MP 联盟**（如 Forced Coexistence）：组织化大战略多人

**MP 体验的独特性**：
- 真实的外交博弈（人类比 AI 复杂得多）
- 真实的背叛、联盟、谈判
- 真实的历史"再现"——每一局都是新的历史
- **唯一能让大战略 AI 显得无关紧要的玩法**

### 十三、外延与边界作品

**纯大战略外的"准大战略"**：

- **Total War 系列**：回合制大战略 + 实时战术战斗
  - 战略层是简化大战略
  - 战术层是 RTS
  - **战役 + 战斗双层结构**让其独树一帜
  - 代表：Medieval II、Shogun 2、Three Kingdoms、Warhammer 系列
- **Distant Worlds 系列**：太空大战略 + 4X 混合
- **Supreme Ruler 系列**：现代地缘政治大战略
- **Geopolitical Simulator / Power & Revolution**：极硬核现代政治模拟
- **Terra Invicta**（2022）：地缘政治 + 太空 4X，**类型混血极佳**
- **Sengoku Jidai**（Slitherine）：日本战国大战略
- **Field of Glory: Empires**：罗马时代轻量大战略
- **Strategic Command 系列**：现代战棋 + 大战略

**Paradox 之外的"传统大战略"几乎不存在**——这是 Paradox 几乎垄断的领域。

### 十四、为什么大战略让人沉迷？

**几个深层原因**：

1. **历史亲历感**：你不是读历史，你**就是**历史
2. **多维度决策**：每一个选择都牵动十几个系统
3. **极长游戏节奏**：100 小时的史诗叙事远超任何 RPG
4. **学习永无止境**：每次开局都发现新机制
5. **故事属于自己**：没有任何剧本，每一局都是独一无二的历史
6. **真实世界的镜像**：玩 Vic 后看现代经济新闻会有不同视角；玩 HoI 后理解二战会更立体
7. **"知识感"**：大战略玩家会**真的学到历史**

> 一位老玩家的总结："**我从 EU4 学到的欧洲历史，比大学课堂多十倍。**"
> 
> 这不是夸张——大战略玩家普遍对历史地理的熟悉度远超平均水平。

### 十五、大战略的未来

**当下挑战**：
- 入门门槛极高，新玩家流失
- AI 提升瓶颈
- DLC 模式的争议
- Vic3 的口碑分化提示了"过度复杂化"风险

**可能方向**：
- **机器学习 AI**：未来 5—10 年可能突破
- **现代题材**：冷战、当代地缘政治大战略仍是蓝海
- **跨类型融合**：大战略 + RPG（如 CK3 的延伸）、大战略 + 4X（如 Stellaris）、大战略 + Roguelike？
- **VR / 沉浸式**：极远期可能性
- **AI 生成内容**：动态事件、动态历史叙事

**Paradox 之外的潜力**：
- 微软入局（Ara）

## 第五节：Wargame（兵棋 / 战棋）

### 一、定义

**Wargame（兵棋，也译"战棋"）**：以**真实或可信军事冲突**为题材，**精确模拟军事行动**的策略游戏类型。它是策略游戏中**最古老、最硬核、最学术**的一支。

> **核心信条**："战争是科学，不是艺术。每一发炮弹都有概率，每一次行军都有距离，每一个决策都有代价。"

### 二、词源与谱系

**"Wargame"** 一词原指**军事训练用的沙盘推演**，最早可追溯至 19 世纪初普鲁士军队的 **"Kriegsspiel"**（战争游戏，1812）——总参谋部用于训练军官的桌面推演系统。

电子兵棋是这一军事传统的**直接数字化后裔**，与"娱乐性策略游戏"相比，更接近**军事专业工具**。

**关键血脉**：
- **军用兵棋**：兰德公司、美军 TACSPIEL、苏军推演系统
- **桌面兵棋**：Avalon Hill（1958 起）、SPI、GMT Games
- **电子兵棋**：1980s 至今，PC 平台为主

### 三、与"普通策略游戏"的区别

| 维度 | 一般策略 / RTS / 4X | Wargame |
|------|------|---------|
| **题材** | 多样（奇幻、科幻、历史） | **真实军事冲突为主** |
| **尺度** | 抽象简化 | **精确还原**（武器射程、装甲、士气）|
| **单位** | 抽象单位 | **具体型号**（T-34/85、M1A2、Bf 109） |
| **地图** | 简化 / 程序生成 | **真实地形 + 等高线** |
| **回合制** | 多为实时 | **回合制为主**（六角格） |
| **目标受众** | 大众 | **军事爱好者、退伍军人、学者** |
| **学习曲线** | 陡 | **垂直** |
| **信息密度** | 中等 | **极高**（手册数百页） |

### 四、核心特征

1. **六角格地图（Hex Grid）**：兵棋的标志性视觉，源自桌面传统
2. **回合制 / I-Go-You-Go**：双方交替行动，部分支持同时下令
3. **武器精确建模**：穿深、射速、精度、装填、视距
4. **地形与天气**：森林、河流、雪、雾，影响视野与机动
5. **士气与疲劳**：单位不只是 HP，还有心理状态
6. **指挥链**：上级损失影响下级、通讯距离、命令延迟
7. **战争迷雾与侦察**：信息不对称是核心
8. **历史场景（Scenario）**：还原真实战役（库尔斯克、阿登、诺曼底）
9. **极厚手册**：100—500 页 PDF 是常态

### 五、发展简史

**桌面时代（1950s—1970s）**：
- **Avalon Hill** 成立（1952），1958 年发布 **《Tactics II》**——首个商业兵棋
- **《Gettysburg》**（1958）、**《D-Day》**（1961）确立兵棋范式
- **SPI**（Simulations Publications）1969 年成立，与 AH 双雄并立
- **《PanzerBlitz》**（1970）：东线战术兵棋经典
- **《Squad Leader》**（1977）：班级战术兵棋，开创新时代

**电子化早期（1980s）**：
- **《Eastern Front 1941》**（1981，Atari）：首批电子兵棋
- **《Cytron Masters》**（1982）
- **SSI（Strategic Simulations, Inc.）**：电子兵棋的 Avalon Hill
  - **《Computer Bismarck》**（1980）
  - **《Kampfgruppe》**（1985）
  - **《War in Russia》**（1984）

**黄金时代（1990s）**：
- **《Panzer General》**（SSI，1994）★：兵棋**大众化里程碑**
  - 简化兵棋 + 战役推进 + 部队成长
  - 兵棋首次"好玩"超过"硬核"
  - 衍生 **Allied General、Pacific General、Fantasy General** 等系列
- **《Steel Panthers》**（SSI，1995）★：战术级兵棋经典
- **《Close Combat》**（Atomic Games，1996）★：实时战术兵棋
  - 二战连排级实时战斗
  - 士气、伤亡、心理崩溃精细模拟
- **《Combat Mission: Beyond Overlord》**（2000）：3D 兵棋革命

**坚守与传承（2000s—2010s）**：
- 兵棋类型受 RTS 与 4X 冲击，**市场萎缩**
- 但**忠实社群**支撑专业开发商生存：
- **Matrix Games**（2000 成立）：硬核兵棋发行商
- **Slitherine**（2000 成立）：与 Matrix 合并后成兵棋第一发行商
- **HPS Simulations / John Tiller Software**：极硬核兵棋
- **2by3 Games**：War in the Pacific、War in the East 等"巨型兵棋"
- **《Combat Mission》系列**：CMBB、CMAK、Shock Force、Black Sea
- **《War in the East》**（2010）：东线战略兵棋，**地图覆盖整个东线**
- **《Command: Modern Air Naval Operations》**（2013）★：现代海空兵棋，**美军真实采购作训练工具**

**当代（2020s）**：
- **《Gary Grigsby's War in the East 2》**（2021）
- **《Flashpoint Campaigns: Southern Storm》**（2022）：冷战变热战
- **《Burden of Command》**（2024）：连级兵棋 + RPG
- **《Headquarters: World War II》**（2023）：现代化轻兵棋
- **AI / 沉浸度提升的尝试持续中**

### 六、Eugen Systems：兵棋大众化的另一条路

法国工作室 **Eugen Systems** 走了与传统兵棋**截然不同**的路线——**实时战略 + 兵棋深度**：

- **《Wargame: European Escalation》**（2012）
- **《Wargame: AirLand Battle》**（2013）
- **《Wargame: Red Dragon》**（2014）★：冷战兵棋 RTS 巅峰
- **《Steel Division》系列**（2017、2019）：二战版
- **《WARNO》**（2022—）：冷战变热战，Red Dragon 精神续作

**特点**：
- **实时**而非回合制
- 千人规模战场
- 数百种真实冷战 / 二战装备
- **建组系统**（Deck）：选择国家、年代、兵种倾向
- 兵棋的"装备考据"+ RTS 的操作快感

**这是兵棋**与 RTS 的**最佳融合**，吸引了大量非传统兵棋玩家。

### 七、主要分支

**按尺度划分**：

1. **战略级（Strategic）**：整个战场 / 战区
   - 例：War in the East（东线全境）、Strategic Command
2. **战役级（Operational）**：军 / 集团军规模
   - 例：Panzer Campaigns、Decisive Campaigns
3. **战术级（Tactical）**：营 / 连规模
   - 例：Combat Mission、Steel Panthers
4. **班排级（Squad）**：单兵到班
   - 例：Close Combat、Squad Battles

**按时代划分**：
- **古代 / 中世纪**：Field of Glory、Scourge of War
- **拿破仑战争**：Scourge of War: Waterloo
- **美国南北战争**：Ultimate General: Civil War
- **一战**：Commander: The Great War
- **二战**：兵棋的**主战场**，作品最多
- **冷战 / 现代**：Flashpoint Campaigns、Command、Wargame 系列
- **科幻**：Battle Academy、部分 mod

### 八、社群与文化

**玩家画像**：
- 平均年龄**显著高于**其他游戏类型（很多 40+、50+）
- 退伍军人 / 历史学者 / 军事爱好者比例高
- "**我父亲在阿登打过仗**"是真实玩家背景

**社群中心**：
- **Matrix Games / Slitherine 论坛**
- **Wargamer.com**：兵棋媒体老牌
- **GrogHeads**："Grog"（**老兵棋玩家**自嘲称呼，意为"老顽固"）
- **BoardGameGeek 的 wargame 板块**（桌面 + 数字交叉）
- **Reddit**：r/wargaming、r/wargame

**文化特征**：
- **极重考据**：错一个装甲数据会被论坛追到天涯
- **PBEM（Play By Email）**：邮件来回下棋，**单局可达数年**
- **AAR（After Action Report）文化**：详细战报传统
- 与现实军事的**真实交叉**：部分作品被军方采购作训练

### 九、为什么兵棋玩家如此忠诚？

1. **学术满足感**：每局都是历史课
2. **决策的真实重量**：你的选择对应真实历史的可能性
3. **慢节奏的深度**：与快节奏游戏完全不同的智力体验
4. **社群的高质量**：年龄与背景过滤后的讨论质量极高
5. **"幸存者偏差"**：能玩进去的都是真爱

### 十、兵棋的困境与未来

**困境**：
- **新玩家入门极难**——手册比游戏还劝退
- **画面长期落后**——开发预算有限
- **市场天花板低**——核心受众老龄化
- **UI 现代化滞后**——许多作品仍像 1990 年代

**积极信号**：
- **Slitherine 持续扩张**：兵棋发行龙头
- **Eugen 路线**证明兵棋可以"好看好玩"
- **Steam 让小众兵棋触达全球玩家**
- **AI 助手**可能降低未来兵棋的入门门槛
- **乌克兰战争等现实事件**重新激发对现代军事兵棋的兴趣

### 十一、与第四节大战略的关系

**Wargame 与 Grand Strategy 容易混淆，但本质不同**：

| 维度 | Wargame | Grand Strategy |
|------|---------|----------------|
| **焦点** | 军事行动本身 | 国家整体运营 |
| **时间尺度** | 一场战役 / 数日—数月 | 数十年—数百年 |
| **非军事系统** | 极少 | 经济、外交、文化、科技并重 |
| **节奏** | 回合制为主 | 实时可暂停 |
| **代表** | Combat Mission、Steel Panthers | EU4、CK3、HoI4 |

**注意**：HoI4 虽是 Paradox 大战略，但**大量兵棋玩家也将其视为"轻兵棋"**——它是两个类型的**桥梁作品**。
