# 1. 极端值 / 异常值对 mean 和 median 的影响

你说：

> 极端值和异常值只会拉 mean 到相应位置，median 不变。

更准确是：

```text
极端值会强烈影响 mean。
median 比 mean resistant，但不一定完全不变。
```

如果只是把一个最大值从 100 改成 10000，median 很可能不变。  
但如果是加入/删除数据点，median 也可能变。

例如：

```text
1, 2, 3, 4, 100
```

median = 3。

如果变成：

```text
1, 2, 3, 4, 10000
```

median 还是 3。

但如果加入一个极端值：

```text
1, 2, 3, 4, 100, 10000
```

median = 3.5。

所以考试表达最好写：

```text
Mean is sensitive to outliers; median is resistant to outliers.
```

不要写 median 一定不变。

---

# 2. p-value 和 alpha

你说：

> pvalue 是去跟置信区间 alpha 比较，大了就是 not reject，小了就是 reject。

基本对，但要改成：

```text
p-value 是和 significance level alpha 比较，不是和 confidence interval 比较。
```

规则：

```text
p-value ≤ alpha: reject H0
p-value > alpha: fail to reject H0
```

常见：

```text
alpha = 0.05
```

所以：

```text
p-value < 0.05  → statistically significant → reject H0
p-value > 0.05  → not statistically significant → fail to reject H0
```

注意是：

```text
fail to reject H0
```

不要说：

```text
accept H0
```

因为没有足够证据拒绝，不等于证明 H0 是真的。

---

# 3. p-value 和 confidence interval 的关系

如果是双侧检验，通常有这个对应关系：

```text
95% confidence interval 对应 alpha = 0.05
```

如果 null value 不在 95% CI 里面：

```text
reject H0 at alpha = 0.05
```

如果 null value 在 95% CI 里面：

```text
fail to reject H0 at alpha = 0.05
```

例如检验：

\[
H_0: \mu = 0
\]

如果 95% CI 是：

\[
(2, 8)
\]

0 不在区间里，所以 reject。

如果 95% CI 是：

\[
(-2, 8)
\]

0 在区间里，所以 fail to reject。

# 4. 所有数据加减常数

你说：

> 所有数据加减只会变 mean 和 median

这个基本对，但要补充：

如果：

\[
Y = X + c
\]

那么：

```text
mean 变：mean + c
median 变：median + c
Q1 变：Q1 + c
Q3 变：Q3 + c
min 变：min + c
max 变：max + c
```

但是 spread 不变：

```text
SD 不变
IQR 不变
range 不变
variance 不变
```

例子：

```text
X: 1, 2, 3
Y = X + 10: 11, 12, 13
```

center 变了，但数据之间的距离没变。

# 5. 所有数据乘除常数

你说：

> 乘除都变

基本对，但要更精确：

如果：

\[
Y = aX
\]

那么：

```text
mean_Y = a mean_X
median_Y = a median_X
SD_Y = |a| SD_X
IQR_Y = |a| IQR_X
range_Y = |a| range_X
variance_Y = a^2 variance_X
```

注意：

```text
SD, IQR, range 都乘 |a|
variance 乘 a²
```

如果乘的是负数，顺序会反过来，但 spread 仍然不能是负的。
```
加常数时，mean/median/quartiles/min/max 都平移，var/SD/IQR/range 不变。
乘常数时，mean/median 会乘这个常数，SD/IQR/range 乘这个常数的绝对值，variance 乘这个常数的平方。
```

# 6. 哪些统计量可以是负数？

你说：

> 除了 SD 其他的都可以是负数。

这个不对。

不能为负数的有：

```text
SD ≥ 0
variance ≥ 0
IQR ≥ 0
range ≥ 0
```

可以是负数的有：

```text
mean
median
Q1
Q3
min
max
correlation r 可以是负数
slope 可以是负数
residual 可以是负数
z-score 可以是负数
```

所以正确总结：

```text
Measures of spread such as SD, variance, IQR, and range cannot be negative.
Measures of location such as mean and median can be negative.
```

# 7. measurement error 和 repeated measurements

你说：

> measurement error 是通过重复测量计算 SD

基本可以，但要补充：

```text
Repeated measurements can estimate random measurement error.
```

如果同一个东西测很多次，每次结果有波动，这些波动的 SD 可以反映 measurement precision。

例如：

```text
10.1, 10.3, 10.0, 10.2
```

SD 小，说明测量比较 precise。

但注意：

```text
repeated measurements 不能自动发现 systematic error / bias。
```

例如一个秤永远多称 2 kg，即使每次结果都很稳定，SD 很小，但还是 biased。

所以：

```text
Random error: repeated measurements + SD 可以衡量
Systematic error/bias: 需要校准或和真实值比较
```

# 8. R 公式里面 x ~ y 是谁预测谁？

你说：

> x~y 是根据 y 来预测 x，那公式就要写 yhat = ...

前半句对，后半句错。

在 R 里面：

```r
response ~ explanatory
```

也就是：

```text
左边是被预测的变量
右边是用来预测的变量
```

所以：

```r
x ~ y
```

意思是：

```text
use y to predict x
```

公式应该写：

$$
\hat{x} = b_0 + b_1 y
$$

不是：

$$
\hat{y} = b_0 + b_1 x
$$

如果是：

```r
y ~ x
```

才是：

$$
\hat{y} = b_0 + b_1 x
$$

记忆：

```text
左边是谁，hat 就是谁。
```

# 9. 线性回归和 residuals

你说：

> 线性回归 mean of 数据和回归线就是 residuals

这句需要改。

Residual 是：

```text
observed value - predicted value
```

对于模型：

$$
\hat{y} = b_0 + b_1x
$$

residual 是：

$$
e = y - \hat{y}
$$

也就是图上每个点到回归线的 vertical distance。

```text
点在线上方：residual > 0
点在线下方：residual < 0
点正好在线上：residual = 0
```

---

# 10. 回归线和 mean 的关系

线性回归有一个重要性质：

```text
如果模型有 intercept，least squares regression line passes through (x̄, ȳ).
```

也就是回归线会经过：

$$
(\bar{x}, \bar{y})
$$

另外：

```text
residuals 的平均值是 0
```

前提是模型里面有 intercept。

所以考试可以写：

```text
The least squares regression line passes through the point of averages.
The residuals have mean 0 when the model includes an intercept.
```

# 大题总原则

每小问都用这个结构：

```text
Claim → Evidence from source → Correct conclusion
```

中文就是：

```text
题目说法对不对 → 数据/输出哪里支持 → 正确应该怎么说
```

不要只说 “wrong”。

# 1(a) 这种题怎么做

题目类似：

> “Higher weight causes more CVD, especially in men.”

问你解释 2 个不正确的地方。

你直接写两点。

---

## 可拿分答案模板

```text
First, the word “causes” is not justified. The data are observational, so the results show an association between weight and CVD, not causation.

Second, the phrase “especially in men” is not supported by the given evidence. Source 2 compares weight by CVD status overall, but does not separately analyse men and women.
```

中文理解：

```text
第一，不能说 causes，因为不是随机实验，只能说 associated with。
第二，especially in men 没证据，因为 Source 2 没有按 gender 分开分析。
```

---

## 如果还想加 Source 2 数字

可以写：

```text
Source 2 shows that the mean weight for patients with CVD is 76.26 kg and without CVD is 72.41 kg, with p-value = 0.003709. This suggests a difference in mean weight, but not causation.
```

# 1(b) p-value 解释题

题目错误说法：

> p-value = 0.8837 means 88.37% of patients belong to gender 2.

这是错的。

---

## 正确写法模板

```text
The p-value is not the proportion of patients in gender 2. Source 3 is a chi-squared test for association between cholesterol and gender. Since p-value = 0.8837 is large, the data do not provide evidence of an association between cholesterol level and gender. We retain the null hypothesis that cholesterol and gender are independent.
```

中文：

```text
p-value 不是比例。
这是 cholesterol 和 gender 的卡方独立性检验。
p-value 很大，不拒绝 H0。
没有证据说明 cholesterol 和 gender 有关系。
```

---

## 必背句

```text
A p-value is not the probability that a patient belongs to a category.
```

```text
A large p-value means the data are consistent with the null hypothesis.
```

# 大题常用英文句型

## 不能说因果

```text
The data show an association, not causation.
```

```text
Causation cannot be concluded because this is not a randomised controlled experiment.
```

```text
There is evidence of an association/difference.
```

```text

There is not sufficient evidence of an association/difference.

```


# Source 2 你该怎么解释

Source 2 是：

```text
Two Sample t-test
weight by cardio
p-value = 0.003709
mean of x = 76.25882
mean of y = 72.40816
95% CI = 1.255877 to 6.445444
```

可以写：

```text
There is evidence that mean weight differs between patients with and without CVD, because p-value = 0.003709 is less than 0.05. The sample mean weight is about 76.26 kg for one cardio group and 72.41 kg for the other group. However, this does not prove that higher weight causes CVD.
```

---

# Source 3 你该怎么解释

Source 3 是：

```text
cholesterol vs gender
p-value = 0.8837
```

可以写：

```text
This is a chi-squared test of association between cholesterol and gender. Since p-value = 0.8837 is large, there is no evidence of an association between cholesterol level and gender in these data.
```

---

# Source 4 你该怎么解释

Source 4 是：

```r
lm(ap_hi ~ weight)
Intercept = 111.1426
weight slope = 0.2451
p-value for slope = 0.0372
R-squared = 0.008686
```

可以写：

```text
The fitted model is:
predicted ap_hi = 111.1426 + 0.2451 × weight.
For each additional kg of weight, predicted systolic blood pressure increases by about 0.245 on average. The p-value = 0.0372 suggests evidence of a linear association, but R-squared = 0.008686 is very small, so weight explains very little of the variation in systolic blood pressure.
```

这句很容易拿分。
