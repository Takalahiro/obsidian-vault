# 1. 极端值 / 异常值对 mean 和 median 的影响

你说：

> 极端值和异常值只会拉 mean 到相应位置，median 不变。

更准确是：

```text
极端值会强烈影响 mean。
median 比 mean resistant，但不一定完全不变。
```

如果只是把一个最大值从 100 改成 10000，median 很可能不变。  
但如果是加入/删除数据点，median 也可能变。

例如：

```text
1, 2, 3, 4, 100
```

median = 3。

如果变成：

```text
1, 2, 3, 4, 10000
```

median 还是 3。

但如果加入一个极端值：

```text
1, 2, 3, 4, 100, 10000
```

median = 3.5。

所以考试表达最好写：

```text
Mean is sensitive to outliers; median is resistant to outliers.
```

不要写 median 一定不变。

# 2. p-value 和 alpha

你说：

> pvalue 是去跟置信区间 alpha 比较，大了就是 not reject，小了就是 reject。

基本对，但要改成：

```text
p-value 是和 significance level alpha 比较，不是和 confidence interval 比较。
```

规则：

```text
p-value ≤ alpha: reject H0
p-value > alpha: fail to reject H0
```

常见：

```text
alpha = 0.05
```

所以：

```text
p-value < 0.05  → statistically significant → reject H0
p-value > 0.05  → not statistically significant → fail to reject H0
```

注意是：

```text
fail to reject H0
```

不要说：

```text
accept H0
```

因为没有足够证据拒绝，不等于证明 H0 是真的。

---

# 3. p-value 和 confidence interval 的关系

如果是双侧检验，通常有这个对应关系：

```text
95% confidence interval 对应 alpha = 0.05
```

如果 null value 不在 95% CI 里面：

```text
reject H0 at alpha = 0.05
```

如果 null value 在 95% CI 里面：

```text
fail to reject H0 at alpha = 0.05
```

例如检验：

\[
H_0: \mu = 0
\]

如果 95% CI 是：

\[
(2, 8)
\]

0 不在区间里，所以 reject。

如果 95% CI 是：

\[
(-2, 8)
\]

0 在区间里，所以 fail to reject。

# 4. 所有数据加减常数

你说：

> 所有数据加减只会变 mean 和 median

这个基本对，但要补充：

如果：

\[
Y = X + c
\]

那么：

```text
mean 变：mean + c
median 变：median + c
Q1 变：Q1 + c
Q3 变：Q3 + c
min 变：min + c
max 变：max + c
```

但是 spread 不变：

```text
SD 不变
IQR 不变
range 不变
variance 不变
```

例子：

```text
X: 1, 2, 3
Y = X + 10: 11, 12, 13
```

center 变了，但数据之间的距离没变。

---

# 5. 所有数据乘除常数

你说：

> 乘除都变

基本对，但要更精确：

如果：

\[
Y = aX
\]

那么：

```text
mean_Y = a mean_X
median_Y = a median_X
SD_Y = |a| SD_X
IQR_Y = |a| IQR_X
range_Y = |a| range_X
variance_Y = a^2 variance_X
```

注意：

```text
SD, IQR, range 都乘 |a|
variance 乘 a²
```

如果乘的是负数，顺序会反过来，但 spread 仍然不能是负的。

# 6. 哪些统计量可以是负数？

你说：

> 除了 SD 其他的都可以是负数。

这个不对。

不能为负数的有：

```text
SD ≥ 0
variance ≥ 0
IQR ≥ 0
range ≥ 0
```

可以是负数的有：

```text
mean
median
Q1
Q3
min
max
correlation r 可以是负数
slope 可以是负数
residual 可以是负数
z-score 可以是负数
```

所以正确总结：

```text
Measures of spread such as SD, variance, IQR, and range cannot be negative.
Measures of location such as mean and median can be negative.
```

# 7. measurement error 和 repeated measurements

你说：

> measurement error 是通过重复测量计算 SD

基本可以，但要补充：

```text
Repeated measurements can estimate random measurement error.
```

如果同一个东西测很多次，每次结果有波动，这些波动的 SD 可以反映 measurement precision。

例如：

```text
10.1, 10.3, 10.0, 10.2
```

SD 小，说明测量比较 precise。

但注意：

```text
repeated measurements 不能自动发现 systematic error / bias。
```

例如一个秤永远多称 2 kg，即使每次结果都很稳定，SD 很小，但还是 biased。

所以：

```text
Random error: repeated measurements + SD 可以衡量
Systematic error/bias: 需要校准或和真实值比较
```

# 8. R 公式里面 x ~ y 是谁预测谁？

你说：

> x~y 是根据 y 来预测 x，那公式就要写 yhat = ...

前半句对，后半句错。

在 R 里面：

```r
response ~ explanatory
```

也就是：

```text
左边是被预测的变量
右边是用来预测的变量
```

所以：

```r
x ~ y
```

意思是：

```text
use y to predict x
```

公式应该写：

\[
\hat{x} = b_0 + b_1 y
\]

不是：

\[
\hat{y} = b_0 + b_1 x
\]

如果是：

```r
y ~ x
```

才是：

\[
\hat{y} = b_0 + b_1 x
\]

记忆：

```text
左边是谁，hat 就是谁。
```

# 9. 线性回归和 residuals

你说：

> 线性回归 mean of 数据和回归线就是 residuals

这句需要改。

Residual 是：

```text
observed value - predicted value
```

对于模型：

\[
\hat{y} = b_0 + b_1x
\]

residual 是：

\[
e = y - \hat{y}
\]

也就是图上每个点到回归线的 vertical distance。

```text
点在线上方：residual > 0
点在线下方：residual < 0
点正好在线上：residual = 0
```

---

# 10. 回归线和 mean 的关系

线性回归有一个重要性质：

```text
如果模型有 intercept，least squares regression line passes through (x̄, ȳ).
```

也就是回归线会经过：

\[
(\bar{x}, \bar{y})
\]

另外：

```text
residuals 的平均值是 0
```

前提是模型里面有 intercept。

所以考试可以写：

```text
The least squares regression line passes through the point of averages.
The residuals have mean 0 when the model includes an intercept.
```

# 最终修改版总结

你可以背这个版本：

```text
1. Outliers strongly affect the mean, but the median is resistant.

2. Compare p-value with alpha:
   p-value ≤ alpha → reject H0
   p-value > alpha → fail to reject H0.

3. For a 95% CI, alpha = 0.05.
   If the null value is outside the CI, reject H0.
   If the null value is inside the CI, fail to reject H0.

4. Adding/subtracting a constant changes mean, median, quartiles, min, max,
   but does not change SD, IQR, range, or variance.

5. Multiplying by a constant changes center and spread:
   mean and median multiply by a,
   SD, IQR, and range multiply by |a|,
   variance multiplies by a².

6. SD, variance, IQR, and range cannot be negative.
   Mean, median, slope, correlation, residuals, and z-scores can be negative.

7. Repeated measurements can estimate random measurement error using SD,
   but they do not automatically detect systematic bias.

8. In R formula notation:
   x ~ y means predict x from y.
   So the regression equation is xhat = b0 + b1y.

9. Residual = observed - predicted.
   For y ~ x:
   residual = y - yhat.

10. A least squares regression line with intercept passes through (xbar, ybar),
    and residuals have mean 0.
```

整体你已经抓到主线了，主要要改的是：

```text
median 不是绝对不变
p-value 是和 alpha 比，不是和 CI 比
x ~ y 的 hat 应该写 xhat
SD、variance、IQR、range 都不能是负数
residual = observed - predicted
```
