我会以第二版为基础，把路口识别改成行驶中持续确认，让选择直行时电机不停；同时调整转向、路口锁存和运动计时，保留终点及故障停车。

下面是基于第二版完整修改的版本，可整体替换原程序。

正常流程改为：

- **直道不停。**
- **路口选择直行时不停，也不停车扫描。**
- **需要转弯、掉头时才停车转向。**
- 终点、前方过近或判断异常仍会停车。
- 保留纠偏、路径记忆和长死路终点判断，并增加回程目标坐标检查。

路口信息改为**行驶中连续采样**，不能简单删除原来的停车语句。下面代码尚未经过编译和实车验证，`SIDE_CENTER_MS` 等参数仍需按车辆标定。

```cpp
#include <Arduino.h>
#include <Servo.h>
#include <string.h>

// 数据结构
// ============================================================

struct Reading {
  int bands;
  int votes;
};

struct Scan {
  int8_t left;    // -1不确定，0墙，1开
  int8_t front;
  int8_t right;
};

// flags：最高位表示节点存在，低4位表示已探索方向。
// 保存到父节点的方向和格数，用于检查回程坐标。
struct Node {
  uint8_t flags;
  uint8_t parentDir;
  uint8_t parentCells;
};

// ============================================================
// 引脚
// ============================================================

Servo leftServo;
Servo rightServo;

const int LEFT_SERVO = 13;
const int RIGHT_SERVO = 12;

const int LEFT_TX = 10;
const int LEFT_RX = 11;

const int FRONT_TX = 6;
const int FRONT_RX = 7;

const int RIGHT_TX = 2;
const int RIGHT_RX = 3;

const int LED_L = A2;
const int LED_M = A1;
const int LED_R = A0;

// ============================================================
// 电机标定
// ============================================================

const int LEFT_STOP_PWM = 1490;
const int RIGHT_STOP_PWM = 1490;

const int LEFT_FORWARD = 1550;
const int RIGHT_FORWARD = 1438;

const int SPIN_LEFT_L = 1430;
const int SPIN_LEFT_R = 1425;

const int SPIN_RIGHT_L = 1570;
const int SPIN_RIGHT_R = 1575;

const int UTURN_LEFT_L = 1430;
const int UTURN_LEFT_R = 1425;

const unsigned long LEFT_TURN_MS = 615;
const unsigned long RIGHT_TURN_MS = 622;
const unsigned long UTURN_LEFT_MS = 1250;

const unsigned long TURN_SETTLE_MS = 150;

// 正常速度通过一格的实测时间。
const unsigned long T_CELL = 1480;

const int CAUTION_DRIVE_PERCENT = 85;

// 85% PWM偏移对应的实际速度比例。
// 这里只用于位置估算，不改变电机输出。
const float SLOW_DISTANCE_FACTOR = 0.85f;

// ============================================================
// 红外参数
// ============================================================

const unsigned long frequencies[5] = {
  38000, 39000, 40000, 41000, 42000
};

const int FRONT_WALL_THRESHOLD = 3;

const int SIDE_WALL_THRESHOLD = 2;
const int SIDE_WALL_MIN_VOTES = 3;

const int SIDE_OPEN_THRESHOLD = 0;
const int SIDE_OPEN_MAX_VOTES = 1;

// 必须实测确认：在碰墙之前能够触发。
const int FRONT_CLOSE_BANDS = 5;
const int FRONT_CLOSE_VOTES = 14;

// 行驶中保留最近7轮读数。
// 每轮读取前、左、右，不做停车扫描。
const uint8_t WINDOW_SIZE = 7;
const uint8_t SIDE_CONFIRM_VOTES = 5;
const uint8_t FRONT_CONFIRM_VOTES = 6;

const uint8_t SIDE_OPEN_CONFIRM = 3;

// 连续确认重新有墙后，才解除该侧开口锁存。
const uint8_t SIDE_WALL_REARM_COUNT = 3;

// 只有前方过近已经停车时，才允许进行静止复核。
const uint8_t STOPPED_SCAN_RETRIES = 3;

// ============================================================
// 纠偏参数
// ============================================================

const float FILTER_OLD_WEIGHT = 0.20f;
const float CORRECTION_GAIN = 2.0f;
const float ERROR_DEADBAND = 2.0f;

const int ALIGN_LEFT_TARGET = 7;
const int ALIGN_RIGHT_TARGET = 7;

const int MAX_CORRECTION = 22;
const int SINGLE_WALL_MAX_CORRECTION = 12;
const int CORRECTION_STEP = 4;

float filteredError = 0.0f;
int lastCorrection = 0;
int correctionWallMask = -1;

// ============================================================
// 路口与接近参数
// ============================================================

// 普通前墙报墙后，允许低速接近的最长时间。
// 这是时间上限，不代表实际走了1.2格。
const float FRONT_APPROACH_CELLS = 1.2f;

const unsigned long FRONT_APPROACH_MS =
    (unsigned long)(FRONT_APPROACH_CELLS * T_CELL);

// 连续确认侧开口后，到车轴适合转弯位置的补走时间。
// 180ms只是初始值，必须现场调整。
// 提前转：适当增大；超过转弯位置：减小。
// 确认开口期间本身也在前进。
const unsigned long SIDE_CENTER_MS = 180;

// 每次从路口出发后，累计前进达到此时间，
// 才重新允许侧开口事件。
// 不影响前方过近保护。
const unsigned long SIDE_REARM_MS = 250;

// ============================================================
// 终点
// ============================================================

// 只有场地满足“目标是唯一可区分的长死路”时才启用。
// 未标定前，可改为false，仅测试运动和探索。
const bool ENABLE_LONG_DEADEND_FINISH = true;

const unsigned long LONG_DEADEND_MS = 2UL * T_CELL;

const uint8_t ENCLOSED_BREAK_COUNT = 3;

// 0表示不限软件运行时间。
const unsigned long RUN_LIMIT_MS = 0;

// ============================================================
// 地图
// ============================================================

const int GRID = 16;

const uint8_t NODE_USED = 0x80;
const uint8_t NO_PARENT = 255;

Node nodes[GRID][GRID];

const int8_t DX[4] = {0, 1, 0, -1};
const int8_t DY[4] = {-1, 0, 1, 0};

int gx = 8;
int gy = 8;

// 相对朝向：0、1、2、3。
// 初始0不要求真实朝北，只要求初始摆放面向通道。
int heading = 0;

// 0：探索新分支
// 1：返回父节点
// 2：闭环后返回刚才的出发节点
uint8_t travelKind = 0;

bool legStarted = false;

// 回程必须到达的目标坐标。
int expectedReturnX = -1;
int expectedReturnY = -1;

// ============================================================
// 运动状态
// ============================================================

// 0：正常行驶
// 1：前墙接近
// 2：侧开口居中
uint8_t phase = 0;

unsigned long phaseStartedAt = 0;

bool halted = false;
bool finished = false;

unsigned long runStartedAt = 0;

// 这里只记录“已下达前进指令”的时间。
// 无编码器，不能判断打滑或顶墙后的真实位移。
bool forwardActive = false;
int activePercent = 100;

unsigned long accountAt = 0;

float legEquivalentMs = 0.0f;
unsigned long afterDepartForwardMs = 0;

// 连续双侧有墙的前进时间。
unsigned long enclosedForwardMs = 0;
bool enclosedNow = false;
uint8_t enclosedBreakVotes = 0;

// ============================================================
// 侧开口跟踪
// ============================================================

uint8_t leftOpenVotes = 0;
uint8_t rightOpenVotes = 0;

uint8_t leftWallVotes = 0;
uint8_t rightWallVotes = 0;

bool leftLatched = false;
bool rightLatched = false;

bool leftCandidate = false;
bool rightCandidate = false;

// ============================================================
// 行驶中扫描窗口
// ============================================================

// 列顺序：左、前、右。
int8_t scanWindow[WINDOW_SIZE][3];

uint8_t windowCount = 0;
uint8_t windowIndex = 0;

unsigned long lastPrintAt = 0;

// ============================================================
// 基础函数
// ============================================================

bool inside(int x, int y) {
  return x >= 0 && y >= 0 && x < GRID && y < GRID;
}

uint8_t bitFor(int d) {
  return (uint8_t)(1U << d);
}

bool nodeUsed(const Node &n) {
  return (n.flags & NODE_USED) != 0;
}

void leds(bool l, bool m, bool r) {
  digitalWrite(LED_L, l);
  digitalWrite(LED_M, m);
  digitalWrite(LED_R, r);
}

void accountMotion() {
  unsigned long now = millis();
  unsigned long dt = now - accountAt;
  accountAt = now;

  if (!forwardActive) return;

  float factor =
      activePercent == 100 ? 1.0f : SLOW_DISTANCE_FACTOR;

  legEquivalentMs += dt * factor;
  afterDepartForwardMs += dt;

  if (enclosedNow) {
    enclosedForwardMs += dt;
  }
}

void stopRobot() {
  accountMotion();
  forwardActive = false;

  leftServo.writeMicroseconds(LEFT_STOP_PWM);
  rightServo.writeMicroseconds(RIGHT_STOP_PWM);
}

void resetCorrection() {
  filteredError = 0.0f;
  lastCorrection = 0;
  correctionWallMask = -1;
}

void fail(const __FlashStringHelper *reason) {
  stopRobot();
  resetCorrection();

  halted = true;
  finished = false;

  Serial.print(F("FAULT: "));
  Serial.println(reason);
}

bool timeOK() {
  if (halted) return false;

  if (RUN_LIMIT_MS != 0 &&
      millis() - runStartedAt >= RUN_LIMIT_MS) {
    fail(F("TIME_LIMIT"));
    return false;
  }

  return true;
}

void finishRobot() {
  stopRobot();
  resetCorrection();

  halted = true;
  finished = true;

  leds(true, true, true);
  Serial.println(F("FINISH: LONG DEAD END"));
}

// ============================================================
// 红外读取
// ============================================================

int irRead(int tx, int rx, unsigned long frequency) {
  tone(tx, frequency);
  delayMicroseconds(700);

  int value = digitalRead(rx);

  noTone(tx);
  digitalWrite(tx, LOW);
  delayMicroseconds(250);

  return value;
}

Reading readSensor(int tx, int rx) {
  Reading r = {0, 0};

  for (int b = 0; b < 5; b++) {
    int hits = 0;

    for (int s = 0; s < 3; s++) {
      if (irRead(tx, rx, frequencies[b]) == LOW) {
        hits++;
      }
    }

    r.votes += hits;

    if (hits >= 2) {
      r.bands++;
    }
  }

  return r;
}

bool hasWall(const Reading &r) {
  return r.bands >= SIDE_WALL_THRESHOLD ||
         r.votes >= SIDE_WALL_MIN_VOTES;
}

bool isOpen(const Reading &r) {
  return r.bands <= SIDE_OPEN_THRESHOLD &&
         r.votes <= SIDE_OPEN_MAX_VOTES;
}

bool tooClose(const Reading &r) {
  return r.bands >= FRONT_CLOSE_BANDS &&
         r.votes >= FRONT_CLOSE_VOTES;
}

int8_t classifySide(const Reading &r) {
  if (hasWall(r)) return 0;
  if (isOpen(r)) return 1;
  return -1;
}

int8_t classifyFront(const Reading &r) {
  return r.bands >= FRONT_WALL_THRESHOLD ? 0 : 1;
}

// ============================================================
// 行驶中连续确认
// ============================================================

void clearScanWindow() {
  windowCount = 0;
  windowIndex = 0;
}

void pushScan(const Reading &L,
              const Reading &front,
              const Reading &R) {
  scanWindow[windowIndex][0] = classifySide(L);
  scanWindow[windowIndex][1] = classifyFront(front);
  scanWindow[windowIndex][2] = classifySide(R);

  windowIndex++;

  if (windowIndex >= WINDOW_SIZE) {
    windowIndex = 0;
  }

  if (windowCount < WINDOW_SIZE) {
    windowCount++;
  }
}

int8_t windowState(uint8_t column, uint8_t required) {
  if (windowCount < WINDOW_SIZE) return -1;

  uint8_t wallCount = 0;
  uint8_t openCount = 0;

  for (uint8_t i = 0; i < WINDOW_SIZE; i++) {
    if (scanWindow[i][column] == 0) {
      wallCount++;
    } else if (scanWindow[i][column] == 1) {
      openCount++;
    }
  }

  if (wallCount >= required) return 0;
  if (openCount >= required) return 1;

  return -1;
}

Scan currentScan() {
  Scan s;

  s.left = windowState(0, SIDE_CONFIRM_VOTES);
  s.front = windowState(1, FRONT_CONFIRM_VOTES);
  s.right = windowState(2, SIDE_CONFIRM_VOTES);

  return s;
}

bool scanValid(const Scan &s) {
  return s.left >= 0 && s.front >= 0 && s.right >= 0;
}

// 防止历史窗口和最新读数明显矛盾时仍执行旧决策。
bool scanMatchesLatest(const Scan &s,
                       const Reading &L,
                       const Reading &front,
                       const Reading &R) {
  if (!scanValid(s)) return false;

  return s.left == classifySide(L) &&
         s.front == classifyFront(front) &&
         s.right == classifySide(R);
}

// 只用于“前方过近，已经安全停车”的复核。
// 正常直行和普通路口绝不调用此函数。
bool scanWhileSafetyStopped(Scan &result) {
  stopRobot();

  for (uint8_t retry = 0;
       retry < STOPPED_SCAN_RETRIES;
       retry++) {
    clearScanWindow();

    Reading L = {0, 0};
    Reading front = {0, 0};
    Reading R = {0, 0};

    for (uint8_t i = 0; i < WINDOW_SIZE; i++) {
      if (!timeOK()) return false;

      front = readSensor(FRONT_TX, FRONT_RX);
      L = readSensor(LEFT_TX, LEFT_RX);
      R = readSensor(RIGHT_TX, RIGHT_RX);

      pushScan(L, front, R);
      delay(5);
    }

    result = currentScan();

    if (scanMatchesLatest(result, L, front, R)) {
      return true;
    }
  }

  return false;
}

// ============================================================
// 直行纠偏：不停车
// ============================================================

void driveCorrected(const Reading &L,
                    const Reading &R,
                    int percent) {
  if (halted) return;

  bool lw = hasWall(L);
  bool rw = hasWall(R);

  int mask = (lw ? 2 : 0) | (rw ? 1 : 0);

  if (mask != correctionWallMask) {
    resetCorrection();
    correctionWallMask = mask;
  }

  float error = 0.0f;

  if (lw && rw) {
    error = (float)(L.votes - ALIGN_LEFT_TARGET)
          - (float)(R.votes - ALIGN_RIGHT_TARGET);
  } else if (lw) {
    error = (float)(L.votes - ALIGN_LEFT_TARGET);
  } else if (rw) {
    error = -(float)(R.votes - ALIGN_RIGHT_TARGET);
  }

  filteredError =
      FILTER_OLD_WEIGHT * filteredError +
      (1.0f - FILTER_OLD_WEIGHT) * error;

  if (!lw && !rw) {
    filteredError = 0.0f;
    lastCorrection = 0;
  }

  int lOff =
      (LEFT_FORWARD - LEFT_STOP_PWM) * percent / 100;

  int rOff =
      (RIGHT_STOP_PWM - RIGHT_FORWARD) * percent / 100;

  int limit =
      (lw && rw) ? MAX_CORRECTION
                 : SINGLE_WALL_MAX_CORRECTION;

  // 保证纠偏不会把前进轮速压到反转。
  int motorLimit = min(lOff, rOff) - 5;
  if (motorLimit < 0) motorLimit = 0;

  limit = min(limit, motorLimit);

  int wanted = 0;

  if (filteredError > ERROR_DEADBAND ||
      filteredError < -ERROR_DEADBAND) {
    wanted = (int)(filteredError * CORRECTION_GAIN);
  }

  wanted = constrain(wanted, -limit, limit);

  int correction = constrain(
      wanted,
      lastCorrection - CORRECTION_STEP,
      lastCorrection + CORRECTION_STEP
  );

  correction = constrain(correction, -limit, limit);
  lastCorrection = correction;

  accountMotion();

  activePercent = percent;
  forwardActive = true;

  leftServo.writeMicroseconds(
      LEFT_STOP_PWM + lOff + correction
  );

  rightServo.writeMicroseconds(
      RIGHT_STOP_PWM - rOff + correction
  );
}

// ============================================================
// 侧墙和开口跟踪
// ============================================================

void updateSideTracking(const Reading &L,
                        const Reading &R) {
  accountMotion();

  bool lw = hasWall(L);
  bool rw = hasWall(R);

  bool lo = isOpen(L);
  bool ro = isOpen(R);

  if (lw && rw) {
    enclosedNow = true;
    enclosedBreakVotes = 0;
  } else {
    enclosedNow = false;

    if (lo || ro) {
      if (enclosedBreakVotes < ENCLOSED_BREAK_COUNT) {
        enclosedBreakVotes++;
      }

      if (enclosedBreakVotes >= ENCLOSED_BREAK_COUNT) {
        enclosedForwardMs = 0;
      }
    } else {
      // 不确定状态打断“连续确认开放”。
      enclosedBreakVotes = 0;
    }
  }

  if (lo) {
    if (leftOpenVotes < SIDE_OPEN_CONFIRM) {
      leftOpenVotes++;
    }
  } else {
    leftOpenVotes = 0;
  }

  if (ro) {
    if (rightOpenVotes < SIDE_OPEN_CONFIRM) {
      rightOpenVotes++;
    }
  } else {
    rightOpenVotes = 0;
  }

  if (lw) {
    if (leftWallVotes < SIDE_WALL_REARM_COUNT) {
      leftWallVotes++;
    }

    if (leftWallVotes >= SIDE_WALL_REARM_COUNT) {
      leftLatched = false;
    }
  } else {
    leftWallVotes = 0;
  }

  if (rw) {
    if (rightWallVotes < SIDE_WALL_REARM_COUNT) {
      rightWallVotes++;
    }

    if (rightWallVotes >= SIDE_WALL_REARM_COUNT) {
      rightLatched = false;
    }
  } else {
    rightWallVotes = 0;
  }
}

// 不额外读取传感器，不停车。
// 屏蔽当前路口已经可见的开口。
void seedSideTracking(const Reading &L,
                      const Reading &R) {
  leftLatched = !hasWall(L);
  rightLatched = !hasWall(R);

  leftOpenVotes = 0;
  rightOpenVotes = 0;

  leftWallVotes = 0;
  rightWallVotes = 0;

  leftCandidate = false;
  rightCandidate = false;
}

// ============================================================
// 转向
// ============================================================

bool turnTo(int target) {
  int relative = (target - heading + 4) % 4;

  // 关键：直行直接返回，不下达停车命令。
  if (relative == 0) {
    return true;
  }

  stopRobot();
  resetCorrection();

  int lp;
  int rp;
  unsigned long duration;

  if (relative == 1) {
    lp = SPIN_RIGHT_L;
    rp = SPIN_RIGHT_R;
    duration = RIGHT_TURN_MS;

    leds(false, false, true);
  } else if (relative == 3) {
    lp = SPIN_LEFT_L;
    rp = SPIN_LEFT_R;
    duration = LEFT_TURN_MS;

    leds(true, false, false);
  } else {
    lp = UTURN_LEFT_L;
    rp = UTURN_LEFT_R;
    duration = UTURN_LEFT_MS;

    leds(true, false, true);
  }

  leftServo.writeMicroseconds(lp);
  rightServo.writeMicroseconds(rp);

  unsigned long started = millis();

  while (millis() - started < duration) {
    if (!timeOK()) return false;
    delay(1);
  }

  stopRobot();
  delay(TURN_SETTLE_MS);

  heading = target;

  enclosedForwardMs = 0;
  enclosedNow = false;
  enclosedBreakVotes = 0;

  clearScanWindow();

  return timeOK();
}

// ============================================================
// 出发
// ============================================================

bool depart(int direction,
            uint8_t kind,
            int expectedX,
            int expectedY,
            const Reading &oldL,
            const Reading &oldR) {
  bool needsTurn = direction != heading;

  // 直行时此函数不会停车。
  if (!turnTo(direction)) return false;

  Reading L = oldL;
  Reading R = oldR;

  if (needsTurn) {
    // 转向完成后，用新朝向的读数启动纠偏。
    // 此时停车属于转向流程的一部分。
    Reading front = readSensor(FRONT_TX, FRONT_RX);

    if (tooClose(front)) {
      fail(F("TURN_EXIT_TOO_CLOSE"));
      return false;
    }

    L = readSensor(LEFT_TX, LEFT_RX);
    R = readSensor(RIGHT_TX, RIGHT_RX);

    pushScan(L, front, R);

    enclosedNow = hasWall(L) && hasWall(R);
  }

  // 先结算旧路段，再开始新路段。
  // 直行路径中forwardActive始终保持true。
  accountMotion();

  travelKind = kind;
  expectedReturnX = expectedX;
  expectedReturnY = expectedY;

  legStarted = true;
  legEquivalentMs = 0.0f;

  afterDepartForwardMs = 0;

  phase = 0;
  phaseStartedAt = 0;

  seedSideTracking(L, R);

  // 无论直行还是转弯后，都立即继续低速前进。
  // 直行时只是更新PWM，不经过STOP PWM。
  driveCorrected(L, R, CAUTION_DRIVE_PERCENT);

  return true;
}

// ============================================================
// 路口决策
// 此函数正常情况下不停车。
// 只有最终选择转向、到达终点或出错才停车。
// ============================================================

bool serviceJunction(const Scan &s,
                     const Reading &L,
                     const Reading &R,
                     bool safetyStopped) {
  if (!scanValid(s)) {
    fail(F("JUNCTION_UNCERTAIN"));
    return false;
  }

  accountMotion();

  // 终点判断先于地图位置更新。
  if (ENABLE_LONG_DEADEND_FINISH &&
      s.left == 0 &&
      s.front == 0 &&
      s.right == 0 &&
      enclosedForwardMs >= LONG_DEADEND_MS) {
    finishRobot();
    return false;
  }

  // 已触发前方过近，却扫描成前方开放：
  // 不直接重新前进，避免保护与规划相互冲突。
  if (safetyStopped && s.front != 0) {
    fail(F("FRONT_CLOSE_SCAN_CONFLICT"));
    return false;
  }

  bool arrived = legStarted;
  int back = (heading + 2) % 4;

  int sourceX = gx;
  int sourceY = gy;

  int cells = 0;

  if (arrived) {
    cells = (int)(
        (legEquivalentMs + T_CELL / 2.0f) / T_CELL
    );

    if (cells < 1) cells = 1;

    int nx = gx + DX[heading] * cells;
    int ny = gy + DY[heading] * cells;

    if (!inside(nx, ny)) {
      fail(F("POSITION_OUT_OF_MAP"));
      return false;
    }

    // 回程不仅检查“是不是旧节点”，
    // 还检查是不是本次预期返回的那个节点。
    if (travelKind != 0 &&
        (nx != expectedReturnX || ny != expectedReturnY)) {
      Serial.print(F("RETURN expected="));
      Serial.print(expectedReturnX);
      Serial.print(',');
      Serial.print(expectedReturnY);
      Serial.print(F(" estimated="));
      Serial.print(nx);
      Serial.print(',');
      Serial.println(ny);

      fail(F("RETURN_TARGET_MISMATCH"));
      return false;
    }

    gx = nx;
    gy = ny;

    legStarted = false;
  }

  Node &node = nodes[gy][gx];

  if (!nodeUsed(node)) {
    if (arrived && travelKind != 0) {
      fail(F("RETURN_NODE_MISSING"));
      return false;
    }

    node.flags = NODE_USED;
    node.parentDir = arrived ? back : NO_PARENT;
    node.parentCells = arrived ? (uint8_t)cells : 0;
  } else if (arrived && travelKind == 0) {
    // 探索新分支却到达旧节点：
    // 认为形成环路，返回刚才出发的节点。
    node.flags |= bitFor(back);

    return depart(
        back, 2, sourceX, sourceY, L, R
    );
  }

  bool open[4] = {false, false, false, false};

  open[(heading + 3) % 4] = s.left == 1;
  open[heading] = s.front == 1;
  open[(heading + 1) % 4] = s.right == 1;

  if (arrived) {
    open[back] = true;
    node.flags |= bitFor(back);
  }

  // 保留原来的左、前、右探索顺序。
  // 不为了“不停车”强行改变探索策略。
  int order[3] = {
    (heading + 3) % 4,
    heading,
    (heading + 1) % 4
  };

  for (uint8_t i = 0; i < 3; i++) {
    int direction = order[i];

    if (open[direction] &&
        !(node.flags & bitFor(direction)) &&
        direction != node.parentDir) {
      node.flags |= bitFor(direction);

      return depart(
          direction, 0, -1, -1, L, R
      );
    }
  }

  if (node.parentDir != NO_PARENT) {
    int direction = node.parentDir;

    if (!open[direction]) {
      fail(F("PARENT_DIRECTION_BLOCKED"));
      return false;
    }

    int parentX =
        gx + DX[direction] * node.parentCells;

    int parentY =
        gy + DY[direction] * node.parentCells;

    if (!inside(parentX, parentY)) {
      fail(F("PARENT_OUT_OF_MAP"));
      return false;
    }

    return depart(
        direction, 1, parentX, parentY, L, R
    );
  }

  fail(F("NO_UNTRIED_ROUTE_OR_FINISH"));
  return false;
}

void handleTooClose(const Reading &L,
                    const Reading &front,
                    const Reading &R) {
  stopRobot();

  Scan s = currentScan();

  if (!scanMatchesLatest(s, L, front, R)) {
    if (!scanWhileSafetyStopped(s)) {
      if (!halted) {
        fail(F("CLOSE_JUNCTION_UNCERTAIN"));
      }
      return;
    }
  }

  if (!timeOK()) return;

  serviceJunction(s, L, R, true);
}

// ============================================================
// 主循环
// ============================================================

void loop() {
  if (halted) {
    stopRobot();

    if (finished) {
      leds(true, true, true);
    } else {
      bool on = (millis() / 250UL) % 2UL;
      leds(on, on, on);
    }

    delay(20);
    return;
  }

  if (!timeOK()) return;

  // 前方先读，过近时立即下达停车命令。
  Reading front = readSensor(FRONT_TX, FRONT_RX);

  bool close = tooClose(front);

  if (close) {
    stopRobot();
  }

  Reading L = readSensor(LEFT_TX, LEFT_RX);
  Reading R = readSensor(RIGHT_TX, RIGHT_RX);

  pushScan(L, front, R);
  updateSideTracking(L, R);

  if (close) {
    handleTooClose(L, front, R);
    return;
  }

  Scan s = currentScan();

  bool leftEvent =
      leftOpenVotes >= SIDE_OPEN_CONFIRM &&
      !leftLatched;

  bool rightEvent =
      rightOpenVotes >= SIDE_OPEN_CONFIRM &&
      !rightLatched;

  // ----------------------------------------------------------
  // 侧开口居中阶段
  // ----------------------------------------------------------

  if (phase == 2) {
    if (millis() - phaseStartedAt >= SIDE_CENTER_MS) {
      bool candidateStillOpen =
          (leftCandidate && isOpen(L)) ||
          (rightCandidate && isOpen(R));

      if (!candidateStillOpen) {
        fail(F("OPENING_LOST_CHECK_SIDE_CENTER"));
        return;
      }

      // 使用行驶中已经收集的结果。
      // 不停车，不再进行七轮阻塞扫描。
      if (!scanMatchesLatest(s, L, front, R)) {
        fail(F("MOVING_JUNCTION_UNCERTAIN"));
        return;
      }

      serviceJunction(s, L, R, false);
      return;
    }

    driveCorrected(L, R, CAUTION_DRIVE_PERCENT);
    printStatus(L, front, R);
    return;
  }

  // ----------------------------------------------------------
  // 新侧开口
  // 在正常行驶或前墙接近阶段，都可以切换到居中。
  // ----------------------------------------------------------

  if ((leftEvent || rightEvent) &&
      afterDepartForwardMs >= SIDE_REARM_MS) {
    leftCandidate = leftEvent;
    rightCandidate = rightEvent;

    if (leftEvent) leftLatched = true;
    if (rightEvent) rightLatched = true;

    phase = 2;
    phaseStartedAt = millis();

    driveCorrected(L, R, CAUTION_DRIVE_PERCENT);
    return;
  }

  // ----------------------------------------------------------
  // 前墙接近阶段
  // ----------------------------------------------------------

  if (phase == 1) {
    // 若连续确认前方重新开放，取消本次前墙接近。
    // 避免单次前墙误读在若干秒后制造假节点。
    if (s.front == 1 &&
        front.bands < FRONT_WALL_THRESHOLD) {
      phase = 0;
      phaseStartedAt = 0;

      driveCorrected(L, R, CAUTION_DRIVE_PERCENT);
      return;
    }

    if (millis() - phaseStartedAt >= FRONT_APPROACH_MS) {
      if (!scanMatchesLatest(s, L, front, R)) {
        fail(F("FRONT_JUNCTION_UNCERTAIN"));
        return;
      }

      if (s.front != 0) {
        fail(F("FRONT_APPROACH_CONFLICT"));
        return;
      }

      // 前方已确认有墙，只会选择侧转、掉头或结束。
      serviceJunction(s, L, R, false);
      return;
    }

    driveCorrected(L, R, CAUTION_DRIVE_PERCENT);
    printStatus(L, front, R);
    return;
  }

  // ----------------------------------------------------------
  // 普通前墙报墙
  // 不立即停车，进入带纠偏的低速接近。
  // ----------------------------------------------------------

  if (front.bands >= FRONT_WALL_THRESHOLD) {
    phase = 1;
    phaseStartedAt = millis();

    driveCorrected(L, R, CAUTION_DRIVE_PERCENT);
    return;
  }

  // ----------------------------------------------------------
  // 正常直行
  // 保持电机运行；传感器采样期间继续使用上一轮PWM。
  // ----------------------------------------------------------

  bool slow =
      afterDepartForwardMs < SIDE_REARM_MS ||
      !hasWall(L) ||
      !hasWall(R) ||
      front.bands >= 1 ||
      front.votes >= 3 ||
      filteredError > 3.0f ||
      filteredError < -3.0f;

  driveCorrected(
      L, R,
      slow ? CAUTION_DRIVE_PERCENT : 100
  );

  leds(false, true, false);
  printStatus(L, front, R);
}
```

下面按实际运行顺序说明。

**1. 硬件和方向定义**

电机和传感器引脚为：

```cpp
左舵机：13
右舵机：12

左传感器：TX 10，RX 11
前传感器：TX 6，RX 7
右传感器：TX 2，RX 3
```

方向用数字表示：

```text
0：初始前进方向
1：右方
2：后方
3：左方
```

这里的“北、东、南、西”只是程序内部坐标，不要求小车真的朝北。只要启动时小车正对通道，后续相对方向就成立。

坐标变化：

```cpp
DX = {0, 1, 0, -1}
DY = {-1, 0, 1, 0}
```

例如：

- `heading=0`，前进后 `y` 减少；
- `heading=1`，前进后 `x` 增加；
- `heading=2`，前进后 `y` 增加；
- `heading=3`，前进后 `x` 减少。

**2. 电机参数**

停止值：

```cpp
LEFT_STOP_PWM  = 1490
RIGHT_STOP_PWM = 1490
```

直行值：

```cpp
LEFT_FORWARD  = 1550
RIGHT_FORWARD = 1438
```

左右轮的正负方向不同，所以左右电机的PWM数值方向不一样。

转弯使用固定时间：

```cpp
LEFT_TURN_MS  = 615
RIGHT_TURN_MS = 622
UTURN_LEFT_MS = 1250
```

你已经实测过这些值，所以当前不需要调整。

```cpp
T_CELL = 1480
```

表示小车正常速度走一格所需的等效时间，也已经实测过，当前不需要调整。

**3. 红外传感器如何读数**

每个传感器检测5个频率：

```text
38000、39000、40000、41000、42000Hz
```

每个频率采样3次。

最后得到：

```cpp
Reading {
  bands,
  votes
}
```

含义是：

- `bands`：5个频率中，有多少个频率被判断为检测到墙；
- `votes`：总共15次采样中，有多少次检测到墙。

例如：

```text
bands=3，votes=9
```

表示反射比较明显。

侧面判断有墙：

```cpp
bands >= 2 || votes >= 3
```

侧面判断开放：

```cpp
bands <= 0 && votes <= 1
```

因此侧面还有一种状态：

```text
既不能确认有墙，也不能确认完全开放
```

这种状态会被记为：

```cpp
-1
```

前方判断比较简单：

```cpp
front.bands >= 3
```

就认为前方有墙，否则认为前方开放。

前方过近保护：

```cpp
bands >= 5 && votes >= 14
```

这不是普通路口判断，而是危险保护。满足时会立即停车。

**4. 启动时做什么**

`setup()`首先：

1. 初始化串口；
2. 设置传感器输入输出；
3. 连接两个舵机；
4. 让小车停止；
5. 等待1秒；
6. 清空16×16地图；
7. 把起点坐标设置为：

```cpp
gx = 8;
gy = 8;
heading = 0;
```

起点被标记为已经使用：

```cpp
root.flags = NODE_USED | bitFor(heading);
```

程序默认：

- 小车正对通道；
- 后方不用探索；
- 初始前进方向为有效方向。

然后读取一次前、左、右传感器，初始化扫描状态，最后调用：

```cpp

```

小车以85%速度开始前进。

**5. 正常直行时如何纠偏**

主循环每次先读取：

```text
前方 → 左侧 → 右侧
```

然后调用：

```cpp
driveCorrected(L, R, percent);
```

如果左右都有墙：

```cpp
error =
(L.votes - ALIGN_LEFT_TARGET)
-
(R.votes - ALIGN_RIGHT_TARGET);
```

当前左右目标都是：

```cpp
ALIGN_LEFT_TARGET  = 7
ALIGN_RIGHT_TARGET = 7
```

程序根据左右反射强弱差异判断车身偏向。

如果只有左墙：

```cpp
error = L.votes - ALIGN_LEFT_TARGET;
```

使用左墙进行单墙纠偏。

如果只有右墙：

```cpp
error = -(R.votes - ALIGN_RIGHT_TARGET);
```

使用右墙进行单墙纠偏。

如果左右都没有可靠墙：

```cpp
error = 0
```

此时没有有效墙面反馈，只能依靠左右电机本身的标定继续直行。

纠偏还有三层限制：

```cpp
ERROR_DEADBAND = 2
```

误差小于等于2时不纠偏，避免频繁摆动。

```cpp
MAX_CORRECTION = 22
```

双墙时最大修正量。

```cpp
SINGLE_WALL_MAX_CORRECTION = 12
```

单墙时最大修正量，故意更小，防止只靠一面墙时过度修正。

```cpp
CORRECTION_STEP = 4
```

每次修正不能突然变化太大。

所以你之前担心的 START 1 到 START 2 路段，右边进入开口后：

- 右墙纠偏会失效；
- 但左墙还在时，会使用左墙纠偏；
- 只有左右都无法检测到墙时，才完全没有墙面纠偏。

**6. 为什么直行不会停车**

正常直行最终都会调用：

```cpp
driveCorrected(...)
```

这个函数只修改电机PWM，不调用：

```cpp
stopRobot()
```

因此直行过程中：

- 读取传感器不会停车；
- 左右出现开口不会立即停车；
- 选择直行时不会停车；
- 只会降低到85%速度并继续走。

主循环中以下情况会降低到85%：

```cpp
afterDepartForwardMs < SIDE_REARM_MS
!hasWall(L)
!hasWall(R)
front.bands >= 1
front.votes >= 3
纠偏误差较大
```

其他情况下可以用100%速度。

**7. 侧面出现开口时怎么处理**

程序会分别统计左右侧连续看到开放的次数：

```cpp
SIDE_OPEN_CONFIRM = 3
```

也就是连续三轮判断某侧开放，才认为出现了真实侧路口。

同时，程序使用：

```cpp
leftLatched
rightLatched
```

防止同一个开口被连续触发多次。

某侧开口被触发后，会进入：

```cpp
phase = 2
```

也就是“侧开口居中阶段”。

此阶段仍然不停，只调用：

```cpp
driveCorrected(L, R, 85)
```

持续前进：

```cpp
SIDE_CENTER_MS = 180
```

180ms之后，程序检查：

1. 原来检测到的那一侧是否仍然开放；
2. 最近7轮传感器结果是否已经稳定；
3. 当前最新读数是否和窗口判断一致。

如果满足，就调用：

```cpp
serviceJunction(...)
```

决定左转、直行、右转或掉头。

如果侧开口消失，程序停车报错：

```text
OPENING_LOST_CHECK_SIDE_CENTER
```

如果扫描结果不一致，停车报错：

```text
MOVING_JUNCTION_UNCERTAIN
```

这里要特别注意：`SIDE_CENTER_MS`不是转弯时间，而是**从发现侧开口到开始进行路口决策之间继续前进的时间**。

**8. 前方出现墙时怎么处理**

普通前方报墙条件是：

```cpp
front.bands >= FRONT_WALL_THRESHOLD
```

当前：

```cpp
FRONT_WALL_THRESHOLD = 3
```

触发后：

```cpp
phase = 1
```

进入前墙接近阶段。

这时小车不会立即停车，而是：

```cpp
driveCorrected(L, R, 85)
```

继续低速向前，同时保持纠偏。

前墙接近最大时间：

```cpp
FRONT_APPROACH_CELLS = 1.2
FRONT_APPROACH_MS = 1.2 * 1480 = 1776ms
```

在这1776ms内：

- 如果前方重新确认开放，取消前墙接近，继续直行；
- 如果检测到侧开口，会优先进入侧开口居中；
- 如果达到1776ms，则调用路口判断。

当前代码中，1776ms到达后会执行：

```cpp
serviceJunction(...)
```

它不是单纯的超时停车，而是把此处当作一个路口继续判断。

所以这部分是当前代码中最需要注意的地方：

> 如果前墙提前很远触发，并且1776ms后侧开口尚未进入合适位置，程序可能提前进行路口决策。

不过如果期间已经触发侧开口，程序会优先走 `phase=2` 的路线。

**9. 前方过近时怎么处理**

主循环首先读取前方传感器：

```cpp
bool close = tooClose(front);
```

如果满足：

```cpp
front.bands >= 5 &&
front.votes >= 14
```

立即：

```cpp
stopRobot();
```

这属于安全停车，和正常直行不同。

停车后，程序会检查最近7轮扫描是否一致。如果不一致，就调用：

```cpp
scanWhileSafetyStopped()
```

此函数会：

1. 保持停止；
2. 重新读取7轮前、左、右；
3. 最多重试3次；
4. 得到稳定的路口状态。

如果仍然判断不清楚，报：

```text
CLOSE_JUNCTION_UNCERTAIN
```

如果前方过近但重新扫描认为前方开放，报：

```text
FRONT_CLOSE_SCAN_CONFLICT
```

如果扫描稳定，就进入：

```cpp
serviceJunction(...)
```

因此前方过近是唯一正常运行中会自动安全停车的传感器事件之一。

**10. 路口如何选择方向**

`serviceJunction()`首先得到：

```cpp

s.right
```

每个值是：

```text

1：开放
-1：不确定
```


之后将相对方向转换为绝对方向：



代码：

```cpp
int order[3] = {
  (heading + 3) % 4,
  heading,
```

- 还没有探索过；
- 不是父节点方向；

的第一个方向。

如果选中的方向和当前朝向相同：

```cpp

```

`turnTo()`直接返回：

```cpp

```

不会停车，继续直行。

如果选中方向是左、右或后方，才会：

```cpp

```

然后旋转。

**11. 你的 START 1 到 START 2 T路口会怎么走**

假设小车从 START 1 向 START 2 行驶，且当前方向是 `heading=0`。

到达这个T路口时：

- 前方通向 START 2，开放；
- 右侧上方支路，开放；
- 左侧是墙。

程序会把：

```text
左：墙
前：开放
右：开放
```

转换成方向。

探索顺序虽然是左、前、右，但左侧是墙，所以：

1. 左侧跳过；
2. 前方开放且未探索；
3. 选择前方；
4. `turnTo()`发现目标方向等于当前方向；
5. 不停车；
6. 继续驶向 START 2。

在进入上方支路的这段过程中，右侧没有墙，但左侧墙仍然存在，因此使用左墙进行单墙纠偏。

**12. 到达死路后如何掉头**

```cpp
s.right == 0
```

**13. 地图和回溯如何工作**

每个地图节点保存：

```cpp
struct Node {
  uint8_t flags;
  uint8_t parentDir;
  uint8_t parentCells;
};
```

`flags`最高位表示该节点已经使用，低4位表示四个方向是否探索过。

例如：

```text
bit0：方向0
bit1：方向1
bit2：方向2
bit3：方向3
bit7：节点已使用
```

第一次进入新节点时，程序记录：

```cpp
node.parentDir
node.parentCells
```

也就是：

- 父节点在哪个方向；
- 走了几格到达这里。

返回时，程序根据：

```cpp
expectedReturnX
expectedReturnY
```

检查是否真的回到预期位置。

如果估算坐标不一致，报：

```text
RETURN_TARGET_MISMATCH
```

这可以防止由于打滑、漏路口或时间估算错误而继续使用错误地图。

**14. 距离和坐标如何估算**

每次小车有前进PWM时，程序记录前进时间：

```cpp

```

到达路口后：

```cpp
cells =
(legEquivalentMs + T_CELL / 2) / T_CELL;
```

也就是四舍五入估算走了几格。

如果算出来小于1格：

```cpp
cells = 1;
```

85%速度时，程序用：

```cpp

```

换算成等效100%速度时间。

但这仍然是开环估计：

- 没有编码器；
- 不知道实际轮速；
- 不知道是否打滑；
- 不知道是否撞墙后仍在给电机指令。

因此地图坐标不是绝对可靠的，只能靠实测参数和路口识别维持。

**17. 这份代码的真实运行状态总结**

实际状态只有三种：

```text
phase=0：正常直行
phase=1：前墙接近，低速直行
phase=2：侧开口居中，低速直行
```

同时还有三种运动结果：

```text
直行：不停车
左转/右转/掉头：停车后旋转
危险、终点、无法判断：停车
```

当前最需要记住的不是所有参数，而是这条执行链：

```text
读取传感器
    ↓
前方过近？
    ├─ 是：停车，重新确认路口
    └─ 否
    ↓
发现侧开口？
    ├─ 是：低速继续走SIDE_CENTER_MS
    │       ↓
    │       路口判断
    └─ 否
    ↓
前方普通报墙？
    ├─ 是：进入前墙接近，低速继续走
    └─ 否：正常直行
    ↓
路口决定左、前、右或后
    ├─ 前：保持电机，不停车
    └─ 左/右/后：停车旋转
```

最现实的限制是：**这份代码能用左右IR进行单墙和双墙纠偏，但无法真正测量车身角度和实际距离。** 所以它的可靠性主要取决于：

- `SIDE_CENTER_MS=180`是否让车轴到达正确转弯点；
- 前墙阈值是否在合适距离触发；
- 左墙单墙纠偏是否能持续检测到墙；
- 普通死路和目标长死路的`enclosedForwardMs`是否能区分；
- 路段时间估算是否让回程坐标一致。


不敢说“量完以后逻辑肯定没问题”。**测量只能把运动参数调准，不能消除代码中的开环定位和传感器误判风险。** 我重新检查后，建议只测下面几项。

### 1. 前墙触发后，1776ms到期会强行决策

代码：

```cpp

    (unsigned long)(FRONT_APPROACH_CELLS * T_CELL);
```


所以1776ms实际只走了约0.85格的正常速度距离，却被当成已经到达路口。

到时间后直接：

```cpp

```

这可能导致：

- 前方远处墙刚触发；
- 侧开口还没有稳定识别；
- 车辆还没到转弯中心；
- 程序已经开始选择左转、右转或掉头。

这是当前最严重的逻辑问题。

**至少应把1776ms改成安全超时，而不是直接决策：**

```cpp
if (millis() - phaseStartedAt >= FRONT_APPROACH_MS) {
  fail(F("FRONT_APPROACH_TIMEOUT"));
  return;
}
```

不过这样会在没识别到侧开口时停车，需要确保实际路口都能先触发侧开口。

如果你暂时不改结构，建议把：

```cpp
FRONT_APPROACH_CELLS = 1.2f;
```

临时增大到：

```cpp
1.6f
```

或者：

```cpp
1.8f
```

这样给侧开口识别更多时间，但这只是应急调参，不能从根本上解决判定问题。

### 2. START 1到START 2理论上会直行，但依赖左墙纠偏

在图中从 START 1 向 START 2：

```text
左侧：连续墙
前方：通道
右侧：开口
```

代码会：

1. 检测到右侧开放；
2. 低速继续前进 `SIDE_CENTER_MS`；
3. 判断前方仍然开放；
4. 选择当前方向直行；
5. `turnTo()`直接返回，不停车。

因此方向逻辑是对的。

右侧没有墙时，纠偏会执行：

```cpp
} else if (lw) {
  error = (float)(L.votes - ALIGN_LEFT_TARGET);
}
```

所以只要左侧传感器持续检测到墙，小车不会完全失去纠偏。

真正的风险是：

```text
左墙距离太远
→ 左传感器也检测不到
→ 左右都没有墙
→ 小车只能靠左右轮标定直行
```

建议你实际看串口中的：

```text
L=bands/votes
```

如果经过右侧开口时左侧仍然有：

```text
bands >= 2 或 votes >= 3
```

这一段基本可用。

### 3. 路口检测窗口过于严格，可能直接报错停车

代码要求最近7轮中：

```cpp
SIDE_CONFIRM_VOTES = 5;
FRONT_CONFIRM_VOTES = 6;
```

并且最新一轮还要和窗口结论完全一致：

```cpp
scanMatchesLatest(...)
```

这在墙角附近可能出现：

```text
前几轮：有墙
后几轮：开放
最新一轮：不确定
```

结果不是继续走，而是：

```text
MOVING_JUNCTION_UNCERTAIN
```

这不是小车方向走错，而是算法选择了停车保护。

如果实测经常出现这个错误，优先把：

```cpp
SIDE_CONFIRM_VOTES = 5;
FRONT_CONFIRM_VOTES = 6;
```

改为：

```cpp
SIDE_CONFIRM_VOTES = 4;
FRONT_CONFIRM_VOTES = 5;
```

暂时不要改传感器墙阈值。

### 4. 前方过近重新扫描后，代码可能使用旧的左右读数

在这里：

```cpp
scanWhileSafetyStopped(s)
```

重新扫描得到新的 `s`，但函数返回后仍然调用：

```cpp
serviceJunction(s, L, R, true);
```

这里的 `L`、`R`仍然是停车前的旧读数。

如果选择直行，`depart()`会使用旧的左右传感器值初始化纠偏：

```cpp
depart(direction, 0, -1, -1, L, R);
```

这可能让转弯或直行后的第一次纠偏使用过时数据。

这是一个代码缺陷，但在你这张图中通常不是第一优先级。时间足够时应让`scanWhileSafetyStopped()`同时返回新的`L/front/R`。

### 5. DFS逻辑基本成立，但依赖坐标估计

这部分逻辑是有的：

```text
进入新分支
→ 标记方向
→ 深入
→ 死路掉头
→ 返回父节点
→ 继续下一个分支
```

但它用：

```cpp
legEquivalentMs
T_CELL
SLOW_DISTANCE_FACTOR
```

估算坐标，没有编码器。

因此只要发生以下任意情况，DFS地图就可能失效：

- 漏掉一个侧开口；
- 同一个开口重复触发；
- 低速实际比例不是0.85；
- 车轮打滑；
- 转弯后进入通道的距离不同；
- 路口决策提前或延迟。

也就是说，**DFS的程序逻辑基本有，但物理定位不是闭环。**

### 6. 终点判定有误判风险

终点判断：

```cpp
s.left == 0 &&
s.front == 0 &&
s.right == 0 &&
enclosedForwardMs >= LONG_DEADEND_MS
```

当前阈值：

```cpp
LONG_DEADEND_MS = 2960ms
```

如果 START 2附近的死路计时超过2960ms，程序可能把它误判为终点；如果目标长死路的左右墙检测中途丢失，也可能无法结束。

建议至少观察：

```text
wall=xxxx
```

确认：

```text
START 2死路计时 < 2960
目标长死路计时 > 2960
```

如果不满足，先临时：

```cpp
ENABLE_LONG_DEADEND_FINISH = false;
```

否则可能在错误位置结束。

### 对这张图的最终判断

从 START 1出发，理想运行顺序应是：

```text
START 1
→ 经过右侧支路
→ 继续直行到 START 2
→ 短死路掉头
→ 返回T路口
→ 左转进入上方通道
→ 按左优先DFS继续探索
→ 最终进入左侧长死路
→ 识别FINISH
```

**方向选择逻辑基本符合这条路线。**

但我不能说“测完参数后肯定没问题”，因为当前真正可能导致失败的是：

1. `FRONT_APPROACH_MS`到期过早决策；
2. 右侧开口时左墙纠偏是否稳定；
3. 7轮窗口是否经常判断不一致；
4. 长死路是否会误判；
5. 时间坐标是否能正确回到父节点。

如果现在只有很短时间，优先级是：

```text
第一：确认START1→START2不会报错、不会偏
第二：确认右侧开口选择直行
第三：确认START2掉头后能回到T口
第四：确认T口返回后进入上方通道
第五：最后才调终点阈值
```

**当前代码不是“逻辑完全没问题”，但主路径逻辑是成立的；最可能直接导致跑错的点是前墙1776ms超时决策和严格的移动路口确认。**
