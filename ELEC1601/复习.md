## 一、普通二进制 → 十进制

**思路：** 从右往左，每位权值是 $2^0, 2^1, 2^2 \ldots$，是 1 的位就加上对应权值。

**看到关键词：** `regular binary`、`unsigned`、`plain binary`

---

## 二、十进制 → 普通二进制

**思路：** 除以 2，记余数，从下往上读。

**做完要数位数**，别漏最高位。

---

## 三、补码 → 十进制

**思路：**
1. 看**最高位**
2. 最高位 0 → 正数，直接按普通二进制算
3. 最高位 1 → 负数，**取反 → 加 1 → 转十进制 → 加负号**

**看到关键词：** `two's complement`

---

## 四、定点 → 十进制（正数）

**思路：**
1. 数小数点后有几位 → 算 $q = 2^{-f}$
2. 去掉小数点，整体当普通二进制转十进制
3. 乘 $q$

**看到关键词：** `fixed point`（没有 `two's complement`）

---

## 五、负小数 → 补码定点

**思路：**
1. 总位数 = 整数位 + 小数位，$q = 2^{-小数位}$
2. 绝对值 ÷ q → 得整数
3. 整数转二进制
4. **补零**到总位数
5. **取反**
6. **加 1**

**看到关键词：** `two's complement fixed-point`，题目有负号

---

## 六、补码定点 → 十进制（读回）

**思路：**
1. 最高位 0 → 直接去掉小数点转十进制，再乘 $q$
2. 最高位 1 → 取反加一 → 转十进制 → 乘 $q$ → 加负号

---

## 七、浮点 → 十进制

**思路：**
1. 按题目给的格式**拆三段**：符号 | 指数 | 尾数
2. 符号位：0 → 正，1 → 负
3. 指数：直接按二进制转十进制（无符号）
4. 尾数：加上**隐式前导**（题目说 1 就前面加 1，说 0 就加 0），写成 `1.xxxx` 形式再算值
5. 最终值 = 符号 × 尾数值 × $2^{指数}$

**看到关键词：** `floating point`、`implicit leading 1/0`、`sign bit`、`exponent bits`、`mantissa bits`

---

## 八、需要几个小数位（误差题）

**思路：**
1. 最坏误差 = $q/2 = 2^{-f-1}$
2. 令 $2^{-f-1} \le$ 题目给的误差
3. 解出**最小的 f**

**看到关键词：** `rounding error`、`off by`、`at most`、`worst case`

---

## 九、表示某范围需要几位（范围题）

**思路：**
1. 数值个数 = 上限 - 下限 + 1
2. 找最小 $n$ 使 $2^n \ge$ 个数

**看到关键词：** `range [a, b]`、`how many bits`、`represent`

---

## 十、最佳缩放因子（scaling factor 题）

**思路：**
1. $n$ 位能有 $2^n$ 个格子
2. 最大能表示 $(2^n - 1) \times q$
3. 令 $(2^n - 1) \times q \ge$ 上限，$q$ 取**最小的 2 的幂**

**看到关键词：** `scaling factor`、`power of 2`、`least rounding error`

---

## 十一、二进制 ↔ 十六进制

**思路：**
- 二进制 → 十六进制：从右往左**每 4 位一组**，每组换一个 hex 符号（0-9，A-F）
- 十六进制 → 二进制：每个符号拆成 **4 位二进制**
- 十六进制 → 十进制：每位权值是 $16^k$，从右往左
- 十进制 → 十六进制：除以 16 取余，从下往上读

## 关键词对照速查

| 英文关键词 | 第一件事 |
|---|---|
| regular / unsigned | 直接转，正数 |
| two's complement | 看最高位，1 就取反加一 |
| fixed point | 算 $q$，乘或除 |
| two's complement fixed-point | 先 ÷q，再取反加一 |
| floating point + implicit leading 1 | 拆三段，尾数前加 1 |
| rounding error / off by | 用 $q/2 = 2^{-f-1}$ |
| range [a, b] | 数量 = b-a+1，求 $2^n$ |
| scaling factor | $(2^n-1)\times q \ge$ 上限 |
