# 0. 先记住 SREG 的 8 个标志位

所有分支指令都靠这些标志，位号必须记牢：

| 位号  | 名称    | 含义                        |
| --- | ----- | ------------------------- |
| 0   | **C** | Carry 进位/借位               |
| 1   | **Z** | Zero 结果为零                 |
| 2   | **N** | Negative 结果最高位（bit7）      |
| 3   | **V** | Overflow 有符号溢出            |
| 4   | **S** | Sign = N ⊕ V              |
| 5   | **H** | Half carry 半进位（bit3→bit4） |
| 6   | **T** | 位复制暂存                     |
| 7   | **I** | 全局中断使能                    |

# 1. 数据传输类

| 指令          | 格式                             | 作用                      | 限制                |
| ----------- | ------------------------------ | ----------------------- | ----------------- |
| ⭐`ldi`      | `ldi Rd, K`                    | Rd ← 立即数 K              | ⚠️ **只能 r16~r31** |
| ⭐`mov`      | `mov Rd, Rr`                   | Rd ← Rr（源不变）            | —                 |
| `movw`      | `movw Rd, Rr`                  | 复制**寄存器对**（16位）         | 必须是偶数编号           |
| ⭐`lds`      | `lds Rd, k`                    | Rd ← 内存[16位地址]          | —                 |
| ⭐`sts`      | `sts k, Rr`                    | 内存[16位地址] ← Rr          | —                 |
| `ld`        | `ld Rd, X`                     | Rd ← 内存[X]              | 不挪指针              |
| ⭐`ld`       | `ld Rd, X+`                    | 先读，**X 后加 1**           | —                 |
| `ld`        | `ld Rd, -X`                    | **X 先减 1**，再读           | —                 |
| `ld`        | `ld Rd, Y` / `Y+` / `-Y`       | 同上，用 Y 指针               | —                 |
| `ldd`       | `ldd Rd, Y+q`                  | Rd ← 内存[Y+q]，q=0~63     | 不挪指针              |
| `ld`        | `ld Rd, Z` / `Z+` / `-Z`       | 同上，用 Z 指针               | —                 |
| `ldd`       | `ldd Rd, Z+q`                  | Rd ← 内存[Z+q]            | —                 |
| `st`        | `st X, Rr` / `X+` / `-X`       | 把 Rr 写进内存，指针按规则变        | —                 |
| `st`        | `st Y, Rr` / `st Z, Rr`（及 +/−） | 同上                      | —                 |
| `std`       | `std Y+q, Rr`                  | 写内存[Y+q]                | —                 |
| `lds`/`sts` | —                              | 见上，用 16 位直接地址           | —                 |
| `lpm`       | `lpm Rd, Z` / `Z+`             | 从**程序内存（Flash）**读       | —                 |
| `elpm`      | `elpm`                         | 扩展版 lpm（大 Flash）        | —                 |
| `spm`       | `spm`                          | 往 Flash 写（Bootloader 用） | —                 |
| `in`        | `in Rd, A`                     | 从 I/O 空间读，A=0~63        | —                 |
| `out`       | `out A, Rr`                    | 往 I/O 空间写               | —                 |
| `push`      | `push Rr`                      | 压栈（栈指针后减）               | —                 |
| `pop`       | `pop Rd`                       | 出栈（栈指针先加）               | —                 |

**指针 X/Y/Z 的组成**（必背）：

| 指针 | 高字节 | 低字节 |
|---|---|---|
| X | r27 | **r26** |
| Y | r29 | **r28** |
| Z | r31 | **r30** |

# 2. 算术运算类

| 指令 | 格式 | 作用 | 限制 |
|---|---|---|---|
| ⭐`add` | `add Rd, Rr` | Rd ← Rd + Rr | — |
| `adc` | `adc Rd, Rr` | Rd ← Rd + Rr + C（多字节加法） | — |
| ⚠️`adiw` | `adiw Rd, K` | 寄存器 **对** 加立即数，K=0~63 | **只能 r24/r26/r28/r30** |
| ⭐`sub` | `sub Rd, Rr` | Rd ← Rd − Rr | — |
| ⭐`subi` | `subi Rd, K` | Rd ← Rd − K | ⚠️ **只能 r16~r31** |
| `sbc` | `sbc Rd, Rr` | Rd ← Rd − Rr − C | — |
| `sbci` | `sbci Rd, K` | Rd ← Rd − K − C | ⚠️ r16~r31 |
| ⚠️`sbiw` | `sbiw Rd, K` | 寄存器对减立即数 | **只能 r24/r26/r28/r30** |
| ⭐`inc` | `inc Rd` | Rd ← Rd + 1 | — |
| ⭐`dec` | `dec Rd` | Rd ← Rd − 1 | — |
| `neg` | `neg Rd` | Rd ← 0 − Rd（取相反数） | — |
| `com` | `com Rd` | Rd ← 0xFF − Rd（按位取反） | — |
| `mul` | `mul Rd, Rr` | **R1:R0** ← Rd × Rr（无符号） | 结果占两个寄存器 |
| `muls` | `muls Rd, Rr` | 有符号乘法 | r16~r31 |
| `mulsu` | `mulsu Rd, Rr` | 有符号 × 无符号 | r16~r23 |
| `fmul` / `fmuls` / `fmulsu` | — | 小数（Q 格式）乘法 | 少用 |

**⚠️ 三个高频陷阱**：
1. **没有 `addi` 指令**（想加立即数？只能先 `ldi` 到一个寄存器再 `add`）
2. **没有 `eori` 指令**
3. 立即数类指令（`ldi` / `andi` / `ori` / `subi` / `sbci` / `cpi`）**统统只能操作 r16~r31**

# 3. 逻辑与位运算类

| 指令 | 格式 | 作用 | 记忆 |
|---|---|---|---|
| ⭐`and` | `and Rd, Rr` | 按位与 | 都是 1 才得 1 → **清位用** |
| `andi` | `andi Rd, K` | 按位与立即数 | ⚠️ r16~r31 |
| `or` | `or Rd, Rr` | 按位或 | 有一个 1 就得 1 → **置位用** |
| `ori` | `ori Rd, K` | 按位或立即数 | ⚠️ r16~r31 |
| ⭐`eor` | `eor Rd, Rr` | 按位异或 | 不同为 1，相同为 0 |
| `sbr` | `sbr Rd, K` | = `ori`（伪指令） | Set Bits |
| `cbr` | `cbr Rd, K` | = `andi Rd, ~K`（伪指令） | Clear Bits |

**高频用法**：

```
eor r18, r18      ; 自己异或自己 → 清零
```

# 4. 移位与旋转类

| 指令 | 格式 | 作用 | 等价于 |
|---|---|---|---|
| ⭐`lsl` | `lsl Rd` | 逻辑左移 1 位，**×2** | `add Rd, Rd` |
| `lsr` | `lsr Rd` | 逻辑右移 1 位，**÷2**，最高位补 0 | — |
| `rol` | `rol Rd` | 循环左移（经过 C） | `adc Rd, Rd` |
| `ror` | `ror Rd` | 循环右移（经过 C） | — |
| `asr` | `asr Rd` | **算术**右移，**保留最高位**（保持符号） | — |
| `swap` | `swap Rd` | 高低 4 位互换 | — |

**lsr 和 asr 的区别**（考点）：

```
lsr: 1000 0000  →  0100 0000   最高位强制补 0
asr: 1000 0000  →  1100 0000   最高位保持原样
```

# 5. 比较类

| 指令 | 格式 | 作用 | 限制 |
|---|---|---|---|
| `cp` | `cp Rd, Rr` | **只改标志位**，不写回 | — |
| `cpc` | `cpc Rd, Rr` | 带进位的比较（多字节） | — |
| ⭐`cpi` | `cpi Rd, K` | 与立即数比较 | ⚠️ r16~r31 |
| `tst` | `tst Rd` | = `and Rd, Rd`（伪指令） | — |
| `clr` | `clr Rd` | = `eor Rd, Rd`（伪指令） | — |
| `ser` | `ser Rd` | = `ldi Rd, 0xFF`（伪指令） | r16~r31 |

**⚠️ 关键点**：`cp` / `cpi` / `tst` **不会改变任何寄存器**，它们只是"减一下看看结果"然后丢掉，只留下标志位给 `brxx` 用。

# 6. 跳转与调用类

| 指令 | 格式 | 作用 | 跳转范围 |
|---|---|---|---|
| `rjmp` | `rjmp k` | 相对跳转 | ±2K 字 |
| `jmp` | `jmp k` | **绝对跳转**，任意位置 | 全空间 |
| `ijmp` | `ijmp` | 跳到 Z 指向的地址 | — |
| `rcall` | `rcall k` | 相对调用子程序 | ±2K 字 |
| `call` | `call k` | 绝对调用 | 全空间 |
| `icall` | `icall` | 跳到 Z 指向的地址并压栈 | — |
| `ret` | `ret` | 子程序返回 | — |
| `reti` | `reti` | 中断返回（会重开中断） | — |

**`jmp` vs `rjmp` 在考试里的用处**：条件分支（`breq` 等）只能跳 **±64 字**，够不着就"条件分支配 `jmp`"两段式：

```
    breq  done       ; 近处，用相对分支
    jmp   loop       ; 远处，用绝对跳转
```

# 7. 条件分支（完整别名表）

基本形式只有两条，其他全是从它们派生出来的名字：

| 基本形式 | 含义 |
|---|---|
| `brbs s, k` | 如果 SREG 第 **s** 位 = **1**，跳转 |
| `brbc s, k` | 如果 SREG 第 **s** 位 = **0**，跳转 |

**别名对照表（考试必背）**：

| s | `brbs`（位=1才跳） | `brbc`（位=0才跳） | 含义 |
|---|---|---|---|
| 0 | `brcs` / **`brlo`** | **`brcc`** / **`brsh`** | 进位 / 无符号比较 |
| 1 | **`breq`** | **`brne`** | 相等 / 不等 |
| 2 | **`brmi`** | **`brpl`** | 负数 / 非负 |
| 3 | `brvs` | `brvc` | 溢出 / 无溢出 |
| 4 | `brlt` | `brge` | 有符号：小于 / 大于等于 |
| 5 | `brhs` | `brhc` | 半进位 / 无半进位 |
| 6 | `brts` | `brtc` | T 标志 |
| 7 | — | — | （中断，一般不分支） |

**无符号 vs 有符号判断**（高频考点）：

| 想做的事 | 无符号用 | 有符号用 |
|---|---|---|
| 大于等于 | `brsh`（=brcc） | `brge` |
| 小于 | `brlo`（=brcs） | `brlt` |
| 相等 | `breq` | `breq` |

> `cp` / `cpi` 之后，`brsh` 成立的含义是"C=0"，也就是**没借位**，即前者 ≥ 后者。这正是你前面 Question 2 里 `cpi r20, 4` + `brsh` 的逻辑。

# 8. 条件跳过类

| 指令 | 格式 | 跳过下一条的条件 |
|---|---|---|
| `cpse` | `cpse Rd, Rr` | 如果 Rd **=** Rr |
| ⭐`sbrs` | `sbrs Rr, b` | 如果 Rr 的 **第 b 位 = 1**（**S**et） |
| `sbrc` | `sbrc Rr, b` | 如果 Rr 的 **第 b 位 = 0**（**C**lear） |
| `sbis` | `sbis A, b` | 如果 I/O 寄存器第 b 位 = 1 |
| `sbic` | `sbic A, b` | 如果 I/O 寄存器第 b 位 = 0 |

**只跳一条**。最经典的组合：

```
sbrs r16, 0      ; bit0=1（奇数）→ 跳过
inc  r20         ; 只有偶数才加 1
```

**记忆口诀**：结尾 **s** = Set = 判 1；结尾 **c** = Clear = 判 0。

# 9. 位与位测试类

| 指令 | 格式 | 作用 |
|---|---|---|
| `sbi` | `sbi A, b` | 把 I/O 寄存器第 b 位置 1 |
| `cbi` | `cbi A, b` | 把 I/O 寄存器第 b 位清 0 |
| `bst` | `bst Rr, b` | 把 Rr 的第 b 位存进 **T 标志** |
| `bld` | `bld Rd, b` | 把 **T 标志** 写进 Rd 的第 b 位 |

**⚠️ 两个易混**：
- `sbrs` / `sbrc` 只**跳过**，**不改**寄存器
- `sbi` / `cbi` 真正**改** I/O 寄存器，且 A 只能 0~31

# 13. 寄存器限制总表（考试最爱设的坑）⚠️

# 14. 一张纸背完：考试真正会用到的

```
数据搬运：ldi  mov  lds  sts  ld X+  st Y+
算术：    add  sub  subi  inc  dec
逻辑：    and  andi  or  eor
移位：    lsl(×2)  lsr(÷2)
比较：    cp  cpi
分支：    breq  brne  brmi  brsh  brlo  brge  brlt  jmp  ret
跳过：    sbrs  sbrc
```

**15 条**。你目前做过的所有题，全部落在这个范围内。

---

## 三个最容易忘的点

1. **改内存需要 `sts`**：`lds` 读进来、`add` 算完，如果后面没有 `sts`，内存根本没变。
2. **`cp` / `cpi` 不改寄存器**：只留标志位。
3. **`sbrs` / `sbrc` 是跳过，`sbi` / `cbi` 是改写**：一个影响程序流程，一个影响 I/O 数据。
