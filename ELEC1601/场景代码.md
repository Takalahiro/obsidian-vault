

**1. 引入库与定义数据结构**

```cpp
#include <Arduino.h>
#include <Servo.h>

struct Reading {
  int bands;  // 检测到反射的频率数量
  int votes;  // 检测到反射的总次数
};
```

**2. 定义硬件引脚与参数**

- 左右轮舵机引脚。
- 左、前、右红外传感器引脚。
- 三个 LED 引脚。
- 直行、停车、左右旋转的舵机控制脉宽。
- 转弯时间、传感器阈值、纠偏参数。
- Case 9/10 搜索时间、出口确认次数、超时限制。

**3. 定义运行状态**

- `turnArmed`：是否允许执行普通转弯。
- `filteredError`：滤波后的左右传感器误差。
- `escapeScenario`：当前是否处于 Case 9/10。
- `escapeTurningLeft`：搜索旋转方向。
- `escapeConfirming`：是否正在停车确认出口。
- `escapeForwardActive`：搜索成功后是否正在短暂直行。
- `escapeFault`：搜索是否超时并锁定停车。

**4. 基础运动控制**

```cpp
motors();         // 设置左右轮控制脉宽
stopRobot();      // 停车
forwardRobot();   // 直行
spinLeft();       // 原地左转
spinRight();      // 原地右转

forwardFor();     // 定时直行
spinLeftFor();    // 定时左转
spinRightFor();   // 定时右转
```

```cpp
ledsOff();              // 关闭指示灯
```


**7. 正常行驶与普通转弯**

```cpp
driveStraight();      // 直行及左右纠偏
executeTurnRight();   // Case 2：定时右转
executeTurnLeft();    // Case 3：定时左转
lockAfterTurn();      // 转弯后暂时禁止重复普通转弯

executeScenario7();   // 保留动作，主循环未自动调用

```

**8. Case 9/10 搜索控制**

```cpp
beginEscape();     // 初始化搜索状态
runEscapeMotor();  // 按指定方向旋转
updateEscape();    // 检测前方，搜索并确认出口
finishEscape();    // 搜索成功，短暂直行
failEscape();      // 搜索超时，锁定停车
```

- **Case 9**：三面有墙，先左转寻找出口，失败后改向右转。
- **Case 10**：普通转弯后前方仍有墙，朝侧面出口继续转。
- 发现可能的出口后，停车并连续确认。
- 搜索超过五秒，停车等待复位。

**9. `setup()` 初始化**

```text
启动串口
→ 设置传感器和 LED 引脚
→ 连接左右舵机
→ 停车等待
→ 记录启动时间
```

**10. `loop()` 主控制流程**

```text
搜索超时锁定？
├─ 是：保持停车
└─ 否
   ↓
正在 Case 9/10？
├─ 是：检测前方并更新搜索状态
└─ 否
   ↓
读取左、前、右传感器
   ↓
处理搜索成功后的短暂直行
   ↓
前方有墙？
├─ 是：停车并复核路口
│  ├─ 三面有墙 → Case 9
│  ├─ 普通转弯未解锁，侧面有出口 → Case 10
│  ├─ 允许普通转弯，左侧开放 → Case 3
│  ├─ 允许普通转弯，右侧开放 → Case 2
│  └─ 状态不确定 → 停车等待
└─ 否
   ↓
左右都开放？
├─ 是：Case 0 停车
└─ 否
   ↓
处理启动阶段和转弯后的恢复
   ↓
Case 1 正常直行，或 Case 5/6 纠偏
```

这是当前版本的大纲，**Case 10 仍依赖先执行普通转弯，不能开机直接独立识别岔路。**
